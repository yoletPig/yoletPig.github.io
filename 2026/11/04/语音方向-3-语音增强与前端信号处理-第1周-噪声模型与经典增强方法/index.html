第1周-噪声模型与经典增强方法

发表于 2026-11-04 更新于 2026-11-05 分类于 语音方向 ， Stage 3-语音增强与前端信号处理 阅读次数： 本文字数： 3.9k 阅读时长 ≈ 14 分钟

第 1 周教程：噪声模型与经典增强方法

本周要回答的三个问题

  1. 平稳噪声与非平稳噪声在增强上有什么本质区别？噪声功率谱怎么估？
  2. 维纳滤波的"最优增益"是怎么推出来的？先验信噪比 ξ\xiξ 是什么？
  3. Decision-Directed 方法为什么能抑制音乐噪声？α\alphaα 平滑因子如何权衡？

对应学习计划：第 1 周。交付物：手写 Decision-Directed 维纳滤波器，在 0/5/10 dB SNR 上测 PESQ/STOI 随 SNR 的变化，并与 Stage 1 的谱减法对比。

1. 第一性原理：增强 = 在时频域估计"干净的增益"

1.1 统一框架

几乎所有单通道语音增强都可归结为：对每个时频单元估计一个增益 G[m,k]G[m,k]G[m,k]，乘到带噪频谱上：

S^[m,k]=G[m,k]⋅Y[m,k]\hat{S}[m,k] = G[m,k] \cdot Y[m,k] S^[m,k]=G[m,k]⋅Y[m,k]

这个公式在干什么：把带噪语音做 STFT（Stage 1 第 2 周的手写 stft()）后，得到一张"时间 × 频率"的二维表格 Y[m,k]Y[m,k]Y[m,k]——mmm 是帧号（时间），kkk 是频率 bin。增强就是给表里每个格子配一个小旋钮 G[m,k]∈[0,1]G[m,k] \in [0,1]G[m,k]∈[0,1]：这个格子听起来像语音（清辅音、元音共振峰）就把旋钮拧到接近 1（全保留），像噪声就拧到接近 0（压掉）。旋完再逆变换回波形。整周要做的事只有一件：怎么决定每个旋钮的位置。

不同方法的区别只在如何估计 GGG。谱减法用功率相减，维纳滤波用最小均方误差——都是对同一个增益的不同估计策略。

1.2 观测模型

y[n]=s[n]+v[n]y[n] = s[n] + v[n] y[n]=s[n]+v[n]

这个公式在干什么：麦克风收到的每一个样本都是"干净语音 + 噪声"的叠加——sss 是干净语音，vvv 是噪声。这个加性假设是整周一切推导的地基（混响导致的卷积噪声不在此列，那是另一个课题）。

在时频域，假设两者不相关，功率可直接相加：

∣Y∣2=∣S∣2+∣V∣2|Y|^2 = |S|^2 + |V|^2 ∣Y∣2=∣S∣2+∣V∣2

这个公式在干什么：为什么"功率"能直接相加？展开 ∣S+V∣2=∣S∣2+∣V∣2+2Re(SV∗)|S+V|^2 = |S|^2 + |V|^2 + 2\text{Re}(SV^*)∣S+V∣2=∣S∣2+∣V∣2+2Re(SV∗)，多出来的交叉项是语音与噪声的乘积——两者不相关时它的时间平均趋于 0，于是剩下一个漂亮的加法式。它告诉你：只要你估得出 ∣V∣2|V|^2∣V∣2（噪声功率谱），就能从 ∣Y∣2|Y|^2∣Y∣2 里"减"出语音功率——这就是第 2.4 节噪声估计如此重要的原因。

由此定义两个信噪比。后验信噪比（posterior SNR，记号 γ\gammaγ）——直接用观测量算：

γ=∣Y[m,k]∣2σ^v2[k]\gamma = \frac{|Y[m,k]|^2}{\hat{\sigma}_v^2[k]} γ=σ^v2​[k]∣Y[m,k]∣2​

先验信噪比（priori SNR，记号 ξ\xiξ，希腊字母 xi）——干净语音与噪声之比，这是我们需要但观测不到的量：

ξ=∣S[m,k]∣2σ^v2[k]\xi = \frac{|S[m,k]|^2}{\hat{\sigma}_v^2[k]} ξ=σ^v2​[k]∣S[m,k]∣2​

这两个符号在干什么：分母都是噪声功率谱估计 σ^v2[k]\hat{\sigma}_v^2[k]σ^v2​[k]（“v 的方差"按频率 bin 给出）。γ\gammaγ 用的是 ∣Y∣2=∣S∣2+∣V∣2|Y|^2 = |S|^2 + |V|^2∣Y∣2=∣S∣2+∣V∣2——所以 γ\gammaγ 在纯噪声段围绕 1 波动（∣S∣2≈0|S|^2\approx 0∣S∣2≈0），有语音时明显大于 1；它可测但被噪声污染。ξ\xiξ 用的是干净的 ∣S∣2|S|^2∣S∣2——它是"真正的信噪比”，是真相但不可测。类比：γ\gammaγ 是"体检时带病测出的指标"，ξ\xiξ 是"健康的真实程度"；增强算法的全部智慧在于从 γ\gammaγ 估计 ξ\xiξ（第 2.3 节的 Decision-Directed 就是干这个的）。

1.3 噪声分类

类型 特征 例子 增强难度
平稳 统计特性不随时间变 白噪声、风扇、空调 易（噪声谱固定，好估）
非平稳 统计特性快速变化 键盘、街道、多人背景 难（噪声谱追不上）
类语音 本身就是语音 背景人声（鸡尾酒会） 最难（与目标同类）

噪声谱估计是经典方法的命门：

  • 平稳噪声：从初始静音段平均即可；
  • 非平稳：需自适应跟踪——MCRA（Minima Controlled Recursive Averaging，Cohen 2003）或最小值跟踪（Minimum Statistics，Martin 2001）：前者"只在最小值附近的帧做递归平均"，后者"滑窗取最小值天然落在噪声上"。本教程用最简单的静音段 + VAD 门控递归平均（2.4 节），为的是把精力集中在增益估计上。

2. 维纳滤波：最小均方误差意义下的最优增益

2.1 推导

维纳滤波要找一个增益 GGG，使估计 S^=G⋅Y\hat{S} = G \cdot YS^=G⋅Y 与真实 SSS 的均方误差最小：

min⁡G  E[∣S−GY∣2]\min_G \; \mathbb{E}\big[|S - G Y|^2\big] Gmin​E[∣S−GY∣2]

这个公式在干什么：在所有可能的增益里，挑"平均而言猜得最准"的那个。E[⋅]\mathbb{E}[\cdot]E[⋅] 是对所有随机情况（语音内容、噪声实现）取期望；∣S−GY∣2|S - GY|^2∣S−GY∣2 是"猜错的能量"。直觉上这是一个定价问题：YYY 是"含噪报价"，GGG 是你对该报价的信任度——信任度该多高，才能让"猜错的总代价"最小？

对 GGG 求导置零（就算允许 GGG 取复数，最优解也是下面这个实数值），利用 SSS 与 VVV 不相关（交叉项 E[VS∗]=0\mathbb{E}[V S^*] = 0E[VS∗]=0 消失）：

Gwiener=E[∣S∣2]E[∣Y∣2]=E[∣S∣2]E[∣S∣2]+E[∣V∣2]=ξ1+ξG_{\text{wiener}} = \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|Y|^2]} = \frac{\mathbb{E}[|S|^2]}{\mathbb{E}[|S|^2] + \mathbb{E}[|V|^2]} = \frac{\xi}{1 + \xi} Gwiener​=E[∣Y∣2]E[∣S∣2]​=E[∣S∣2]+E[∣V∣2]E[∣S∣2]​=1+ξξ​

这三步在干什么：最优信任度 = “信号功率占观测功率的比例”。语音越强，越信观测；噪声越强，越不信。代入先验信噪比 ξ\xiξ 得到盒装的最优增益：

 G=ξ1+ξ \boxed{\,G = \frac{\xi}{1 + \xi}\,} G=1+ξξ​​

这正是学习计划自测题里的那个公式。动手感受它的形状（拿计算器按两下比背公式有用）：

先验 SNR ξ\xiξ 增益 G=ξ1+ξG=\frac{\xi}{1+\xi}G=1+ξξ​ 策略
9（≈9.5 dB） 0.90 语音很强 → 几乎全保留
1（0 dB） 0.50 五五开 → 砍半（-6 dB）
0.11（≈-9.5 dB） 0.10 噪声主导 → 只留 10%
0 0 纯噪声 → 全压掉

注意 GGG 永远在 (0,1)(0,1)(0,1) 之间且永不突然跳变——这与谱减法的"硬开关"形成对比，是维纳滤波音乐噪声更少的原因之一。

2.2 核心困难：ξ\xiξ 未知

ξ\xiξ 依赖未知的 ∣S∣2|S|^2∣S∣2——你手里只有带噪的 YYY。经典做法是 **Decision-Directed（判决导向）**估计，出自 Ephraim & Malah 1984 年那篇著名论文（同一篇提出了 MMSE-STSA 幅度估计器）。

2.3 Decision-Directed 方法

一句话直觉：像医生复诊——对当前病情的判断 = 大部分参考"上一次的诊断结果"（α\alphaα），小部分参考"今天的化验单"（1−α1-\alpha1−α）。两路信息按固定比例混合，既稳又不太迟钝。

Ephraim-Malah 的决策导向法用上一帧的增强结果来估计当前帧的先验信噪比：

ξ^[m,k]=α∣S^[m−1,k]∣2σ^v2[k]⏟上一帧增强结果外推+(1−α)max⁡(γ[m,k]−1,0)⏟当前帧后验粗估\hat{\xi}[m,k] = \alpha \underbrace{\frac{|\hat{S}[m-1,k]|^2}{\hat{\sigma}_v^2[k]}}_{\text{上一帧增强结果外推}} + (1-\alpha) \underbrace{\max(\gamma[m,k] - 1, 0)}_{\text{当前帧后验粗估}} ξ^​[m,k]=α上一帧增强结果外推σ^v2​[k]∣S^[m−1,k]∣2​​​+(1−α)当前帧后验粗估max(γ[m,k]−1,0)​​

逐符号拆开：

  • ∣S^[m−1,k]∣2|\hat{S}[m-1,k]|^2∣S^[m−1,k]∣2：上一帧刚增强完的干净功率谱——它是我们手里对"语音长什么样"最好的猜测；
  • 除以 σ^v2[k]\hat{\sigma}_v^2[k]σ^v2​[k]：换算成先验 SNR 的单位；
  • γ[m,k]−1\gamma[m,k]-1γ[m,k]−1：由 1.2 节 ∣Y∣2=∣S∣2+∣V∣2|Y|^2 = |S|^2+|V|^2∣Y∣2=∣S∣2+∣V∣2 可知 γ−1≈∣S∣2/σ^v2=ξ\gamma-1 \approx |S|^2/\hat{\sigma}_v^2 = \xiγ−1≈∣S∣2/σ^v2​=ξ——减 1 就是粗略地把噪声份额剔掉；max⁡(⋅,0)\max(\cdot, 0)max(⋅,0) 防止噪声波动让它变负；
  • α\alphaα：两路信息的混合比例（α∈[0,1)\alpha \in [0,1)α∈[0,1)）。

两项的含义：

  • 第一项（权重 α\alphaα）：用上一帧已增强的 ∣S^∣2|\hat{S}|^2∣S^∣2 外推当前——时间平滑，抑制噪声引起的瞬时波动；
  • 第二项（权重 1−α1-\alpha1−α）：当前帧的后验粗估——快速响应，跟上语音突然出现。

α\alphaα 的作用（本周自测题）：

α\alphaα 行为 代价
大（0.98） 强平滑，增益曲线连续 音乐噪声少；但响应慢，辅音瞬态被抹平
小（0.5） 快速跟上变化 瞬态保得好；但平滑弱，音乐噪声回来

为什么能抑制音乐噪声（对比谱减法）：谱减法直接功率相减，噪声谱估计误差造成随机孤立尖峰——一帧在、一帧不在的"孤岛"信号，听感是"汩汩水声/鸟鸣"；Decision-Directed 的时间平滑让增益在时频面上连续变化，孤立尖峰被相邻帧平均掉。

2.4 噪声功率谱估计

本周用初始静音段平均（简化版），并实现一个基础的递归平均应对缓慢变化：

σ^v2[k]←βσ^v2[k]+(1−β)∣Y[m,k]∣2（仅在判定为噪声帧时更新）\hat{\sigma}_v^2[k] \leftarrow \beta \hat{\sigma}_v^2[k] + (1-\beta)|Y[m,k]|^2 \quad \text{（仅在判定为噪声帧时更新）} σ^v2​[k]←βσ^v2​[k]+(1−β)∣Y[m,k]∣2（仅在判定为噪声帧时更新）

这个公式在干什么：指数滑动平均（EMA）——新估计 = “93% 旧估计 + 7% 当前观测”（取 β=0.93\beta=0.93β=0.93 时）。β\betaβ 越大越"恋旧"（平滑、抗突发），越小越"追新"。关键在括号里的条件：只在 VAD 判定当前帧是噪声时才更新——否则语音帧的功率会被当成噪声学进去，把语音一起削掉。这就是"VAD 门控"。生产系统用 MCRA/最小值跟踪替代这个手工开关（1.3 节）。

一句话总结：经典增强 = 在每个时频格上估增益；维纳滤波给出最优增益 G=ξ/(1+ξ)G=\xi/(1+\xi)G=ξ/(1+ξ)；ξ\xiξ 测不到，就用"上一帧结果 + 当前粗估"按 α\alphaα 混合来估（Decision-Directed）；而整个体系的地基——噪声功率谱——全靠估计，估不准则满盘皆输，这正是第 2 周深度方法要接管的环节。

3.2 多 SNR 实验与对比表

PESQ 需要 pip install pesq（含 C 扩展）。PESQ 的宽带模式 "wb" 只支持 8/16 kHz 采样率——这也是语音处理统一用 16 kHz 的原因之一。

预期：三行输出，每行增强后 PESQ/STOI 均高于带噪（0 dB 时 PESQ 提升最明显，可达 +0.3~0.8；10 dB 时提升较小，本来就干净）。STOI 本身对"降噪但轻微失真"不敏感，数值变化不如 PESQ 明显，属正常现象。

3.3 与谱减法对比 + α\alphaα 消融

谱减法出处：Boll 1979《Suppression of Acoustic Noise in Speech Using Spectral Subtraction》。这里的 alpha=2.0 是"过减因子"（多减一点噪声、压低残留），beta=0.01 是"谱底"（负值不置零而是压到 0.01⋅∣Y∣20.01\cdot|Y|^20.01⋅∣Y∣2，正是 Boll 为抑制音乐噪声提出的技巧——Berouti 等人同年的工作将其参数化为 α,β\alpha,\betaα,β）。

预期：维纳 DD 通常略优于谱减法；α\alphaα 消融显示 0.98 的平滑最稳（音乐噪声最少）。试听三者确认音乐噪声差异——这是理解"为什么经典方法不够"的关键体验。

4. 工程权衡与失效模式

4.1 权衡

  • α\alphaα 平滑：大 → 稳但钝（抹瞬态）；小 → 快但噪。0.95-0.98 是经验区间；
  • 增益下限 gain_floor：太低 → 音乐噪声；太高 → 残留噪声。0.01-0.1；
  • 噪声估计：初始段平均简单但对非平稳失效——这是下周深度方法要解决的。

4.2 失效模式

  1. 非平稳噪声失效：键盘声、背景人声——静态噪声谱严重失配。定位：看增强后噪声是否"跟着变"；修复：自适应估计或深度模型。
  2. 音乐噪声：α\alphaα 太小或 gain_floor 太低。试听有"鸟鸣"；修复：加大 α\alphaα、提下限。
  3. 辅音被抹：平滑过强把 /s/ /t/ 的瞬态压掉，可懂度降。修复：降 α\alphaα、缩短平滑窗。
  4. 音乐噪声与失真的混淆：PESQ 升但听感"发闷"——这是过度平滑。PESQ 对平滑不敏感，需配合试听与 STOI。

5. 延伸思考题（含解析）

Q1：维纳增益 G=ξ/(1+ξ)G = \xi/(1+\xi)G=ξ/(1+ξ) 中 ξ\xiξ 是什么？为什么它观测不到？
A：ξ\xiξ 是先验信噪比，干净语音功率与噪声功率之比。它含未知的 ∣S∣2|S|^2∣S∣2，观测里只有 S+VS+VS+V 的混合，故不可直接测，必须估计。

Q2：先验 ξ\xiξ 与后验 γ\gammaγ 的区别？
A：后验 γ=∣Y∣2/σv2\gamma = |Y|^2/\sigma_v^2γ=∣Y∣2/σv2​ 用含噪观测 YYY 算，可直接得但被噪声污染；先验 ξ=∣S∣2/σv2\xi = |S|^2/\sigma_v^2ξ=∣S∣2/σv2​ 用干净 SSS，是真值但未知。DD 法用后验和历史增强结果去估先验。

Q3：α\alphaα 平滑因子如何权衡？取 0 和 1 分别退化为什么？
A：α\alphaα 大强平滑（稳但钝），α\alphaα 小快响应（快但噪）。α=0\alpha=0α=0 退化为纯后验（每帧独立、音乐噪声重）；α=1\alpha=1α=1 完全依赖上一帧（响应极慢）。

Q4：Decision-Directed 为什么比谱减法音乐噪声少？
A：DD 的时间平滑使增益在时频面连续变化，噪声谱估计误差造成的孤立尖峰被相邻帧平均掉；谱减法逐帧独立相减，误差直接表现为随机尖峰。

Q5：为什么非平稳噪声下经典方法失效？深度方法凭什么能行？
A：经典方法依赖显式的噪声功率谱估计，非平稳噪声的谱追不准。深度模型端到端学习"带噪→干净"的映射，隐式建模噪声的时变结构，不需显式估噪声谱——这是第 2 周的主题。
