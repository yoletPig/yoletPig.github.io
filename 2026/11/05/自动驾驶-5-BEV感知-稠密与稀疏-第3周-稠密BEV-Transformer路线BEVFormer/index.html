第 3 周教程：稠密 BEV 路线 II——Transformer 与 BEVFormer

本周要回答的四个问题

  1. BEVFormer 的 BEV query 是什么？"格子主动问图像"和 LSS 的"像素撒向格子"方向差在哪？
  2. Spatial Cross-Attention 的公式逐符号是什么？多相机重叠、视野外的格子怎么处理？
  3. 时序融合怎么做？ego 在动，上一帧的 BEV 特征怎么"搬"到当前帧对齐？
  4. BEVFormer 和 DETR 是什么关系？LSS 系 vs Transformer 系到底怎么选？

对应学习计划：第 3 周。交付物：NumPy 模拟 1 个 BEV query 柱（4 个高度参考点）投影到 3 个虚拟相机做带 mask 的 cross-attention；验证注意力权重和为 1；实现 ego 运动 warp 的格子对齐计算。

1. 方向性反转：从"像素撒"到"格子问"

LSS 的信息流：图像是主体，每个像素带着深度分布撒向 BEV 网格——网格被动接收。BEVFormer（Li et al., ECCV 2022, arXiv:2203.17270，官方代码 fundamentalvision/BEVFormer）把方向反过来：BEV 网格是主体。

1.1 BEV query：可学习的"格栅问句"

定义一组可学习参数 Q∈RHB×WB×CQ \in \mathbb{R}^{H_B \times W_B \times C}Q∈RHB​×WB​×C（nuScenes 惯例 HB=WB=200H_B = W_B = 200HB​=WB​=200，C=256），每个元素对应一根 BEV 柱，称为 BEV query。把它读成一句"问话"：

“我是 ego 系里 (x=20.5 m, y=-15.4 m) 这一格。谁经过这里？长什么样？过去几帧有没有动？”

回答问话的方式不是让像素来投（Lift-Splat），而是每个 query 主动去 6 个相机的特征图上找证据——找哪里、信多少，由注意力机制学出来。这个"主动问"的设计直接继承自 DETR（Carion et al., ECCV 2020）：DETR 用 ~100 个 object query 去图像里"问目标"，BEVFormer 把 query 数量放大到 200×200 = 40000 个、语义从"问目标"换成"问空间格"。所以面试里"BEVFormer 和 DETR 什么关系"的标准答案：同一种 query-based 集合表征，query 从目标级换成空间网格级，注意力从单相机换成多相机 + 多时刻。

1.2 整体结构

BEV queries  [  Temporal Self-Attention→Spatial Cross-Attention→FFN  ]×3  →  BEV 特征\text{BEV queries} \;\Big[\; \text{Temporal Self-Attention} \to \text{Spatial Cross-Attention} \to \text{FFN} \;\Big] \times 3 \; \to \; \text{BEV 特征} BEV queries[Temporal Self-Attention→Spatial Cross-Attention→FFN]×3→BEV 特征

nuScenes 配置下（官方 bevformer_base.py）：BEV 200×200（x/y ∈ [-51.2, 51.2] m @ 0.512 m）、输入 6 相机 704×1600、编码器 3 层（每层先时序后空间）。BEV 特征出来后接 CenterPoint-style 检测头（同 Stage 2），外加地图分割头。

2. Spatial Cross-Attention（SCA）公式逐符号

这是 BEVFormer 的视角转换核心。问题：BEV 柱 (i, j) 应该看 6 张图的哪些像素？

2.1 第一步：柱上参考点投影（把"看哪里"定下来）

BEVFormer 沿每根柱取 4 个不同高度的参考点（num_points_in_pillar=4，官方配置值；柱高范围 -5 m 到 3 m，取 4 个采样高度）。参考点 pkp_kpk​（k=1…4）是 ego 系 3D 点：

pk=(xi,  yj,  zk)其中 (xi,yj) 是柱的平面中心，zk 是第 k 个高度p_k = \big(x_i,\; y_j,\; z_k\big) \quad \text{其中 } (x_i, y_j) \text{ 是柱的平面中心，} z_k \text{ 是第 k 个高度} pk​=(xi​,yj​,zk​)其中 (xi​,yj​) 是柱的平面中心，zk​ 是第 k 个高度

为什么要在柱上取多个高度而不是柱心一个点：上周反投影公式告诉我们，一个像素对应一条射线；反过来，一个 3D 点只对应图像上一个像素。柱是"竖直的一串空间"，不同高度的物体（车顶、车身、车轮）落在图像的不同行上——只取一个高度会漏掉柱内其他高度的物体。4 个高度就是把柱"竖着采样 4 次"。

每个参考点用标定矩阵正投影到 6 个相机（上周公式反向用）：

(uk,n,vk,n)  ∝  Kn(Rn⋅pk+tn),n=1,…,6(u_{k,n}, v_{k,n}) \;\propto\; K_n \big( R_n \cdot p_k + t_n \big), \quad n = 1, \dots, 6 (uk,n​,vk,n​)∝Kn​(Rn​⋅pk​+tn​),n=1,…,6

逐符号：Kn,Rn,tnK_n, R_n, t_nKn​,Rn​,tn​ 是第 n 个相机的内参/ego→相机外参（Stage 3 的产物，冻结常量）；(uk,n,vk,n)(u_{k,n}, v_{k,n})(uk,n​,vk,n​) 是参考点在第 n 张图上的像素坐标。投影后做两道筛选（masked attention）：

  1. 视野 mask：像素落在图像边界外 → 该相机对该参考点不可见，剔除；
  2. 相机 mask：官方实现只保留参考点命中的相机（每个 3D 点通常只被 1~2 个相机看到，环视相机视场互斥大部分区域）。

结果：4 个高度 × 命中相机数 = 每根柱最终只有少量有效采样位置。论文原文描述：一根柱通常只被 1~2 个相机看到，SCA 只在这些相机的投影位置上计算——被所有相机都看不到的柱不更新。

2.2 第二步：在命中位置做 deformable attention

逐符号讲清这个公式在干什么：

  • Qi,j∈RCQ_{i,j} \in \mathbb{R}^{C}Qi,j​∈RC：第 (i, j) 根柱的 query 向量；
  • Vi,j\mathcal{V}_{i,j}Vi,j​：该柱有效相机集合（投影命中的相机 id 集合）——这就是"只对命中的相机算注意力"的形式化；
  • n∈Vi,jn \in \mathcal{V}_{i,j}n∈Vi,j​ 外层求和：对每个命中相机分别收集证据；
  • k=1..4k = 1..4k=1..4 内层求和：柱上 4 个高度参考点各自贡献一份证据；

  • Fn∈RH′×W′×CF_n \in \mathbb{R}^{H' \times W' \times C}Fn​∈RH′×W′×C：第 n 相机的图像特征图（backbone 输出，704×1600 下采样若干倍）；
  • DeformAttn\text{DeformAttn}DeformAttn：可变形注意力（deformable attention，出自 Deformable DETR, Zhu et al., ICLR 2021）——不做全图 attention，只在参考位置 P\mathcal{P}P 附近采少数点、并让网络预测每个采样点的注意力权重。直觉：query 拿着自己的"问句"到指定像素周围小邻域内"凑近看"，权重由"问句 × 附近特征"算出；
  • 外层 1/∣Vi,j∣1/|\mathcal{V}_{i,j}|1/∣Vi,j​∣：对命中相机数取平均，使梯度尺度不因可见相机多少而漂移。

全部拼起来的直觉：一根柱 = "我这里（x, y）这个竖直空间里有什么？"→ 取 4 个高度、投影到能看到它的相机 → 每个投影点附近采样图像特征 → 按相关性加权 → 平均回 query。LSS 是"把特征撒过去"，SCA 是"把证据收回来"——同一次坐标变换的两种用法，方向相反。

2.3 与 LSS 的三个关键差异

维度 LSS BEVFormer SCA
深度 显式 41 档分布，撒满整条射线 隐式：采样点固定在柱的 4 个高度上，"深度对不对"由注意力权重与训练信号隐式修正
算子 大规模 scatter/索引（custom CUDA 友好） deformable attention（生态标准算子，A100/Orin 都有优化）
相机间交互 各相机独立撒，重叠区在池化时叠加 一根柱显式跨相机收集证据

3. Temporal Self-Attention：时序对齐

3.1 问题：ego 在动，世界也没动

BEV 感知要回答"横穿行人"这类问题必须有速度信息——单帧 BEV 特征里"位置"有、"速度"没有。BEVFormer 的方案：把上一帧算好的 BEV 特征搬进当前帧一起算（recurrent，论文称 temporal fusion 跨 8 帧）。但两帧的 BEV 网格是"贴在车上"的坐标系——车前进 3.4 m 后，同一辆车在网格里的格子索引变了。直接把两帧特征按索引做 self-attention 是错位的。

3.2 解法：ego-motion warp（运动补偿）

Balignedt−1(i,j)=Bt−1(g−1(i,j))B^{t-1}_{\text{aligned}}(i, j) = B^{t-1}\big(g^{-1}(i, j)\big) Balignedt−1​(i,j)=Bt−1(g−1(i,j))

逐符号：Bt−1B^{t-1}Bt−1 是上一帧 BEV 特征；ggg 是本次 ego 运动对应的网格坐标变换（由定位/里程计给出位移与 yaw）；g−1(i,j)g^{-1}(i,j)g−1(i,j) 是"当前帧格子 (i,j) 的内容在上一帧网格里的位置"——通常非整数，实现上用双线性插值（grid_sample）。第 5 节代码实测：上一帧格子 (100,100)，ego 前进 (3.4, -0.2) m，该格内容对应当前帧 (93.36, 100.39)——车向前开，旧内容在当前网格索引上向后移。这个操作就是 Stage 1 学的"多帧叠加需要位姿变换"在特征层面的版本，也和 Stage 2 CenterPoint 的时序做法（把前帧点云 warp 后拼接）同一个思想：车动了、世界没动，先把坐标系统一。

3.3 warp 之后的 Temporal Self-Attention

对齐后，当前帧每根柱的 query 与同一格子索引上对齐后的上一帧特征做 self-attention：

TSA(Qi,jt)=softmax(Qi,jtKTC′)[Balignedt−1(:,i,j)Qi,jt]V\text{TSA}(Q_{i,j}^{t}) = \text{softmax}\left(\frac{Q_{i,j}^{t} K^T}{\sqrt{C'}}\right) \begin{bmatrix} B^{t-1}_{\text{aligned}}(:, i, j) \\ Q_{i,j}^{t}\end{bmatrix} V TSA(Qi,jt​)=softmax(C′​Qi,jt​KT​)[Balignedt−1​(:,i,j)Qi,jt​​]V

逐符号：key/value 只取两处——当前柱自身与对齐后的同位置历史特征（空间局部：每根柱只看自己那一格的历史，不是全图注意力，这是省算力的关键设计）；C′C'C′ 是缩放维度；输出把历史信息"揉"进当前 query。直觉：柱在问"我这个格子上一刻有什么、现在有什么——它们是同一个东西在动吗？"跨帧的对应关系让网络能学出速度。

失效模式（官方实现注释同款提醒）：ego 高速/大转向时 warp 插值误差大，超出网格范围的格子直接置零；静止目标跨 warp 反而"动"了（对齐的是世界，目标自己也在动——动目标的时序建模是第 4 周稀疏路线用"目标级传播"解决得更好的点）。

6. 工程权衡与失效模式

6.1 权衡速查

  • BEV 分辨率：0.512 m 的格子对 0.6 m 宽的行人只占 1~2 格，BEVFormer 的检测上限受网格分辨率约束——后续工作（如 BEVFormer v2、SOLOFusion）在输入分辨率与网格上继续加码；
  • 3 层编码器：每层都是全量 40000 query 的 TSA+SCA，层数与延迟线性相关；端侧复刻常砍到 1~2 层；
  • warp 依赖定位精度：TSA 的对齐质量受里程计/定位误差直接影响——定位漂移时序融合反而引入拖影（与 Stage 3 第 4 周时间标定呼应：同步误差在 warp 里同样放大）。

6.2 典型失效模式

  1. 视野交界柱信息缺失：两相机边界处参考点恰好在两者边缘出画，柱没有证据 → BEV 图"竖缝"。缓解：相机覆盖重叠区设计 + mask 策略放宽（投影到多相机）。
  2. 大转向帧 warp 错位：yaw 变化大时双线性插值取到错误邻域。症状：转急弯时远处时序拖影。缓解：只用可靠位姿帧、限制跨帧数。
  3. 注意力权重不可解释：没有显式深度分布可监督，深度学错难定位。缓解：加深度辅助监督（如 BEVDepth 思路迁移）或用带显式深度的混合架构。

7. 延伸思考题（含解析）

Q1：SCA 为什么用"参考点附近的 deformable attention"而不是"全图 attention"？
A：全图 attention 的 key 数 = 6×(H’×W’) 数万级，40000 柱 × 3 层根本算不动；且几何上柱的答案只可能在它投影位置附近——参考点投影就是强先验。deformable attention 把计算量压到"每柱 × 每命中相机 × 每高度 × 少数采样点"，同时保留可学习的微调能力。

Q2：TSA 只对"同格子"做注意力，为什么不需要更多历史格子？
A：warp 已把"世界同一位置"对齐到同一格子索引——空间对应关系由几何完成了，注意力只需判断"同一格的内容跨帧是不是同一物体"。运动目标会偏离 warp 预测，这是该设计的已知局限（第 4 周目标级传播的动机之一）。

Q3：BEVFormer 的 40000 个 BEV query 和 DETR 的 100 个 object query，训练上的最大不同？
A：DETR 用匈牙利匹配让 query 与目标 1-1 对应（稀疏集合预测）；BEVFormer 是稠密网格表征——每个 query 固定绑死一个空间格子，不存在匹配问题，检测头再从 BEV 特征出框。所以 BEVFormer 的 query 是"空间问句"，DETR 的 query 是"目标候选"——第 4 周 DETR3D 会把后者搬进 3D。

Q4：为什么 BEVFormer-base 的 test 集 mAP（37.5）比 val（41.6）还低，但 NDS 反而更高（56.9 vs 51.7）？
A：val 和 test 是不同标注子集，难度分布不同；NDS 是 mAP、mATE、mASE、mAOE、mAVE、mAAE 的复合指标，时序融合显著降低速度误差 mAVE，NDS 对"定位准、速度准"的加权让 BEVFormer 的时序优势在 NDS 上放大。教训：比较方法必须同集合同版本，单看 mAP 或单看 NDS 都会被误导。
