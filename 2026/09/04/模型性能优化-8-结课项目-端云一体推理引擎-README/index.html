Stage 8 教程索引：结课项目——端云一体推理引擎

本目录是《学习计划》的配套教程，按周组织。每篇教程遵循统一框架：设计推导与决策依据 → 系统架构与数据流 → 工程权衡与失效模式 → 实现与验证（可运行代码）→ MVP 交付指导 → 延伸思考题（含解析）。

🎓 这是性能优化方向的结课项目，也是两个方向学习计划的交汇点：语音结课项目（端侧语音助手）负责"听与说"，本项目负责"想与答"。两者共用监控与部署底座，合并即完整的端云协同语音+LLM 系统——你的旗舰作品集。

第 1-2 周：端云协同架构设计与分流策略 第 1-2 周 四象限分流决策怎么定？级联推理的时序怎么画？
第 3-4 周：云端侧搭建与压测定标 第 3-4 周 量化模型 + 调优引擎 + 编排怎么装配成服务？API 契约怎么定？
第 5-6 周：路由层与端侧集成级联闭环 第 5-6 周 路由层怎么实现四象限分流？级联"升级-回填"闭环怎么跑通？
第 7-8 周：全链路监控与结课作品集 第 7-8 周 端云分流指标怎么加进大盘？作品集怎么包装成求职材料？

贯穿全阶段的一条主线

请求→路由层{端侧（隐私/低延迟/兜底）云端（能力/重载）→级联 + 回填响应\text{请求} \xrightarrow{\text{路由层}} \begin{cases} \text{端侧（隐私/低延迟/兜底）} \\ \text{云端（能力/重载）} \end{cases} \xrightarrow{\text{级联 + 回填}} \text{响应} 请求路由层​{端侧（隐私/低延迟/兜底）云端（能力/重载）​级联 + 回填​响应

核心创新点在路由层的分流决策与级联推理闭环：端侧先答、置信度低升级云端、结果回填缓存——这是端云协同区别于"纯云端"的灵魂。

  • 依赖：vllm、llama.cpp/rknn-llm、FastAPI、redis、Prometheus + OpenTelemetry。
