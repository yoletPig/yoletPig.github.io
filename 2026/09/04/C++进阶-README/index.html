C++ 进阶：从会写到写快——构建、模板深水区、SIMD、无锁、协程与端侧实战

面向：已读完本仓库《C++》系列全部 13 章（到并发编程与实战项目）、Python 为主语言 C++ 为次、目标是端侧/推理工程的读者。RKNN runtime、昇腾 CANN、llama.cpp、PyTorch C++ 扩展全是 C++ 项目，这个系列补上参与这些项目所需的工程进阶：构建系统、模板深水区、SIMD、无锁、协程、与 Python 互操作、端侧约束下的 C++，最后一章用 ~700 行写一个高性能 JSON 解析器收尾。

学习路径

篇 主题 你将学会
01-CMake与工程构建 target 中心思想、find_package/FetchContent、安装导出 把散装 cpp 文件组织成能被人用的库
02-模板深水区 SFINAE、void_t、if constexpr、变参模板、concepts 读懂推理引擎源码里的模板魔法
03-SIMD与向量化 AVX2 intrinsics、对齐、自动向量化、跨平台派发 用一条指令处理 8 个 float
04-内存模型与原子操作进阶 六种 memory_order、happens-before、ABA、伪共享 知道每处原子操作"为什么是这个序"
05-无锁数据结构 SPSC 环形队列、CAS 风暴、Hazard Pointer、RCU 亲手写无锁队列，也学会克制
06-性能工程与代码优化 编译器优化验证、SoA、variant 分派、arena、perf 用数据驱动的方式把代码写快
07-C++20-23现代特性 ranges、span、expected、format、modules 现状 该用的新特性用对，不该追的别追
08-协程 co_await/promise_type、最小 generator、异步调度 把回调地狱写成顺序代码
09-与Python互操作 pybind11、numpy 零拷贝、GIL、scikit-build-core 给 Python 包写 C++ 扩展
10-端侧与嵌入式C++ -fno-exceptions、静态内存规划、交叉编译、RKNN 在 MB 级内存里写可靠的 C++
11-C++实现经典设计模式精选 Meyers 单例、CRTP、pimpl、scope guard 用 C++ 的方式用模式，而不是 Java 的方式
12-实战-用C++写一个高性能JSON解析器 递归下降、三回合优化、模糊测试 综合全系列，产出能测、能跑、能复盘的项目

阶段划分

  1. 工程化（01）：构建系统是参与任何 C++ 项目的入场券，先解决"怎么组织代码"。
  2. 语言深水区（02、07、08）：模板、新特性、协程。推理引擎源码里到处是这些。
  3. 性能（03–06）：SIMD → 内存序 → 无锁 → 性能工程。每一章都有实测数字。
  4. 实战（09–12）：Python 互操作、端侧、设计模式、综合项目。

与本仓库其他方向的衔接

  • 《C++》系列 12（并发编程）是本系列 04/05 的前置：mutex/atomic 的基本用法在那边，这里讲"为什么是这些内存序"和"无锁什么时候值得"。
  • 《计算机系统与网络》03（缓存层级）、05（浮点）是 03/06 章的理论基础：SIMD 和数据布局优化的收益都来自缓存与流水线。
  • 《Linux 性能工程》03/10 提供观测方法：perf/火焰图怎么用在那边讲，这里演示"perf 火焰图读 C++ 栈"。
  • 《模型性能优化》Stage 3（CUDA）是延伸方向：03 章讲清 CPU SIMD 与 GPU 的分工边界；10 章 RKNN 骨架衔接 Stage 4（NPU）。
  • llama.cpp / PyTorch C++ 扩展是实战目标：09 章（扩展 Python）、06 章（llama.cpp 同款 arena 思想）、08 章（llama.cpp server 的异步模型）。
  • 《设计模式与架构》系列讲通用模式，本系列 11 章只讲"C++ 特有实现"：magic statics、CRTP、pimpl。
  • 《测试》系列 09/11：12 章的模糊测试、09 章的扩展模块测试分别与之衔接。

约定

  • 全系列按 C20 为主、C23 顺带 编写；少数 C23 特性（std::expected、std::format）需要 g 13+，文中均标注了替代方案。
  • 验证环境：g++ 11.4.0 / CMake 3.22 / Ubuntu 22.04 (WSL2) / x86-64（i5-12600K）。所有可运行示例均实际编译运行，文中"输出"为真实运行结果；标注"经验做法"的段落是工程实践中反复验证过的做法，不是标准条文。
  • 编译命令统一 g++ -std=c++20 -O2 -Wall -Wextra（协程章加 -fcoroutines，并发章加 -pthread）。
  • 基准数据都是单机实测，绝对值会因机器而异，请关注相对倍数和测量方法，而不是照抄毫秒数。
