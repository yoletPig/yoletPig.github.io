08 - Actor-Critic

本篇目标

读完本篇，你应该能做到：

  1. 把 04 章"MC vs TD"的偏差-方差之争接到策略梯度上，说清 REINFORCE（纯 MC）差在哪、Critic 补什么。
  2. 推导 GAE（广义优势估计）——把 07 章的基线、04 章的 TD 误差、资格迹统一成一个公式；理解 λ\lambdaλ 的物理含义。
  3. 实现共享主干的 A2C（CartPole，实测 ep700 评估满分），并复现一个真实调参事故：MSE 价值损失通过共享主干摧毁策略，换 Huber 后梯度范数从 18–40 降到 1–4。
  4. 讲清 A3C 的异步思想，以及它为什么被同步版本（A2C/PPO）取代——并行范式之争的工程逻辑。

1. 偏差-方差权衡的延续：REINFORCE 缺的那块

07 章结尾的问题：REINFORCE 用实测回报 GtG_tGt​ 当权重——无偏但方差巨大（数据用一次、整条轨迹的随机性全算进去）。04 章给过答案的方向：自举（用 r+γV(s′)r + \gamma V(s')r+γV(s′) 当目标）以引入少量偏差为代价砍掉大量方差。

把这两个拼起来就是 Actor-Critic 的设计图（Sutton & Barto, 2nd ed., §13.5、§13.7）：

权重信号 偏差 方差 数据要求
REINFORCE GtG_tGt​（实测回报） 无 高 必须 episodic、数据用一次
Actor-Critic A(st,at)≈δtA(s_t, a_t) \approx \delta_tA(st​,at​)≈δt​ 或 GAE 有（来自 VVV 的误差） 低 可在线增量、可用部分轨迹

其中优势函数 Aπ(s,a)=Qπ(s,a)−Vπ(s)A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)Aπ(s,a)=Qπ(s,a)−Vπ(s) 就是 07 章"基线"的函数近似版：V(s)V(s)V(s) 是基线，Q−VQ-VQ−V 是去均值后的信号。它回答的问题是"这个动作比按当前策略平均表现好多少"——比原始回报 GtG_tGt​ 的信噪比高得多（GtG_tGt​ 里混着"状态本身好不好"的成分，优势把这部分减掉了）。

实现上优势几乎从不用 QQQ 网络算（另养一个 QQQ 网络成本翻倍），而是用 TD 误差：

δt=rt+1+γV(st+1)−V(st)\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t) δt​=rt+1​+γV(st+1​)−V(st​)

可以证明（Sutton & Barto, 2nd ed., §13.5）E[δt∣st,at]=Aπ(st,at)\mathbb{E}[\delta_t | s_t, a_t] = A^\pi(s_t,a_t)E[δt​∣st​,at​]=Aπ(st​,at​)——TD 误差是优势的无偏单样本估计。一个 VVV 网络，既当基线又当 critic，还顺带解决了"continuing 任务没有回合终点"的问题。这就是"值函数线的资产被策略梯度线收购"的全过程。

2. GAE：把光谱参数化

2.1 推导

07 章说过策略梯度信号可以用任意基线；§1 说 TD 误差 δt\delta_tδt​ 是单步优势估计（偏差来自 VVV，方差只有一步）。λ\lambdaλ-优势把 kkk 步优势估计指数加权混合（Schulman et al., “High-Dimensional Continuous Control Using Generalized Advantage Estimation”, arXiv:1506.02438, ICLR 2016）。

先定义 kkk 步优势（kkk 步 TD 的策略梯度版，04 章 G(n)G^{(n)}G(n) 的亲戚）：

A^t(1)=δt=rt+γV(st+1)−V(st)（1 步：偏差大方差小）\hat{A}_t^{(1)} = \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) \quad\text{（1 步：偏差大方差小）} A^t(1)​=δt​=rt​+γV(st+1​)−V(st​)（1 步：偏差大方差小）

A^t(2)=rt+γrt+1+γ2V(st+2)−V(st)=δt+γδt+1\hat{A}_t^{(2)} = r_t + \gamma r_{t+1} + \gamma^2 V(s_{t+2}) - V(s_t) = \delta_t + \gamma\delta_{t+1} A^t(2)​=rt​+γrt+1​+γ2V(st+2​)−V(st​)=δt​+γδt+1​

A^t(k)=∑l=0k−1γlδt+l\hat{A}_t^{(k)} = \sum_{l=0}^{k-1} \gamma^l \delta_{t+l} A^t(k)​=l=0∑k−1​γlδt+l​

A^t(∞)=Gt−V(st)（MC：无偏差差）\hat{A}_t^{(\infty)} = G_t - V(s_t) \quad\text{（MC：无偏差差）} A^t(∞)​=Gt​−V(st​)（MC：无偏差差）

GAE = 对这些估计做指数加权平均，权重 ∝λk−1\propto \lambda^{k-1}∝λk−1：

A^tGAE(γ,λ)=(1−λ)∑k=1∞λk−1A^t(k)\hat{A}_t^{\text{GAE}(\gamma,\lambda)} = (1-\lambda)\sum_{k=1}^{\infty} \lambda^{k-1} \hat{A}_t^{(k)} A^tGAE(γ,λ)​=(1−λ)k=1∑∞​λk−1A^t(k)​

把 A^(k)=∑lγlδt+l\hat{A}^{(k)} = \sum_l \gamma^l \delta_{t+l}A^(k)=∑l​γlδt+l​ 代入交换求和顺序，权重 (1−λ)λk−1(1-\lambda)\lambda^{k-1}(1−λ)λk−1 对 kkk 求和恰好归一，得到极简形式：

A^tGAE=∑l=0∞(γλ)lδt+l=δt+γλA^t+1GAE\boxed{\hat{A}_t^{\text{GAE}} = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l} = \delta_t + \gamma\lambda \hat{A}_{t+1}^{\text{GAE}}} A^tGAE​=l=0∑∞​(γλ)lδt+l​=δt​+γλA^t+1GAE​​

实现就是一行倒序递推：gae = delta[t] + gamma * lam * gae。两个端点：

  • λ=0\lambda = 0λ=0：A^t=δt\hat A_t = \delta_tA^t​=δt​，纯一步 TD 优势（方差最小、偏差全靠 VVV 的准确性）；
  • λ=1\lambda = 1λ=1：A^t=Gt−V(st)\hat A_t = G_t - V(s_t)A^t​=Gt​−V(st​)，MC 减基线（无偏、方差回到 REINFORCE 水平）。

λ\lambdaλ 就是 04 章 n-step 光谱的"资格迹参数化"——07 章结尾说"GAE 是 λ\lambdaλ 的现代继承者"，指的就是这个公式。工程甜点：λ∈[0.9,0.97]\lambda \in [0.9, 0.97]λ∈[0.9,0.97]，09 章 PPO 默认 0.95。

2.2 λ 消融实验（真实数据）

在 §4 的实现上只改 λ\lambdaλ，各跑 500 回合（seed=0，训练期回报的 50 回合窗口均值）：

λ\lambdaλ 含义 最后 50 回合训练均值
0.0 纯 TD(0) 残差 δt\delta_tδt​ 9.3（不学习）
0.9 偏自举 217.7
0.95 默认值 175.8
1.0 MC − 基线 133.9

读数：λ=0\lambda=0λ=0 完全不学习——单步 TD 优势的偏差（初期 VVV 极不准）把策略梯度信号毁掉了，信用分配被压得太局部；λ≥0.9\lambda \ge 0.9λ≥0.9 才有足够的视野；λ=1\lambda=1λ=1 反而略慢（方差回归）。这不是普适结论（不同任务最优 λ\lambdaλ 会移动），但"λ=0\lambda=0λ=0 崩、中间甜点区宽"的形状是普遍的。经验做法：永远不要从 λ=0\lambda=0λ=0 调起；从 0.95 出发，先调 lr 再动 λ\lambdaλ。

3. A2C 架构

3.1 网络：共享主干还是分开

A2C（Advantage Actor-Critic，Mnih et al. 2016 的同步版）一个网络两条头：

共享主干省一半算力、让两条头共享特征；代价是两条头的梯度互相干扰（§5 的真实事故）。任务更复杂时常用分离网络（或 PPO 实现里的 share_encoder 开关）。

3.2 损失函数三项

L=−E[A^tlog⁡πθ(at∣st)]⏟策略损失（07 章的负号进 loss）+cv(R^t−Vϕ(st))2⏟价值损失：回归 GAE 的目标−ceH[πθ(⋅∣st)]⏟熵奖励（鼓励探索）L = \underbrace{-\mathbb{E}\big[\hat{A}_t \log \pi_\theta(a_t|s_t)\big]}_{\text{策略损失（07 章的负号进 loss）}} + c_v \underbrace{\big(\hat{R}_t - V_\phi(s_t)\big)^2}_{\text{价值损失：回归 GAE 的目标}} - c_e \underbrace{H[\pi_\theta(\cdot|s_t)]}_{\text{熵奖励（鼓励探索）}} L=策略损失（07 章的负号进 loss）−E[A^t​logπθ​(at​∣st​)]​​+cv​价值损失：回归 GAE 的目标(R^t​−Vϕ​(st​))2​​−ce​熵奖励（鼓励探索）H[πθ​(⋅∣st​)]​​

三项各自的道理：

  • 策略损失就是 07 章的 REINFORCE 损失，权重从 GtG_tGt​ 换成 A^tGAE\hat A_t^{\text{GAE}}A^tGAE​；
  • 价值损失教 VVV 回归"优势校正后的回报" R^t=A^t+V(st)\hat R_t = \hat A_t + V(s_t)R^t​=A^t​+V(st​)（GAE 的配套 return，数学上 R^t\hat R_tR^t​ 是 λ\lambdaλ-return，Sutton & Barto, 2nd ed., §12.8 的 off-policy 版本同源）；cvc_vcv​ 一般 0.5；
  • 熵奖励防止策略过早塌缩成确定性（探索退场太早 = 02 章 ε 固定过小的策略梯度版）；cec_ece​ 一般 0.01。

5. 调参事故复盘：MSE 价值损失毁掉共享主干（真实数据）

本章实现过程中真实发生的事故，比任何"常见误区"都有说服力：

现象：初版用 MSELoss 算价值损失（其余全部同款超参），训练 600 回合评估分始终卡在 9–25（随机水平是 ~22），梯度范数（裁剪前）长期在 6–20。

诊断：CartPole 的 return 量级 10–500，初期 V(s)≈0V(s)\approx 0V(s)≈0，MSE 损失 (0−G)2(0 - G)^2(0−G)2 量级几百且梯度极大——价值头的巨大梯度穿过共享主干，把策略头赖以工作的特征每个更新都拽一次。策略相当于"在地震中学习"，熵塌缩后锁死在坏策略上。换 Huber（smooth_l1） 后：

教训（Sutton & Barto §13.5 未强调、但工程上致命）：共享主干时，两条头的梯度尺度必须匹配。价值目标量级大 → 用 Huber 或对 return 做归一化；或者干脆分离网络；或者给价值头单独的低学习率。排查顺序（经验做法）：不收敛 + 梯度范数异常大 → 先看哪一项损失的量级失控，再谈调 lr。

6. A3C：异步思想与它的退场

A3C（Asynchronous Advantage Actor-Critic，Mnih et al., ICML 2016）的核心不是算法而是并行架构：16 个 worker 线程各自持有环境副本与网络副本，独立采样、独立算梯度、异步地把梯度推给全局共享参数；每个 worker 周期性拉取最新参数继续采样。

两个贡献：

  1. 数据多样性：16 个 worker 的环境状态各不相同（有的在开局、有的在深处），等效于 16 个并行的探索线，天然打破时间相关性（06 章经验回放在 on-policy 语境下的替代品）；
  2. lock-free 更新：不等慢 worker，GPU/CPU 永不空转——2016 年算力背景下的务实设计。

为什么被 A2C/PPO 的同步版本取代（OpenAI 的对比实验见 OpenAI Baselines 博客 2017, “A2C is A3C without asynchrony”）：

  • 陈旧梯度（stale gradients）：worker 更新期间全局参数已被别人改过，推上去的梯度基于旧参数——等效于不可控的"过去策略"数据混入，on-policy 性质被悄悄破坏；
  • GPU 时代并行成本反转：异步多线程的意义在 CPU 集群；GPU 上批量同步计算反而更快。同步 A2C 用"8 个环境各采 5 步凑一批（batch=40）"达到同等多样性，实现简单、完全可复现；
  • 复现性差：异步时序不可固定种子，bug 无法重放。

经验做法：现代实现里"异步"移到了环境侧（向量化环境并行采样，12 章），"同步批量更新"留在学习侧。记住分工：采样并行化解决的是吞吐，梯度同步化解决的是正确性与可复现。

7. 常见误区

  1. 价值损失用 MSE 且量级失控（§5 全文）。症状优先级最高的排查项：训练完全不学 + 裁剪前梯度范数 > 10。先检查价值目标的量级，再检查共享主干。
  2. λ\lambdaλ 从 0 开始调。§2.2 实测 λ=0\lambda=0λ=0 直接不学习。GAE 的 λ\lambdaλ 永远从 0.95 起步——它不是"探索率"那种可大幅调节的旋钮，而是"信用分配视野"的微调。
  3. 截断（truncation）时把 bootstrap 清零。整回合 rollout 在 truncation（时间上限）结束时 next_v 应该用 V(sT+1)V(s_{T+1})V(sT+1​) 而不是 0——与 05/06 章同一个 bug 的 A2C 版。CartPole 500 步上限的场景下症状：策略在 480 步附近开始送死。
  4. 优势归一化不分场合。 回合内归一化（本实现）在整回合几百步时是稳态增益；但固定 T=8 的小 rollout 上，把 8 个数强行归一到 ±1 会把纯噪声放大成满幅信号（§4 教学版之所以用整回合就是这个原因）。经验做法：归一化的样本规模至少几十，且记住它只是稳定器不是算法部件。
  5. 熵系数设 0 之后困惑"为什么突然不探索了"。 策略梯度没有外生探索机制（对比 DQN 的 ε-greedy），策略分布本身的熵是唯一探索来源。训练中期评估分骤降，先查熵曲线是否塌缩。

本篇小结

  • Actor-Critic = 策略梯度 + 学出来的基线：δt\delta_tδt​ 是优势的无偏单样本估计，一个 VVV 网络同时解决基线、自举、continuing 三个问题。
  • GAE：A^t=∑(γλ)lδt+l\hat A_t = \sum (\gamma\lambda)^l \delta_{t+l}A^t​=∑(γλ)lδt+l​，一行倒序递推；λ\lambdaλ 参数化偏差-方差光谱，实测 λ=0\lambda=0λ=0 完全不学（9.3）、0.9–1.0 才可用。
  • A2C 三项损失：策略（GAE 加权 log-prob）+ 价值（Huber 回归 λ-return）− 熵奖励；共享主干时两头的梯度尺度必须匹配（真实事故：MSE 价值损失让 eval 卡死 ≤25，Huber 后 ep700 满分）。
  • A3C 的异步范式被同步版本取代：陈旧梯度破坏 on-policy 性质、不可复现；现代分工是"环境并行 + 学习同步"。
  • 08 章的 A2C 离 SOTA 还差最后一块：策略更新没有"步长控制"，一次大更新就能毁掉策略——09 章 PPO 的 clip 登场。

  1. 把 §4 的价值损失换回 MSE 复现 §5 的事故：打印每 50 回合的 v_loss.item()、梯度范数与 eval，画出"价值梯度淹没策略梯度"的证据曲线。
  2. 把 rollout 从整回合改成固定 T=8（回合中断时保留跨 rollout 的中间量：用 delta 递推需要 A^t+1\hat A_{t+1}A^t+1​，试着正确实现跨段 GAE），对比整回合版的收敛速度——体会 12 章向量化环境存在的理由。
  3. 实现 λ\lambdaλ-return 的显式版本（R^t=∑(γλ)kGt(k+1)\hat R_t = \sum (\gamma\lambda)^k G_{t}^{(k+1)}R^t​=∑(γλ)kGt(k+1)​ 的混合式）并验证它与 adv + vals 数值一致（提示：两者在数学上恒等，这是 GAE 论文的式 (16)）。
  4. 给策略头加"熵塌缩监控"：每 100 回合打印 dist.entropy().mean().item()，观察它与评估分回落（ep 500–600）的对应关系。
  5. 思考题：DQN 的目标网络"冻结目标 CCC 步"与 PPO 的"同一批数据只更新几个 epoch"都在控制"目标漂移速度"。从 09 章 TRPO 的"信任域"视角，说明这两者是同一思想在不同部件（值函数/策略）上的实例化。
