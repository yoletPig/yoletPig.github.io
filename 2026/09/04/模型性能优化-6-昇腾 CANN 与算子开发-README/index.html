Stage 6 教程索引：昇腾 CANN 与 Ascend C 算子开发

本目录是《学习计划》的配套教程，按周组织。每篇教程遵循统一框架：第一性原理与数学本质 → 系统架构与数据流 → 工程权衡与失效模式 → 实现与验证（可运行代码/命令）→ MVP 交付指导 → 延伸思考题（含解析）。

⚠️ 这是全计划最难的八周。策略是「推理先行、开发殿后」：前 4 周在你手上的 310P/Atlas 200I 上建立部署手感，后 4 周才碰云上 910B 与 Ascend C 算子开发。昇腾生态文档不如 CUDA 完善，遇到对不上的地方一律以昇腾社区官方文档与 ascend/samples 实际代码为准，本教程给的是方法与骨架。

文档 对应周次 核心问题
第 1 周：昇腾生态全景与 CANN 架构 第 1 周 达芬奇三单元各管什么？CANN 与 CUDA 生态怎么逐项对照？
第 2 周：ATC 模型转换与 ACL 离线推理 第 2 周 PyTorch→ONNX→OM 的完整转换链？ACL 推理八步流程？
第 3 周：MindIE 大模型推理服务 第 3 周 昇腾版 vLLM 的概念怎么对照？7B 怎么在昇腾上压测？
第 4 周：torch_npu 训练迁移与精度排查 第 4 周 CUDA 脚本怎么搬到 910B？精度对不齐怎么排查？
第 5-6 周：Ascend C 算子开发基础与实践一 第 5-6 周 Kernel/Tiling/流水怎么组织？fused Add+RMSNorm 怎么写？
第 7-8 周：Ascend C 进阶算子与接入模型复盘 第 7-8 周 带归约的算子怎么设计？算子怎么接进真实模型？

贯穿全阶段的一条主线

模型→ATC 转换OM→ACL/MindIE推理自定义计算→Ascend C高性能算子\text{模型} \xrightarrow{\text{ATC 转换}} \text{OM} \xrightarrow{\text{ACL/MindIE}} \text{推理} \qquad\qquad \text{自定义计算} \xrightarrow{\text{Ascend C}} \text{高性能算子} 模型ATC 转换​OMACL/MindIE​推理自定义计算Ascend C​高性能算子

前半程（第 1-4 周）走通"用昇腾跑模型"（转换 + 推理 + 服务 + 迁移）；后半程（第 5-8 周）进阶到"给昇腾写算子"。前者是后者的地基——不先理解昇腾怎么跑模型，写不出对路的算子。

前置依赖

  • 本地 310P/Atlas 200I（推理）+ 云上 910B（训练/算子开发）；
  • Stage 3 的 CUDA fused RMSNorm（第 5-6 周要用 Ascend C 重写，双平台对照）；
  • Stage 5 的 vLLM 知识（第 3 周与 MindIE 逐项对照）。
