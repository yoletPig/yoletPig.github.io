04 - 蒙特卡洛与时序差分

本篇目标

读完本篇，你应该能做到：

  1. 掌握两种"从数据学值函数"的原型方法：MC（等一整条轨迹算总账）与 TD(0)（每一步就自举更新），并写出两者的更新式。
  2. 说清偏差 vs 方差这对贯穿全系列的权衡：MC 无偏高方差，TD 有偏低方差——以及它如何一路延伸到 n-step、资格迹、GAE（08 章）。
  3. 熟练使用 TD 误差 δt\delta_tδt​——它在 05 章（Q-learning）、08 章（优势）、09 章（PPO 的 GAE）里反复出现。
  4. 在 5 状态随机游走上完成 MC vs TD 收敛实验（100 次运行平均），亲眼看到"TD 早期更快、MC 尾巴更干净"。

03 章 DP 的局限是"需要环境模型"。MC 与 TD 共同迈出那一步：不需要 PPP，直接从经验中学习值函数（model-free prediction，Sutton & Barto, 2nd ed., 第 5–6 章）。它们的全部区别只在一件事上：用什么当"真值"去修正当前估计。

1. 蒙特卡洛：等回合结束算总账

思想：值函数的定义是回报的期望。那就按定义来——采样完整回合，实测一次回报 GtG_tGt​，用它更新估计（Sutton & Barto, 2nd ed., §5.1）：

V(st)←V(st)+α[Gt−V(st)]V(s_t) \leftarrow V(s_t) + \alpha\left[G_t - V(s_t)\right] V(st​)←V(st​)+α[Gt​−V(st​)]

Gt−V(st)G_t - V(s_t)Gt​−V(st​) 叫 MC 误差：实测回报与当前估计之差。这是最朴素的"样本均值"思想。

1.1 首访 vs 每次访问

一个回合里同一状态可能出现多次。两种记账口径（Sutton & Barto, 2nd ed., §5.1）：

  • 首次访问 MC：每回合中每个状态只用第一次出现时的回报更新；
  • 每次访问 MC：每次出现都更新。

两者都收敛到 VπV^\piVπ（首访 MC 收敛证明简单：独立同分布样本的均值；每次访问 MC 收敛到同一极限但形式更绕，Singh & Sutton, 1996）。实现上首访版用"倒序算 GtG_tGt​ + 已访问集合"最省事。

1.2 增量式均值：每步 O(1)O(1)O(1) 更新

均值的标准式 Qn=1n∑i=1nriQ_n = \frac{1}{n}\sum_{i=1}^n r_iQn​=n1​∑i=1n​ri​ 需要存全部历史；展开重排得到增量式（Sutton & Barto, 2nd ed., §2.4，02 章已用过）：

μn=μn−1+1n(rn−μn−1)\mu_n = \mu_{n-1} + \frac{1}{n}(r_n - \mu_{n-1}) μn​=μn−1​+n1​(rn​−μn−1​)

一般化 1n→α\frac{1}{n} \to \alphan1​→α（固定步长）就是所有 RL 更新的通式 V←V+α(目标−V)V \leftarrow V + \alpha(\text{目标} - V)V←V+α(目标−V)。"目标 − 当前估计"这个残差结构在 RL 里无处不在：MC 误差、TD 误差、优势函数、DQN 的 Huber 损失、PPO 的 ratio 目标全是它的变体。

2. TD(0)：每一步都学习

2.1 更新式与"自举"

MC 必须等回合结束才知道 GtG_tGt​。时序差分（Temporal-Difference，Sutton, 1988, Machine Learning；Sutton & Barto, 2nd ed., §6.1–6.2）说：用"立即奖励 + 下一状态的当前估计"当目标：

V(st)←V(st)+α[ rt+1+γV(st+1)−V(st) ]V(s_t) \leftarrow V(s_t) + \alpha\left[\,r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\,\right] V(st​)←V(st​)+α[rt+1​+γV(st+1​)−V(st​)]

其中：

δt=rt+1+γV(st+1)−V(st)（TD 误差）\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t) \quad \text{（TD 误差）} δt​=rt+1​+γV(st+1​)−V(st​)（TD 误差）

关键性质：rt+1+γV(st+1)r_{t+1} + \gamma V(s_{t+1})rt+1​+γV(st+1​) 是 Vπ(st)V^\pi(s_t)Vπ(st​) 的有偏估计（V(st+1)V(s_{t+1})V(st+1​) 自己就是个近似值），但方差小得多——只涉及一步随机性（一个转移），而 GtG_tGt​ 涉及整条轨迹所有随机性（Sutton & Barto, 2nd ed., §6.2 末尾的讨论；Guez et al., 2018 给出了系统分析）。用估计值更新估计值这件事叫自举（bootstrapping）——名字借自统计学，含义就是"自己拉自己的鞋带把自己提起来"。

2.2 TD 误差：预测的"逐期修正量"

对 TD 误差求和有一个漂亮的恒等式（gamma=1 无折扣时最直观）：

Gt−V(st)=δt+γδt+1+γ2δt+2+⋯+γT−t−1δT−1G_t - V(s_t) = \delta_t + \gamma\delta_{t+1} + \gamma^2\delta_{t+2} + \cdots + \gamma^{T-t-1}\delta_{T-1} Gt​−V(st​)=δt​+γδt+1​+γ2δt+2​+⋯+γT−t−1δT−1​

即 MC 误差 = 整条轨迹 TD 误差的折扣和（Sutton & Barto, 2nd ed., 式 6.5）。这说明 MC 与 TD 不是两个世界，而是同一条光谱的两个端点：MC = 用全部未来的 TD 误差修正一次，TD(0) = 每一步只修正一步。n-step 方法（§4）就是中间的任意切点。08 章 GAE 的 λ\lambdaλ 参数会把这个光谱参数化。

3.1 实验设定

4. n-step 与资格迹：光谱的参数化

4.1 n-step TD

把"1 步自举"推广成"n 步自举"（Sutton & Barto, 2nd ed., §7.1）：

Gt(n)=rt+1+γrt+2+⋯+γn−1rt+n+γnV(st+n)G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n}) Gt(n)​=rt+1​+γrt+2​+⋯+γn−1rt+n​+γnV(st+n​)

V(st)←V(st)+α[Gt(n)−V(st)]V(s_t) \leftarrow V(s_t) + \alpha\left[G_t^{(n)} - V(s_t)\right] V(st​)←V(st​)+α[Gt(n)​−V(st​)]

n=1n=1n=1 就是 TD(0)，n=∞n=\inftyn=∞（到回合尾）就是 MC。n 是偏差-方差旋钮：n 越大越接近 MC（偏差小、方差大），越小越接近 TD（偏差大、方差小）。经验上 n∈[3,8]n \in [3, 8]n∈[3,8] 常常是甜点区——偏差刚引入一点，方差已经砍掉一大截（“经验做法”，具体最优值随任务变）。

4.2 资格迹 TD(λ\lambdaλ)（概念）

n-step 有个工程缺陷：要同时维护 n 个估计、且更新 Gt(n)G_t^{(n)}Gt(n)​ 需要往后看 n 步。**资格迹（eligibility traces）**用"向前看"替代"向后看"（Sutton & Barto, 2nd ed., §7.2–7.5；Sutton 1988 原始提出）：

  • 每个状态维护一个迹值 e(s)∈[0,1]e(s) \in [0,1]e(s)∈[0,1]：被访问时 e(s)←1e(s) \leftarrow 1e(s)←1，每步衰减 e(s)←γλe(s)e(s) \leftarrow \gamma\lambda e(s)e(s)←γλe(s)；
  • 每步收到 δt\delta_tδt​ 后，对所有状态按 V(s)←V(s)+α δt e(s)V(s) \leftarrow V(s) + \alpha\, \delta_t\, e(s)V(s)←V(s)+αδt​e(s) 一次更新。

λ∈[0,1]\lambda \in [0,1]λ∈[0,1] 是指数加权参数：λ=0\lambda=0λ=0 退化为 TD(0)，λ→1\lambda \to 1λ→1 近似 MC（但在线、增量，且对 episodic/continuing 都适用）。“最近访问的状态责任更大”——迹就是信用分配的指数衰减记忆。深度 RL 里 λ\lambdaλ 以另一种面貌出现：08 章 GAE 的 λ\lambdaλ 与资格迹在数学上等价（对优势估计做指数加权），09 章 PPO 默认 λ=0.95\lambda=0.95λ=0.95 就是它的现代继承者。

5. 常见误区

  1. 用 MC 处理没有终止的任务。 continuing 任务没有"回合结束"，GtG_tGt​ 无穷长——MC 直接不可用。症状：跑了很久每个状态的 VVV 还在慢速漂移，因为"总账"永远没算完。TD 无此限制（这也是 TD 在工程上占主导的原因之一）。
  2. 自举 + 函数近似 + off-policy 三件套直接叠加（Deadly Triad，Sutton & Barto, 2nd ed., §11.3 的命名）。本章任务里三者最多出现一件，所以 TD(0) 收敛良好；06 章 DQN 里三者全齐，不稳定性就成为默认现象。现在记住结论即可：见到 off-policy TD + 函数近似，先怀疑发散。
  3. 首访 MC 的实现顺序错误。 必须倒序先算 GtG_tGt​ 再判"首访"；正序遍历时你拿不到 GtG_tGt​（不知道未来），很多人在这里直接用了 rtr_trt​ 当 GtG_tGt​——更新方向全错。症状：值收敛到的不是 VπV^\piVπ 而是某个"即时奖励场"。
  4. α\alphaα 固定不衰减，然后困惑"为什么误差停在 0.05 不动了"。 本章 §3.2 结论 3 就是这个现象的实测。表格法可以让 αn=1/N(s)\alpha_n = 1/N(s)αn​=1/N(s)（严格均值）归零；函数近似/深度 RL 里固定小步长 + 噪声地板是常态，评估指标要允许噪声带。
  5. TD 的 target 忘记"终止状态值为 0"。 target = r + gamma * V[next] 在 st+1s_{t+1}st+1​ 是终止状态时应为 target = r。本章代码用 0.0 if ns in (0,6) else V[ns-1] 处理；DQN 里它变成 (1 - terminated) 乘法因子（06 章）。这是 RL 实现出现率第一的 bug。

本篇小结

  • MC 按定义学：用实测回报 GtG_tGt​ 更新，无偏但高方差、必须 episodic；TD 自举：用 r+γV(s′)r + \gamma V(s')r+γV(s′) 更新，有偏但低方差、在线增量。两者是同一条光谱的端点。
  • 增量式均值 μn=μn−1+1n(rn−μn−1)\mu_n = \mu_{n-1} + \frac{1}{n}(r_n - \mu_{n-1})μn​=μn−1​+n1​(rn​−μn−1​) 及其 α\alphaα 推广是所有 RL 更新的通用外壳："目标 − 估计"残差结构贯穿全系列。
  • TD 误差 δt\delta_tδt​ 是基本货币：MC 误差 = 折扣 TD 误差之和；05/08/09 章的优势函数、GAE 全部建立在 δ\deltaδ 上。
  • n-step 与资格迹 TD(λ\lambdaλ) 把光谱参数化；工程甜点在中间（n=3–8 或 λ=0.9–0.97\lambda=0.9\text{–}0.97λ=0.9–0.97）。
  • 实验结论（100 运行平均）：α=0.1\alpha=0.1α=0.1 时 TD 每个阶段都快于 MC 且稳态残差更低（0.055 vs 0.090）；固定步长存在噪声地板。
  • 下一章把"值函数怎么学"变成"策略怎么改进"：Q-learning 与 SARSA。

练习

  1. 把 §3.1 的 mc_first_visit 改成每次访问 MC（去掉 visited 集合），100 运行平均对比两者收敛曲线。理论上两者极限相同，你观察到差异了吗？在哪个阶段？
  2. 实现 n-step TD（n=1, 2, 4, 8, 完整回合）在随机游走上的版本，100 运行平均画 RMS 曲线族。验证"n 增大 → 早期更慢（偏差小但方差大）"还是相反，并解释。
  3. α\alphaα 衰减实验：MC 用 αn=1/N(s)\alpha_n = 1/N(s)αn​=1/N(s)（每个状态的访问计数分之一），验证误差能持续降到接近 0；对比固定 α=0.01\alpha=0.01α=0.01 的噪声地板。
