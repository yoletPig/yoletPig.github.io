01 - 强化学习是什么与 MDP

本篇目标

读完本篇，你应该能做到：

  1. 说清强化学习与监督学习的两条本质区别：数据分布由策略自己决定、奖励延迟且稀疏——以及这两条如何决定了 RL 的所有工程难点。
  2. 画出 agent-environment 交互回路，并把 MDP 五元组 (S,A,P,R,γ)(S, A, P, R, \gamma)(S,A,P,R,γ) 与真实任务（CartPole、推荐系统、LLM 对话）一一对应。
  3. 手算折扣回报 GtG_tGt​，理解 γ\gammaγ 的两重身份：数值上的收敛保险 + 认知上的"远视程度"。
  4. 在"值函数 / 策略 / 模型"三类方法的谱系图上，定位本系列后续每一章的算法——以及 RLHF/DPO（库内 Stage 6/7）。

1. 与监督学习的本质区别

监督学习你已经很熟：给定固定数据集 {(xi,yi)}\{(x_i, y_i)\}{(xi​,yi​)}，最小化 Ex∼D[L(f(x),y)]\mathbb{E}_{x \sim D}[L(f(x), y)]Ex∼D​[L(f(x),y)]。强化学习不同在哪里？不是"没有标签"这么简单，而是三条结构性区别（Sutton & Barto, 2nd ed., §1.1、§3.1）：

区别一：数据分布由你自己决定。 监督学习的训练集是给定的、静态的；RL 中 agent 的每个动作决定了下一步看到什么状态。你把车开向悬崖，接下来看到的就是悬崖边的画面——数据分布 ρπ(s)\rho_\pi(s)ρπ​(s) 依赖策略 π\piπ 本身。这带来一个鸡生蛋问题：想学好策略需要好数据，想采到好数据需要好策略。深度 RL 大部分"不收敛"的病根都在这里（06 章经验回放、09 章 PPO 的 ratio 裁剪，全是围绕这一条的补救）。

区别二：奖励延迟。 监督学习每条样本立刻有 yiy_iyi​；RL 的奖励可能稀疏且滞后——下棋只有终局有输赢，LLM 生成 500 个 token 后才知道对错。于是必须解决信用分配（credit assignment）：终局赢了，前面哪几步是关键好棋？（04 章 TD、07 章策略梯度都是对这一条的机制设计。）

区别三：评价方式是"试错"而非"对错"。 监督学习告诉你正确答案；RL 只告诉你这个动作"得了多少分"，从不告诉你最优动作是什么。agent 必须自己探索（02 章整个主题）。

维度 监督学习 强化学习
数据 静态数据集，i.i.d. 采样 交互产生，分布随策略漂移
反馈 每样本的正确标签 标量奖励，可能延迟/稀疏
目标 拟合固定分布 最大化长期累积回报
难点根源 过拟合/泛化 探索-利用 + 信用分配 + 分布漂移
评价指标 loss / accuracy 回报（噪声极大，要多次评估取均值）

经验做法：监督学习里 loss 下降 ≈ 在进步；RL 里平均回报上升经常是假信号（一次幸运探索、熵太低后偶然走运），必须固定评估协议（如 10 个评估 episode 取均值、多随机种子）再下结论。这是从监督学习转 RL 最容易踩的坑。

2. Agent-Environment 交互回路

RL 的世界模型只有一张图（Sutton & Barto, 2nd ed., §3.1 图 3.1）：

每个时间步 ttt 发生两件事：

  1. Agent 观测状态 sts_tst​，按策略输出动作 at∼π(⋅∣st)a_t \sim \pi(\cdot|s_t)at​∼π(⋅∣st​)；
  2. 环境返回奖励 rt+1r_{t+1}rt+1​ 和新状态 st+1s_{t+1}st+1​。

注意一个细节：奖励记作 rt+1r_{t+1}rt+1​ 而不是 rtr_trt​，因为它是环境对 (st,at)(s_t, a_t)(st​,at​) 的响应结果，属于"未来"（Sutton & Barto §3.2 的记号约定）。这个记号会在后面反复出现：TD 误差写成 rt+1+γV(st+1)−V(st)r_{t+1} + \gamma V(s_{t+1}) - V(s_t)rt+1​+γV(st+1​)−V(st​)。

3. MDP 五元组

马尔可夫决策过程形式化定义为五元组 (S,A,P,R,γ)(S, A, P, R, \gamma)(S,A,P,R,γ)（Sutton & Barto, 2nd ed., §3.5）：

  • SSS：状态集合；
  • AAA：动作集合；
  • P(s′∣s,a)=Pr⁡{st+1=s′∣st=s,at=a}P(s'|s,a) = \Pr\{s_{t+1}=s' \mid s_t=s, a_t=a\}P(s′∣s,a)=Pr{st+1​=s′∣st​=s,at​=a}：转移函数，环境动力学；
  • R(s,a)=E[rt+1∣st=s,at=a]R(s,a) = \mathbb{E}[r_{t+1} \mid s_t=s, a_t=a]R(s,a)=E[rt+1​∣st​=s,at​=a]：奖励函数；
  • γ∈[0,1]\gamma \in [0,1]γ∈[0,1]：折扣因子。

马尔可夫性是整个体系的承重墙：sts_tst​ 包含了预测未来所需的全部信息，历史 s0,…,st−1s_0,\dots,s_{t-1}s0​,…,st−1​ 不再有用。两条推论：

  • 推论一：所有学习算法（Q 表、Q 网络、策略网络）都可以只以"当前状态"为输入，不必维护历史。真实任务不满足马尔可夫性时怎么办？加历史窗口（帧叠加，Atari 标配 4 帧）、RNN/Transformer 状态——但底层算法不变。
  • 推论二：部分可观测任务（POMDP）在工程上常被"状态堆叠"近似成 MDP 处理。经验做法：调试 RL 不收敛时，先问一句"我的观测是否遗漏了决策必需的信息"——这是排在前五的高频病因。

4. 回报与折扣因子

agent 的目标不是单步奖励，而是回报（return）——从当前时刻起的累积折扣奖励（Sutton & Barto, 2nd ed., §3.3）：

Gt=rt+1+γrt+2+γ2rt+3+⋯=∑k=0∞γkrt+k+1G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1} Gt​=rt+1​+γrt+2​+γ2rt+3​+⋯=k=0∑∞​γkrt+k+1​

回报满足一个对实现极其重要的递归：

Gt=rt+1+γGt+1G_t = r_{t+1} + \gamma G_{t+1} Gt​=rt+1​+γGt+1​

“未来的回报 = 立刻的奖励 + 折扣后的未来回报”——这一个式子就是贝尔曼方程的种子（03 章展开），也是所有 RL 算法自举（bootstrapping）的来源。

5. Episodic vs Continuing

回合制（episodic）任务：有明确的终止状态，交互分成一个个回合，回合之间互相独立。CartPole 杆倒了/撑过 500 步即终止；下棋终局即终止。终止状态（terminal state）的值恒为 0——这一点在实现里就是 done/terminated 标志的语义（06 章 DQN 的 target 计算里 (1 - done) 项就是它）。

连续型（continuing）任务：没有终点，理论上无限进行。股票交易、推荐系统、恒温控制。

工程上的灰色地带：很多任务是"名义 episodic、实际 continuing"——推荐系统一天的会话可以当回合，但用户第二天回来，跨回合信息仍在。经验做法：不确定时按 episodic 建模（简单），但注意把"人为截断"与"真实终止"区分开。gymnasium 1.x 的 terminated（环境真终止，value 应记 0）与 truncated（时间上限截断，value 不该记 0）两个返回值正是为此设计的——老代码里笼统的 done 是 06/09 章难以复现的常见原因。

三个维度是正交的：PPO 是 on-policy 的策略梯度法（无模型）；DQN 是 off-policy 的值函数法（无模型）；MuZero 是 model-based 的策略+值混合。看任何新论文先在这张图上定位，学习成本立减一半。

经验做法：本系列按"值函数线（04–06）→ 策略梯度线（07–09）"两条线推进，因为深度 RL 的两大门派（DeepMind 系 DQN、OpenAI 系 PPO）分别源于这两条线；10 章会看到 LLM 对齐几乎全部落在策略梯度线——这就是为什么 RLHF 用 PPO 而不用 DQN。

7. 常见误区

  1. 把 RL 当"没标签的监督学习"，直接拿单步奖励当标签回归。 单步奖励 rt+1r_{t+1}rt+1​ 不等于"这个动作的好坏"——一个好动作可能跟在坏状态后面得到低奖励。动作好坏要看回报（长视角），这正是 04 章 TD 误差、08 章优势函数存在的意义。
  2. 忽略数据分布漂移，用监督学习思维评估。 在"固定测试集"上评估 RL 策略没有意义——策略改了，访问到的状态分布就变了。评估必须用当前策略实际交互若干 episode 的平均回报。
  3. 以为 γ\gammaγ 只是个防发散的小数，随手取 0.99 就完事。 γ\gammaγ 直接定义了优化目标本身：0.9 和 0.999 的最优策略可能是完全不同的行为（短视 vs 远谋）。调参先定 γ\gammaγ，再谈学习率。
  4. 混淆 terminated 与 truncated（详见 §5）。把"到时间上限"也当成真实终止去 bootstrap=0，会系统性低估长活策略的值，表现为：训练后期回报不升反降、学出"故意送死"的行为（早死不亏）。
  5. 期望一步到位看懂收敛曲线。 监督学习曲线平滑，RL 曲线锯齿满地。单次运行甚至单次评估的波动是常态，结论必须来自多种子平均——这也是全系列代码固定种子的原因：先保证"可复现"，再谈"变好"。

本篇小结

  • RL 与监督学习的本质区别：数据分布由策略决定、奖励延迟稀疏、只给分数不给对错。由此派生 RL 三大难点：探索-利用、信用分配、分布漂移。
  • 交互回路：st→πat→环境rt+1,st+1s_t \xrightarrow{\pi} a_t \xrightarrow{环境} r_{t+1}, s_{t+1}st​π​at​环境​rt+1​,st+1​。LLM 生成 token = RL 的一步，这是 10 章的接口。
  • MDP 五元组 (S,A,P,R,γ)(S,A,P,R,\gamma)(S,A,P,R,γ)；马尔可夫性让算法只需当前状态。已知 P,RP,RP,R 走 DP（03），未知走无模型（04 起）。
  • 回报 Gt=∑γkrt+k+1G_t = \sum \gamma^k r_{t+k+1}Gt​=∑γkrt+k+1​，递归式 Gt=rt+1+γGt+1G_t = r_{t+1} + \gamma G_{t+1}Gt​=rt+1​+γGt+1​；γ\gammaγ 既是收敛保险也是视野旋钮（视野 ≈ 1/(1−γ)1/(1-\gamma)1/(1−γ)）。
  • episodic vs continuing，且必须区分真终止（terminated）与截断（truncated）。
  • 算法谱系三正交维度：学什么（值/策略/混合）、要不要模型、on/off-policy。后续章节全部可以在这张图上定位。
