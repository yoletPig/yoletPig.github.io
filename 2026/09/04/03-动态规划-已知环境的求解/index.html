03 - 动态规划：已知环境的求解

本篇目标

读完本篇，你应该能做到：

  1. 从"回报的递归式"推导出贝尔曼期望方程与贝尔曼最优方程——这两条方程是后面 04–09 章所有算法的理论骨架。
  2. 实现策略评估、策略迭代、值迭代三件套，在 4×4 GridWorld 上看到真实的收敛过程（每次 sweep 的 δ\deltaδ 打印）。
  3. 理解广义策略迭代（GPI）：策略迭代、值迭代、MC、TD、Q-learning、PPO 全是"GPI 插值点上的不同组合"。
  4. 说清动态规划为什么在现实任务中少用：模型未知 + 维度灾难——由此自然引出后续全部章节。

动态规划（DP）假设环境模型 P(s′∣s,a)P(s'|s,a)P(s′∣s,a) 与 RRR 完全已知。听起来"作弊"，但它是唯一能看清算法骨架的入口：没有采样噪声干扰，每一步更新在数学上做什么一目了然。Sutton & Barto (2nd ed.) 第 4 章整章就干这一件事。

1. 贝尔曼方程：把"未来"折进"现在"

1.1 状态值函数与动作值函数

状态值函数 Vπ(s)V^\pi(s)Vπ(s)：从状态 sss 出发、一直按策略 π\piπ 行动的期望回报（Sutton & Barto, 2nd ed., §3.5）：

Vπ(s)=Eπ[Gt∣st=s]V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s] Vπ(s)=Eπ​[Gt​∣st​=s]

动作值函数 Qπ(s,a)Q^\pi(s,a)Qπ(s,a)：在 sss 先执行动作 aaa、之后按 π\piπ 行动的期望回报：

Qπ(s,a)=Eπ[Gt∣st=s,at=a]Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a] Qπ(s,a)=Eπ​[Gt​∣st​=s,at​=a]

两者通过策略互相换算：Vπ(s)=∑aπ(a∣s)Qπ(s,a)V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)Vπ(s)=∑a​π(a∣s)Qπ(s,a)。值函数是 RL 的"地图"——有了它，策略就退化为"站在每个路口选值最高的方向"。

1.2 贝尔曼期望方程推导（分步）

起点是 01 章留下的递归式 Gt=rt+1+γGt+1G_t = r_{t+1} + \gamma G_{t+1}Gt​=rt+1​+γGt+1​。对它取条件期望：

Vπ(s)=Eπ[Gt∣st=s]=Eπ[rt+1+γGt+1∣st=s]=Eπ[rt+1∣st=s]+γ Eπ[Gt+1∣st=s]V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t=s] = \mathbb{E}_\pi\left[r_{t+1} + \gamma G_{t+1} \mid s_t=s\right] = \mathbb{E}_\pi[r_{t+1} \mid s_t=s] + \gamma\, \mathbb{E}_\pi[G_{t+1} \mid s_t=s] Vπ(s)=Eπ​[Gt​∣st​=s]=Eπ​[rt+1​+γGt+1​∣st​=s]=Eπ​[rt+1​∣st​=s]+γEπ​[Gt+1​∣st​=s]

第一项是"立即奖励的期望"；第二项的关键动作是把联合期望拆成"对动作求期望 → 对下一状态求期望"（全期望公式）：

Eπ[Gt+1∣st=s]=∑aπ(a∣s)∑s′P(s′∣s,a) Vπ(s′)\mathbb{E}_\pi[G_{t+1} \mid s_t=s] = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\, V^\pi(s') Eπ​[Gt+1​∣st​=s]=a∑​π(a∣s)s′∑​P(s′∣s,a)Vπ(s′)

合并得到贝尔曼期望方程（Sutton & Barto, 2nd ed., 式 4.4）：

Vπ(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[R(s,a)+γVπ(s′)]\boxed{V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^\pi(s')\right]} Vπ(s)=a∑​π(a∣s)s′∑​P(s′∣s,a)[R(s,a)+γVπ(s′)]​

直觉解读：“当前状态的值 = 各动作的（立即奖励 + 折扣后的下一状态值）按策略加权的平均”。它把 VπV^\piVπ 定义成一个线性方程组：∣S∣|S|∣S∣ 个方程、∣S∣|S|∣S∣ 个未知数，理论上可以解析求解——但 ∣S∣|S|∣S∣ 稍大就不可行（10610^6106 状态的矩阵求逆是 101810^{18}1018 量级运算），所以 DP 用迭代法解它。

同理，对 QQQ 写出贝尔曼期望方程，并对策略取 max，得到贝尔曼最优方程（Sutton & Barto, 2nd ed., 式 4.9）：

V∗(s)=max⁡a∑s′P(s′∣s,a)[R(s,a)+γV∗(s′)]V^*(s) = \max_a \sum_{s'} P(s'|s,a)\left[R(s,a) + \gamma V^*(s')\right] V∗(s)=amax​s′∑​P(s′∣s,a)[R(s,a)+γV∗(s′)]

注意两处差别：平均（∑aπ\sum_a \pi∑a​π）换成了 max，π\piπ 消失了——最优解不依赖策略。非线性（max）意味着最优值函数对应确定性贪心策略即最优。

3. 策略评估：给定策略算值

问题：给定 π\piπ，求 VπV^\piVπ。做法是把贝尔曼期望方程当作更新规则反复迭代（Sutton & Barto, 2nd ed., §4.1）：

Vk+1(s)=∑aπ(a∣s)∑s′P(s′∣s,a)[R+γVk(s′)]V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\left[R + \gamma V_k(s')\right] Vk+1​(s)=a∑​π(a∣s)s′∑​P(s′∣s,a)[R+γVk​(s′)]

{Vk}\{V_k\}{Vk​} 收敛到 VπV^\piVπ 的保证来自压缩映射：∣S∣|S|∣S∣ 有限时该算子是 γ\gammaγ-压缩，误差以 γk\gamma^kγk 几何速度衰减（Banach 不动点定理）。实现里用 δ=max⁡s∣Vk+1(s)−Vk(s)∣<θ\delta = \max_s |V_{k+1}(s) - V_k(s)| < \thetaδ=maxs​∣Vk+1​(s)−Vk​(s)∣<θ 做停止条件。

  2. 值从终点向外单调变差——信息从终止状态沿更新规则"逆流而上"，每轮 sweep 传播一格。这就是 backup 图的物理意义：值从后继向前回灌。
  3. 收敛速度受两点控制：γ\gammaγ（越小收敛越快）与信息传播距离（离终点越远的状态越晚获得准确值，sweep 数 ≥ 最短路径长度）。

经验做法：就地更新（Gauss-Seidel，改完立刻用）与双缓冲更新（Jacobi，一轮内用旧表）结果相同，但就地更新收敛更快——本例 312 vs 471 sweeps，快 34%。原因是新信息当轮就用上了。表格法就这么写；深度 RL 里的 target 网络反而是刻意禁止就地更新（06 章）。

4. 策略迭代：评估与改进交替

想法（Sutton & Barto, 2nd ed., §4.3）：知道 VπV^\piVπ 后，可以做策略改进定理（policy improvement theorem）保证不亏的一步——对每个状态贪心化：

π′(s)=arg⁡max⁡a∑s′P(s′∣s,a)[R+γVπ(s′)]\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R + \gamma V^\pi(s')] π′(s)=argamax​s′∑​P(s′∣s,a)[R+γVπ(s′)]

改进定理保证 Vπ′≥VπV^{\pi'} \ge V^\piVπ′≥Vπ（逐状态），且只有当 π′=π\pi' = \piπ′=π 时才取等。于是"评估 → 改进"循环：值单调上升，策略最多 ∣S∣|S|∣S∣ 种有限，必然终止于最优策略 π∗\pi^*π∗。

真实运行结果：

最优策略图上每个状态都指向"离终点更近"的方向（次对角线上的状态有两个等价选择，argmax 取先到者）。注意 7 轮 > 理论最少轮数：初始"全向上"策略里有死循环（顶部一行向上撞墙永远走不到终点，γ=1\gamma=1γ=1 下评估值发散为 −1000-1000−1000 量级才被截断），改进定理仍然把它逐步拉了回来——策略迭代对糟糕的初始策略极其鲁棒，这是它理论上的最大优点。

5. 值迭代：把两步压成一步

策略迭代的问题是每次改进前都要把 VVV 评估到收敛（本例一个确定性策略要上百次 sweep，随机策略 312 次）。值迭代（value iteration，Sutton & Barto, 2nd ed., §4.4）说：何必等？改进定理不需要精确的 VπV^\piVπ，方向对了就行——把"评估的贝尔曼期望更新"直接换成"max 版本"，一轮顶一轮：

Vk+1(s)=max⁡a∑s′P(s′∣s,a)[R+γVk(s′)]V_{k+1}(s) = \max_a \sum_{s'} P(s'|s,a)\left[R + \gamma V_k(s')\right] Vk+1​(s)=amax​s′∑​P(s′∣s,a)[R+γVk​(s′)]

这等于"每次只做一次评估 sweep 就改进"的策略迭代极限压缩，仍收敛到 V∗V^*V∗（max 算子依然是 γ\gammaγ-压缩）。

真实运行结果：

对比读数：值迭代 7 次 sweep vs 策略迭代 7 轮（每轮含几十上百次评估 sweep）——总计算量差一个数量级以上。V∗V^*V∗ 矩阵本身就是答案的另一种写法：左上角 −6-6−6 = 最短 6 步 × 每步 −1-1−1，且从任意状态出发的最短步数可以直接从表里读出来。注意 sweep 0–5 的 δ\deltaδ 恒为 1.0——δ=1\delta=1δ=1 说明"有状态的最短距离记录还在缩短一格"，直到第 7 轮所有状态的最短路都被打通后 δ\deltaδ 骤降。这个现象在更大网格上会更明显：值迭代的收敛台阶由"信息传播距离"决定。

策略迭代 vs 值迭代怎么选？策略迭代每轮贵但轮数少（值函数精确）；值迭代每轮便宜但轮数多。中间还有"截断式策略迭代"（评估只跑几轮就改进）——三者其实是同一个光谱上的三个点，这就引出 GPI。

6. 广义策略迭代（GPI）：全系列的总纲

广义策略迭代（generalized policy iteration，Sutton & Barto, 2nd ed., §4.6）：几乎全部 RL 算法 = 一个近似值函数 + 一个近似策略 + 两条互相拉扯的更新线：

两条线谁也不等谁：值函数线不等策略定准，策略线不等值函数评估完。只要两条线互相"把对方往自己的最优方向拉"，且都有不动点，最终就会相遇在 (V∗,π∗)(V^*, \pi^*)(V∗,π∗)——这正是"广义"的含义。

用这把尺子量全系列（也是本系列的组织逻辑）：

算法 评估线 改进线 GPI 位置
策略迭代 评估到收敛 每轮贪心 两个极端
值迭代 不显式评估 max 内嵌 另一个极端
MC（04 章） 整条轨迹平均 隐式（ε-greedy） 评估线拉长
TD/Q-learning（04–05 章） 单步自举 隐式/显式贪心 评估线压到 1 步

看懂这张表，“新算法"就只是"GPI 两条线上换零件”。经验做法：拿到任何不认识的 RL 论文，先问三个问题——评估线用什么信号（MC/TD/n-step）？改进线怎么动（贪心/梯度）？两条线怎么防止互相拉崩（目标冻结/裁剪/信任域）？第三问就是 06/09 章的全部内容。

7. 为什么 DP 在现实中少用

三大原因（Sutton & Barto, 2nd ed., §4.5）：

  1. 模型未知。DP 需要 P(s′∣s,a)P(s'|s,a)P(s′∣s,a) 显式给出。现实任务里这恰恰是最难拿到的东西：机器人不知道自己的物理参数，LLM 环境就是用户本人。→ 04 章起的无模型方法（MC/TD）直接从交互数据学，绕开 PPP。
  2. 维度灾难。计算量 O(∣S∣2∣A∣)O(|S|^2 |A|)O(∣S∣2∣A∣) 起步、内存 O(∣S∣)O(|S|)O(∣S∣)。Backgammon 约 102010^{20}1020 状态，围棋 1017010^{170}10170——表格存不下，更新也跑不完。→ 06 章用神经网络做函数近似，V(s;θ)V(s;\theta)V(s;θ) 只需网络参数量级的内存，还能泛化到没见过的状态。
  3. 并行扫全表不现实。DP 假设可以反复"扫"全部状态；真实 agent 只能沿轨迹访问极小部分状态。→ 04 章起的"沿轨迹更新"范式。

但 DP 没有白学：无模型方法的更新公式长得一模一样，只是把 ∑s′P(s′∣s,a)(⋅)\sum_{s'} P(s'|s,a)(\cdot)∑s′​P(s′∣s,a)(⋅) 换成了"从真实交互里采一个 (s′,r)(s', r)(s′,r)"。这个替换叫从期望到样本（expectation → sample），是全系列最重要的抽象一步：样本是无偏的（单样本意义下），代价是方差——04 章的偏差-方差之争由此开场。

8. 常见误区

  1. θ\thetaθ 设得太小，误以为"不收敛"。 迭代停止条件 δ<θ\delta < \thetaδ<θ 与数值精度强相关：γ=1\gamma=1γ=1、奖励量级大时 δ\deltaδ 收缩慢，312 sweeps 看着"还在动"其实是几何衰减的尾巴。先用对数刻度画 δ\deltaδ 随 sweep 的曲线再下结论。
  2. γ=1\gamma=1γ=1 + 不存在终止状态 = 不收敛。 本章策略迭代 7 轮里，"全向上"初始策略在顶行形成死循环，评估值一路滑向 −103-10^3−103 才被截断。排除方法：episodic 任务确认每个策略能以正概率到达终止状态；continuing 任务必须 γ<1\gamma < 1γ<1。
  3. 终止状态被更新了。 终止状态值必须恒为 0，否则奖励会计入"终止之后的假想未来"。实现上就是 if is_terminal: continue。这个 bug 的典型症状：VVV 矩阵整体偏移一个常数，策略却"看似正确"——直到换成要求值精确对齐的任务才暴露。
  4. 把值迭代的 δ\deltaδ 当作误差界直接信任。 δ<θ\delta < \thetaδ<θ 只保证 VkV_kVk​ 自身变化小；对 V∗V^*V∗ 的真实误差约为 δ⋅γ/(1−γ)\delta \cdot \gamma/(1-\gamma)δ⋅γ/(1−γ)（压缩映射的误差传递）。γ=0.99\gamma=0.99γ=0.99 时真实误差可能是 δ\deltaδ 的 99 倍——要求"真值误差 < 0.1"需要 θ≈0.001\theta \approx 0.001θ≈0.001。
  5. 拿 GridWorld 的收敛速度外推到深度 RL。 表格 DP 收敛又稳又快是因为没有采样噪声、没有函数近似误差。深度 RL 里同款更新公式配上神经网络和采样噪声后稳定性塌方（06 章 Deadly Triad）——不是公式错了，是它的两个收敛前提（精确表格 + 全状态期望）没了。

本篇小结

  • 贝尔曼期望方程把 VπV^\piVπ 定义为线性方程组；贝尔曼最优方程把 V∗V^*V∗ 定义为非线性方程组（max）。两者都是把"未来折进现在"的递归。
  • 策略评估 = 迭代贝尔曼期望方程，收敛速度由 γ\gammaγ 与信息传播距离决定；就地更新（Gauss-Seidel）比双缓冲快约 34%（312 vs 471 sweeps，本例实测）。
  • 策略迭代 = 评估到收敛 + 贪心改进，单调收敛到 π∗\pi^*π∗，对烂初始化鲁棒但每轮评估昂贵（本例 7 轮）；值迭代 = max 一步到位，总计算量小一个量级（本例 7 sweeps）。
  • GPI：一切 RL 算法 = 值线 + 策略线互相拉扯；后续每章都是这两条线的不同组合与保护机制。
  • DP 的三个现实障碍（模型未知/维度灾难/无法扫全表）精确对应后续三章要解决的三个问题（无模型/函数近似/沿轨迹学习）。

  1. 把 GridWorld 改成 8×8 并把终点改到 (7,7)，重跑值迭代：最优值应变为 −14-14−14（曼哈顿距离）。观察收敛 sweep 数如何随网格变大增长，解释"信息传播"与 sweep 数的关系。
  2. 把 γ\gammaγ 改为 0.9 重跑策略评估（均匀随机策略），解释为什么收敛 sweep 数大幅下降、值矩阵如何变化。（提示：压缩因子让远处状态的信息衰减。）
  3. 实现"截断式策略迭代"：每次评估只跑 3 个 sweep 就做策略改进。验证它同样收敛到 π∗\pi^*π∗，并记录总 sweep 数——应落在策略迭代与值迭代之间。
  4. 加入一个"陷阱格"（如 (1,1)，进入奖励 -10 并直接终止），重跑值迭代，观察最优策略如何绕开它。陷阱格的 VVV 值应该是多少？为什么？
  5. 思考题：DQN 用一个网络近似 Q(s,a;θ)Q(s,a;\theta)Q(s,a;θ) 并用 TD 误差更新，从 GPI 视角说明"评估线"和"改进线"分别由哪段代码实现，以及"两条线互相拉崩"在 DQN 里对应什么现象。（答案在 06 章，但先试着推。）
