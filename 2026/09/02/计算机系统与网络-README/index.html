计算机系统与网络系列教程：从晶体管到 HTTP 请求

面向以 Python 为主、能读懂 C、在 WSL2/Linux 上动手、目标成为**算法工程师（推理服务方向）**的学习者。本系列补上知识库里缺的两块拼图：① 程序在硬件上如何真正执行（晶体管→门→流水线→缓存→指令，这是性能优化的物理极限所在）；② 网络协议体系（从比特到 HTTP 请求的完整旅程，这是推理服务作为网络系统的通用语言）。库里的操作系统系列已经在 OS 层讲过进程/内存/epoll/socket，Linux 性能工程系列讲过"怎么测"，本系列的立场是：性能工程那边告诉你"数字是多少"，这边解释"为什么是这个数"。
全系列为中文原创，共 13 章。关键论断标注可查证来源（CSAPP 即《深入理解计算机系统》、《计算机组成与设计》即 Patterson & Hennessy、Intel SDM 即 Intel 64 and IA-32 Architectures Software Developer’s Manual、网络协议注明 RFC 编号）；无法查证的经验做法一律明确标注"经验做法"。演示代码 C 与 Python 混用、中文注释、完整可运行，终端命令在 Ubuntu 22.04 / WSL2 (kernel 6.6) 上验证过。

学习路径

篇 主题 你将学会
01-从晶体管到程序 门→组合逻辑→时序逻辑→CPU 抽象阶梯、ISA 软硬件契约、x86-64 vs ARM/RISC-V、gcc 四阶段与链接器 从开关讲到程序；用 gcc -E/-S/-c 拆出每一步中间产物；用 nm/ldd 解释 undefined reference
02-机器级表示-读懂汇编 寄存器、寻址模式、常用指令、System V AMD64 调用约定、栈帧、-O0 vs -O2 对照 读懂 objdump 输出；说清参数怎么传、栈怎么开；用 gdb 单步看栈帧变化
03-缓存层级与局部性 存储金字塔、64B 缓存行、组相联、写策略、行优先 vs 列优先实测、伪共享实测 背出各级延迟量级；写出缓存友好的代码；解释权重加载为什么是带宽受限
04-流水线与分支预测 流水线、三类冒险、分支预测、有序 vs 无序数组实测、乱序执行/超标量、SIMD 概念 讲清误预测 15~20 周期从哪来；实测分支预测收益与 cmov 优化；说 SIMD 何时能吃到
05-数字的表示与浮点陷阱 补码、整数溢出、IEEE 754 逐位拆解、0.1+0.2、Kahan 求和、fp16/bf16、NaN/Inf 手拆一个浮点数；预判累加误差；为训练选对半精度格式；排查 loss=NaN
06-网络分层模型与IP OSI vs TCP/IP、封装解封装、IP/CIDR 计算、路由与 NAT、ping/traceroute/mtr 实测、IPv6 手算子网边界；读懂路由表；用 TTL 反推跳数；解释家用路由器怎么上网
07-TCP详解 序号/确认/重传、三次握手四次挥手、TIME_WAIT、流量控制、拥塞控制四算法、BBR、tcpdump 抓握手 逐包分析一次握手；解释为什么不能两次握手；画出 cwnd 曲线；读懂 tcpdump 输出
08-HTTP协议详解 报文逐行解剖、方法/状态码语义、关键头部、CORS 预检、队头阻塞、HTTP/2 与 HTTP/3/QUIC 手写合法报文；讲清 301/302/307 区别；完整走一遍 CORS 预检；说明 QUIC 为什么解决队头阻塞
09-TLS与安全通信 对称/非对称分工、TLS1.2 vs 1.3 握手、证书链、openssl 实测、前向保密、自签证书实验 用 s_client 解析真实证书；画出两个版本握手时序；自己签一张证书并抓握手
10-DNS-负载均衡与CDN 递归/迭代解析、记录类型、dig +trace、GSLB、四层 vs 七层 LB、健康检查/会话保持、CDN 与 Anycast 走通一次完整解析；读懂 dig 各字段；给服务选负载均衡层；解释大模型 API 为什么用 Anycast
11-RPC与序列化 远程调用语义、JSON/MessagePack/Protobuf 实测对比、varint 编码、gRPC 四种流、重试风暴、手写 mini-RPC 量化三种格式的编码大小；读懂 .proto 兼容性规则；避开重试风暴；写下 100 行 mini-RPC
12-延迟与带宽的工程常识 延迟数字表、BDP、为什么加机器不一定变快、Amdahl 定律推导、RTT 敏感设计、跨地域部署 背下延迟数量级并推算上限；算出窗口够不够吃满带宽；用 Amdahl 预判并行收益
13-实战-完整请求旅程与抓包分析 URL→响应全旅程逐层抓包、手写支持 keep-alive 的 HTTP 服务器、HTTP/1.1 vs HTTP/2 连接数对比、面试 30 题 把 06–12 章串成一次完整实验；独立完成手写服务器；带走 30 道高频面试题要点

阶段划分

  1. 硬件执行篇（01–05）：从晶体管到 ISA（01）、汇编与调用约定（02）、缓存层级（03）、流水线与分支预测（04）、数字表示（05）。回答"程序在硬件上如何真正执行"，为性能优化划定物理边界。读这五章不需要任何网络知识，是模型性能优化系列的底层地基。
  2. 网络协议篇（06–11）：分层与 IP（06）、TCP（07）、HTTP（08）、TLS（09）、DNS/LB/CDN（10）、RPC 与序列化（11）。沿"一个 HTTP 请求从浏览器到服务器"的路径逐层下钻，每章都有抓包/实测。
  3. 工程常识与综合实战篇（12–13）：延迟带宽常识是网络篇的"提炼与内化"（类似 03 章之于硬件篇）；13 章用一次完整请求旅程把全部知识串起来，并附面试题清单。

与本仓库其他方向的衔接

  • 操作系统系列 = OS 层：那边的 04/05（虚拟内存与分页）解释"地址是什么"，本系列 01/02 解释"地址上的指令长什么样、怎么被执行"；那边的 09（epoll）与 12（socket API）是"系统调用层怎么用"，本系列 07/08 往下补"线上跑的字节序列长什么样"。两边共享《CSAPP》引用体系。
  • Linux 性能工程系列 = 观测层，本系列 = 原理层：性能工程 03 篇教你读 perf stat 的 IPC 和 cache-misses，本系列 03/04 解释这些数字背后的缓存组织与流水线惩罚；性能工程 07 篇教你用 ss/tcpdump 观测网络，本系列 07/08 解释你抓到的每个字段。建议顺序：先性能工程建立"测量直觉"，读本系列补"为什么"，再回性能工程做定量归因。
  • 模型性能优化 Stage 3（CUDA）← 本系列 03（内存层级）：GPU 的显存层级（global/shared/register）与 CPU 缓存是同一思想在不同硬件上的展开；本系列 03 的"权重加载是带宽受限"正是 CUDA 优化中"算术强度"概念的 CPU 版铺垫。05 章的 fp16/bf16 直接对应混合精度训练与量化部署。
  • C++ 系列 ← 本系列 01/02（汇编/ABI）：C++ 系列讲"怎么写"，本系列 02 讲"编译出来是什么"——虚函数表的间接调用开销、内联为什么快、ABI 兼容性问题，读完 02 再看 C++ 系列的编译与链接章会非常顺。
  • 分布式系统系列 10 章 ← 本系列 11（重试风暴）：11 章的"重试预算/指数退避"与分布式系列的容错与熔断章互为表里：这边讲单次 RPC 怎么配重试，那边讲全链路的级联失效怎么防。
  • Agent 生产部署：推理服务的网关/限流/灰度都落在 10（负载均衡）、12（延迟设计）的常识上；调用大模型 API 时 08 章（HTTP/2 流式）与 11 章（server-streaming）解释你天天在用的 SSE 与流式接口底层。

约定

  • 架构约定：以 x86-64 为准（Ubuntu 22.04 验证），涉及 ARM 的差异（如 char 默认符号性、调用约定 AAPCS、NEON/SVE）在文中以 ARM 注 标出；不展开 RISC-V 细节，仅在 01 章做事实对比。
  • 工具约定：编译用 gcc（11.4），调试用 gdb，反汇编用 objdump，ELF 分析用 readelf/nm/ldd；抓包以 tcpdump（WSL2 直接可用，需 sudo）为主，Wireshark 图形界面在 WSL2 下需 WSLg 支持或用 tshark 命令行替代，文中标注。
  • 网络约定：实验面向"容器/WSL2 的受限环境"设计——能真实抓包的本机回环实验优先，需要公网的实验给出真实输出但提醒"你抓到的 IP/数字必然不同，看形状不看数值"。WSL2 默认 NAT 模式、且可能有代理（本机存在 https_proxy），涉及 traceroute/HTTP/3 的实验差异会显式标注。
  • 数字约定：延迟/带宽数字标注来源（Intel SDM Vol.3 第 11 章、CSAPP 第 6 章、Jeff Dean《Latency Numbers Every Programmer Should Know》2009、RFC 编号）；"经验做法"不冒充定论。
  • 术语约定：优先中文术语、首次出现附英文；寄存器与汇编助记符保留原文（mov、rax）以便与工具输出对照。
  • 本系列不使用 Obsidian 双链以外的特殊语法，任何 markdown 阅读器都能正常渲染。
