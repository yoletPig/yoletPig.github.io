Agent 系列教程：从 ReAct 到可控、安全的 Agent 开发

面向已经会用 LLM API（会写一个 chat 调用）的初学者，系统讲清楚 AI Agent（智能体）到底是什么、怎么一步步搭起来、以及开发中最常踩的坑和最重要的安全边界。
全系列为中文原创，涉及的关键事实（论文出处、协议细节、时间线）均标注了可查证的来源；文中代码以 Python 为主，只依赖标准库和最常见的三方库。

学习路径

篇 主题 你将学会
01-Agent概念与心智模型 Agent vs 工作流 vs 聊天机器人 建立"感知-决策-行动-反馈"的心智模型，知道什么时候才真的需要 Agent
02-ReAct-推理与行动循环 Thought → Action → Observation 手写一个最小 ReAct 循环，理解 Agent 的骨架
03-工具调用与FunctionCalling Function Calling / Tool Use 用 OpenAI、Anthropic 的原生工具调用接口写出可靠的工具执行器
04-MCP协议详解 Model Context Protocol 理解 MCP 的架构、原语（tools/resources/prompts）与传输方式，写一个最小 MCP Server
05-记忆与上下文管理 短期/长期记忆、上下文窗口 会话状态、记忆压缩、上下文窗口管理的工程做法
06-多Agent协作 Orchestrator-Worker、A2A 什么时候该拆多 Agent、怎么拆、协作模式的取舍
07-Agent开发常见问题与陷阱 失败模式排查清单 死循环、工具调用失败级联、上下文腐化、评测缺失等高频问题的成因与对策
08-权限与沙箱安全 最小权限、审批门、沙箱 给 Agent 设计权限模型：能力白名单、人审环节、文件系统/网络隔离
09-提示词注入与Agent安全 Prompt Injection（直接/间接） 理解注入攻击原理、OWASP LLM Top 10 中的相关条目与纵深防御
10-实战项目-文件整理Agent 综合实战 把全系列串起来：一个带权限控制、审批门和评测的最小可用 Agent
11-进阶-上下文工程与提示词架构 Context Engineering 五段式系统提示、上下文预算分配、工具结果压缩——把上下文当内存管理
12-进阶-长任务Agent与规划 长任务系统设计 任务分解、计划外置（PLAN.md）、事件溯源持久化、幂等重放与断点续做
13-进阶-Agent评测体系 Evals 工程 测试金字塔、LLM-as-judge 偏差控制、CI 门禁、评测与生产闭环
14-进阶-生产部署与可观测性 生产工程 Tracing、成本治理、失败分型与降级阶梯、多租户隔离、灰度回滚

阶段划分

  1. 概念与骨架（01–03）：Agent 是什么、ReAct 循环、工具调用。学完就能写出"能干活"的单 Agent。
  2. 协议与能力扩展（04–06）：MCP、记忆、多 Agent。让 Agent 从"玩具"走向"系统工程"。
  3. 可靠性与安全（07–09）：本系列最重要的部分。没有这三篇，前面的 Agent 只是演示；有了这三篇，才谈得上开发。
  4. 实战（10）：综合项目。
  5. 进阶篇（11–14）：面向真实生产的纵深——上下文工程、长任务规划、评测体系、部署运维。每篇都建立在基础篇对应章节之上（11↔05、12↔07、13↔07、14↔08/09），建议先读基础篇再读对应进阶章。

与本仓库其他方向的衔接

  • VLM & VLA Stage 9（Multimodal Agent） 讲多模态场景下的 Agent 规划与闭环执行，本系列提供其单模态基础。
  • 语音方向 Stage 7（端侧语音助手） 的"语音前端 + LLM 决策 + 工具执行"链路，就是一个语音交互的 Agent，可直接套用本系列 03（工具调用）与 08（权限）。

约定

  • 代码环境：Python 3.10+。示例中 llm_call 一类函数是抽象占位，实际接入任选一家 SDK。
  • 引用规范：关键论断给出论文/官方文档出处，无法查证的内容一律标注"经验做法"，不冒充定论。
  • 本系列不推荐任何"某某框架是最好的"——框架选择放在 06 篇末尾讨论，且只列事实性对比。
