02 - 函数深入

本篇目标

  1. 把"函数是一等公民"落到实处：函数可以赋值、传参、返回、存进容器——这是理解装饰器（03 篇）的前提；
  2. 彻底搞懂默认参数在 def 时求值一次：可变默认参数陷阱是 Python 面试出场率最高的问题，也是真实事故源；
  3. 掌握闭包与变量捕获：闭包捕获的是变量（名字绑定）而非值，会写会用 nonlocal，并解释 late binding 陷阱；
  4. 会用 *args/**kwargs 转发参数、用 __name__/__doc__/__defaults__ 等做函数内省。

1. 函数是一等公民

"一等公民（first-class）"指的是：函数和 int、str 一样是普通对象——可以绑定到名字、存入容器、作为参数传递、作为返回值。Python 官方 FAQ 与《Fluent Python》第 7 章都以此为核心。

因为函数是对象，它有自己的属性和类型（function 类型本身可调用——01 篇说过"一切皆对象"）。高阶函数（接受或返回函数的函数）因此成为 Python 的常规武器：map/sorted(key=...)/functools.reduce，以及 03 篇的装饰器，全都建立在本节之上。

2. 默认参数：def 时求值一次（经典面试题）

这是 Python 语义中最容易被误解的一条：默认值表达式在 def 语句执行时求值一次，得到的结果对象被存进函数对象，之后所有调用共享（Python 官方 Tutorial 第 8 章 “More on Defining Functions” 明确写道：“default values are evaluated at the point of function definition”）。

3. 闭包与变量捕获

闭包（closure）：内层函数引用了外层函数作用域中的名字，且内层函数在外层返回后仍可被调用——它把"函数 + 该函数所需的自由变量环境"打包在了一起。被引用的外层名字存在内层函数的 __closure__ 属性中（cell 对象）。

4. *args 与 **kwargs：参数转发与解包

规则（《Fluent Python》第 5 章 + 官方文档 Expressions → Calls）：

  • *args 收集多余的位置参数为元组；**kwargs 收集多余的关键字参数为字典；
  • 定义时是"收集"，调用时是"解包"：f(*lst, **dct) 把容器摊开成参数；
  • 形参顺序固定为：位置参数 → *args → 仅关键字参数（keyword-only）→ **kwargs。

最常用、也最有价值的模式是参数转发（forwarding）——包装函数把一切参数原样转交内层函数，这是 03 篇通用装饰器的技术基础：

仅关键字参数（* 之后）是经验做法：布尔开关、可选项用 *, force=False 强制写关键字调用，调用点可读性大增，API 演化时也不怕位置参数错位。3.8+ 还有 / 声明仅位置参数（PEP 570），用于"参数名只是占位、不承诺稳定"的场合。

常见陷阱

陷阱一：可变默认参数（第 2 节详述）。检查方式 f.__defaults__ 里有没有 list/dict/set；修复方式哨兵 None。

陷阱二：闭包 late binding（第 3 节详述）。循环里创建 lambda/闭包并"稍后调用"时，九成会踩；修复方式 lambda i=i: ... 或 functools.partial(func, i)。

陷阱三：以为默认值每次调用都重新求值，把 datetime.now()/random.random()/uuid.uuid4() 写进默认值——结果所有调用拿到同一个时间/随机数/ID：

陷阱四：在闭包里读外层可变名字但忘了它是延迟读取，比如在 for 循环中 create_task 后任务读到的循环变量不是"创建那一刻"的值——同 late binding，正解同上（固定进默认参数或用 partial）。

陷阱五：lambda 里塞复杂逻辑还试图赋值（f = lambda x: ...）。PEP 8 明确反对"Assigning a lambda to an identifier"——它抹掉了函数名（__name__ 变成 <lambda>），栈跟踪难读；超过一个表达式的逻辑写成 def。

本篇小结

  • 函数是一等对象：可赋值、入容器、作参数、作返回值；ops = {"add": add} 这种字典分发就是 Agent 工具注册的原型；
  • 默认值在 def 时求值一次并存在 __defaults__：可变默认参数跨调用共享，正解哨兵 None；
  • 闭包捕获变量而非值：重新绑定需 nonlocal；循环闭包 late binding 用默认参数固化；
  • *args/**kwargs 定义时收集、调用时解包，是参数转发与通用装饰器的基石；
  • 内省三件套：__name__/__doc__/__defaults__ 手工看，inspect.signature 程序化读——框架把签名变成工具 Schema 就是这么来的。
