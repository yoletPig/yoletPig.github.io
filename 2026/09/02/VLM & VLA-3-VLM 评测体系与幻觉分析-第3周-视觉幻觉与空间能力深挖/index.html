第 3 周教程：视觉幻觉与空间能力深挖

本周要回答的三个问题

  1. 幻觉的三个层次（物体/属性/关系）各自的结构性根源是什么？
  2. POPE 的 Random/Popular/Adversarial 三种采样分别度量什么？Yes 偏置如何被 F1 抓住？
  3. 怎么用消融实验区分"没看见图"（视觉缺失）和"没看图在编"（语言先验）？

对应学习计划：第 3 周。交付物：POPE 评测导出 False Positive 样本；分析脚本计算 Adversarial 模式 F1，定位最易被文本先验诱导幻觉的 10 个类别。

勘误：学习计划所引 HallusionBench 标题有误，正确为 HallusionBench: An Advanced Diagnostic Suite for Entangled Language Hallucination and Visual Illusion in Large Vision-Language Models（CVPR 2024，arXiv:2310.14566，已核实；346 图 / 1129 题，GPT-4V 的问题对准确率约 31.4%）。

1. 第一性原理：幻觉为什么是结构性的

1.1 根本矛盾：训练目标的"编故事"倾向 vs 视觉证据的约束力

VLM 的生成目标（下一词预测）天然鼓励"生成最可能的延续"——而"最可能的文本"由语言先验决定。当视觉信号弱（图看不清、细粒度特征没编码到）、或问题涉及视觉证据薄弱的细节（数数、稀有物体、相对位置）时，语言先验就会接管输出：模型不是在描述图片，而是在续写一段"关于这类图片的典型文本"。

幻觉不是 bug，是训练目标与证据约束之间张力的表现。它的三个层次恰好对应视觉语义的三个抽象层级，且根因各有不同：

层次 定义 例子 结构性根源
物体存在（Object Existence） 图中没有的对象被断言存在 无猫图说"有一只猫" 语言先验最强的地方："图里有什么"这类问题的先验分布高度长尾（“人/沙发/杯子"高频），模型偏向输出高频物体；SFT 数据中正例（“图中有 X”）远多于显式负例（“图中没有 X”），模型没学过"说没有”
属性（Attribute） 对象属性（颜色/数量/材质）张冠李戴 红车说成蓝色 属性绑定（binding）问题：视觉特征里"车"与"红色"是分离的特征，跨模态对齐在属性级粒度上远粗于物体级；CLIP 式对比学习全局对齐进一步稀释属性细节
关系/空间（Relation/Spatial） 对象间关系说反 人在马左边说成右边 视觉塔的空间编码先天薄弱：ViT 的注意力无几何先验，2D 位置信息靠位置编码间接注入；语言侧对"左/右"的描述又高度依赖视角约定，训练数据里视角标注不一致（从谁的视角看"左边"？）

训练侧的对照（衔接 Stage 2）：Stage 2 第 2 周失效 1 提到的"语言先验捷径"正是物体存在幻觉的训练成因——SFT 时模型发现靠先验答题就能把 loss 降下来，视觉通道的梯度贡献趋近于零。评测（本周）与训练干预（Stage 4 数据合成）之间的闭环就建立在这个因果链上。

1.2 POPE：把"存在幻觉"变成可度量的二分类

POPE（Evaluating Object Hallucination in Large Vision-Language Models, EMNLP 2023）的设计极简而聪明：把幻觉检测还原为一系列"图中有没有 X？"的 Yes/No 二分类。每张图配 6 个问题（3 个真值为 Yes——图里确实有的物体，3 个真值为 No——图里没有的物体），正负样本严格 1:1。

三种负例（No 问题中的物体 X）采样策略，难度递进：

策略 X 的来源 度量的失败模式
Random 从全类别词表随机抽 基础幻觉率：连随机物体都"看出来"，问题严重
Popular 从 COCO 全数据集的高频物体词表抽 频率先验诱导：模型是否倾向于"看见"常见物体
Adversarial 按"与图中物体的共现频率"排序，抽共现高但本图没有的物体（如图中有餐桌，抽"椅子"） 语境先验诱导：最强干扰，直接度量"文本共现先验压过视觉证据"的程度

三档分数的差值本身就是诊断信号：Random ≈ Popular ≈ Adversarial → 模型幻觉主要由感知失败驱动；Adversarial 显著低于 Popular → 语言先验主导，感知是够的，是"先验压过了证据"。

指标用标准二分类混淆矩阵（把 “Yes” 当正类 = 断言物体存在）：

Precision=TPTP+FP,Recall=TPTP+FN,F1=2⋅P⋅RP+R\text{Precision} = \frac{TP}{TP + FP}, \quad \text{Recall} = \frac{TP}{TP + FN}, \quad F_1 = \frac{2 \cdot P \cdot R}{P + R} Precision=TP+FPTP​,Recall=TP+FNTP​,F1​=P+R2⋅P⋅R​

  • FP（False Positive）：图里没有却答 Yes——这就是幻觉样本本身，本周 MVP 要导出的东西；
  • FN：图里有却答 No——过度保守（视觉感知太弱，连真有的都看不见）；
  • 另报 Yes Ratio（回答 Yes 的比例）：诊断 Yes 偏置的直接仪表。

1.3 彩票攻击：为什么必须看 F1 而不能只看 Recall

学习计划自测清单的考点，这里给出完整推导。设模型对所有问题无脑答 “Yes”。POPE 的正负样本各半：

  • TP=N/2TP = N/2TP=N/2（所有 Yes 真值答对），FN=0FN = 0FN=0 → Recall=100%\text{Recall} = 100\%Recall=100%
  • FP=N/2FP = N/2FP=N/2（所有 No 真值答错），TP+FP=NTP + FP = NTP+FP=N → Precision=50%\text{Precision} = 50\%Precision=50%
  • F1=2×0.5×10.5+1=66.7%F_1 = \frac{2 \times 0.5 \times 1}{0.5 + 1} = 66.7\%F1​=0.5+12×0.5×1​=66.7%

结论：Recall 会被拉满到 100%，Precision 跌到 50%（随机水平），F1 压到 66.7%。单看 Recall 会把"满嘴跑火车"的模型捧成完美；F1 同时惩罚 FP 与 FN，Yes 偏置在 F1 上现形。Acc+（MME）与 F1（POPE）是同一防作弊哲学的两次实现：任何只奖励单一方向的指标都会被 degenerate 策略攻破，评测协议必须让"偷懒策略"的期望得分不高于诚实策略。

1.4 HallusionBench：分离"语言幻觉"与"视觉错觉"

物体存在幻觉之上还有更隐蔽的一层：模型对"图文关系"本身的推理被先验带偏。HallusionBench 用**控制变量式的"问题对"（question pairs）**设计来定位：

  • 同一张图配一对互斥问题（如"图中山谷更蓝还是天空更蓝？" vs 交换主语的镜像问法），或一对视觉上极易与语言常识冲突的图（错觉图、反常识场景）；
  • 若模型在镜像问法下给出逻辑矛盾的两个答案 → 说明它在按问题的语言模式答题而非按图答题（language hallucination）；
  • 若模型对"反常识图像"系统性答错、对"常识图像"答对 → 视觉理解被先验覆盖（visual illusion）。

这种"成对出题 + 逻辑一致性计分"的设计思想值得带走：单一问题的对错噪声很大，控制变量的问题对才能把失败原因剥离出来。GPT-4V 在其 1129 题上问题对准确率仅约 31.4%（论文实测，2024 年初），足见此类任务的难度——不要以"通用 VQA 分数高"推断幻觉免疫力。

1.5 空间定位评价：IoU 与阈值化

Grounding（定位）的评价用交并比：

IoU=∣Bpred∩Bgt∣∣Bpred∪Bgt∣,Acc@t=1N∑i1[IoUi≥t]\text{IoU} = \frac{|B_{pred} \cap B_{gt}|}{|B_{pred} \cup B_{gt}|}, \quad \text{Acc@}t = \frac{1}{N}\sum_i \mathbb{1}[\text{IoU}_i \geq t] IoU=∣Bpred​∪Bgt​∣∣Bpred​∩Bgt​∣​,Acc@t=N1​i∑​1[IoUi​≥t]

  • t=0.5t = 0.5t=0.5 是 PASCAL VOC 传统阈值，“大致框对”；
  • 严格场景（具身抓取）用 t=0.75t = 0.75t=0.75 或 0.90.90.9，此时空间幻觉（框到邻近物体）无法蒙混；
  • 同时报告平均 IoU 与 Acc@0.5：前者反映"框的质量分布"，后者反映"可用率"。一个模型可能平均 IoU 0.6 但 Acc@0.5 只有 40%——一半的框完全不可用，均值掩盖了分布的双峰。
  • 空间关系的语言描述评价（“左边/右边”）则回到二分类+方向约定问题：出题时必须固定视角约定（“以观察者视角”），否则真值本身有歧义。

3. 工程权衡与失效模式

3.1 No-image Baseline：区分"看不见"与"瞎编"（自测考点预演）

归因的核心消融：同一批问题，把图像替换为纯黑/纯白/噪声图，再跑一遍。

观察 结论
无图回答与有图回答高度一致（答 Yes 的题无图也答 Yes） 模型在按语言先验答题，视觉通道贡献近零——训练侧"捷径"问题（回 Stage 2 修配方）
无图回答接近随机/全 No，有图回答显著变好 视觉通道在工作，剩余错误是感知失败——修视觉侧（分辨率/编码/数据）
无图时 Yes Ratio 显著高（如 >60%） 存在系统性 Yes 偏置，先报这个再谈能力

HallusionBench 的"语言幻觉 vs 视觉错觉"分类正是这一思想的基准化。工程上这个消融只需重跑推理（几十分钟），是所有幻觉分析报告的必备基线。

3.2 三个代表性失效模式

失效 1：答案解析方向反了，F1 全错

  • 症状：某模型 POPE F1 高得离谱（>98%），细看其 FP 数为 0。
  • 根因：该模型回答"是的，图中没有猫"这类含双重否定的句子，提取器取到"是"判为 Yes，但真值语义是 No；或模型的回答格式是完整句子而非单词，isin(["yes"]) 匹配失败后默认按 No 计——方向性错误。
  • 定位：人工读 30 条预测原文 vs 解析结果。
  • 修复：复用第 1 周的布尔提取器（含中文归一化），并把"解析失败"单独计数，不允许静默归为某一类。

失效 2：Adversarial 分数虚高——采样泄漏

  • 症状：自建的"adversarial 集合"分数与 Random 无异，甚至更低。
  • 根因：自己构造负例时，用了"图中物体类别列表"做排除，但排除逻辑只针对该图的 COCO 标注，图片里实际可见但未标注的物体（COCO 标注不完整）被选为"负例"——真值本身错了。
  • 定位：人工复核 50 条 FP"幻觉样本"的原图——若图里真有该物体，是标注泄漏不是模型幻觉。
  • 修复：负例采样后加一轮人工/强模型图检；引用官方 POPE 数据而非自造。

失效 3：Yes Ratio 偏置掩盖了真实能力差异

  • 症状：两个模型 F1 相近，但部署观感差异巨大（A 模型"什么都承认有"，B 模型"经常说没有"）。
  • 根因：F1 对 FP/FN 对称惩罚，但业务代价不对称——具身场景漏检（FN）可能比误检（FP）更危险，而安防场景相反。
  • 定位：报告 Yes Ratio 与混淆矩阵四格，而非只报 F1。
  • 修复：按业务代价选阈值化指标（如 FβF_\betaFβ​，β>1\beta>1β>1 偏重 Recall）；或对齐/校准模型的 Yes 偏置后再评（prompt 层校正是快糙猛的手段，正式手段是训练数据里补负例）。

4. 延伸思考题

  1. 指标设计题：把 POPE 的二分类扩展到属性幻觉（“车是什么颜色？“四选一），设计一个"属性 POPE”：如何构造负例（错误属性）、用什么指标、如何防"乱猜也有 1/4 正确率”？（提示：负例属性从同类别其他实例的属性分布抽；用循环评测 + 多题一致；或要求模型同时输出置信度做校准曲线。）
  2. 因果推断视角：No-image baseline 显示"无图与有图回答一致率 85%"，能断言"视觉通道没用"吗？设计补充实验增强或推翻这个结论。（提示：不能——可能是这 85% 的题本来就靠先验可答；应按"必须看图才能答对"的题目子集分层，看该子集上的一致率与正确率。）
  3. 反哺推演（衔接 Stage 4）：基于 2.2 节的 Top-10 幻觉类别（假设椅子/餐桌居首）与"Adversarial 显著低于 Random"的发现，写出三条具体的数据合成需求（数据类型、规模、来源图的约束）——这就是 Stage 4 的输入规格。
