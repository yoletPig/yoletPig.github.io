02 - 从零实现线性回归：不用框架

本篇目标

读完本篇，你应该能做到：

  1. 只用 NumPy 手写一个完整的线性回归训练：前向、损失、梯度、参数更新，四件套一页写完。
  2. 手推 MSE 损失对 w,bw, bw,b 的梯度公式，并用数值验证自己推得对不对。
  3. 用解析解（正规方程）验证梯度下降的结果，理解"迭代法"与"闭式解"的关系。
  4. 把 NumPy 版"翻译"成 PyTorch 版，看清 PyTorch 替你干了哪两件事，以及训练循环的骨架从此定型——后面 11 章学的所有东西都长在这个骨架上。

本篇刻意不用任何框架。框架是好东西，但先手推一遍，你才知道框架每行代码替你省了什么、也才会在框架出错时知道去哪里查。

1. 问题设定

1.1 为什么从线性回归开始

深度学习的每个环节在线性回归里都有对应物：

线性回归 深度网络
y^=wx+b\hat{y} = wx + by^​=wx+b 前向传播
MSE 损失 交叉熵等损失函数
∂L/∂w\partial L/\partial w∂L/∂w 反向传播
梯度下降 optimizer.step()

唯一的差别是深度网络把 y^=wx+b\hat{y}=wx+by^​=wx+b 换成了一叠非线性函数。训练机制本身没有变。

1.2 造一份带噪声的数据

真实世界的数据几乎都有噪声，我们模拟这个过程（设随机种子保证你跑出来的数和文中一致）：

2. 手写四件套（NumPy 版）

2.1 前向与损失

模型：y^i=wxi+b\hat{y}_i = w x_i + by^​i​=wxi​+b。

损失用均方误差（MSE）：

L(w,b)=1n∑i=1n(y^i−yi)2L(w, b) = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2 L(w,b)=n1​i=1∑n​(y^​i​−yi​)2

2.2 手推梯度（本篇核心）

对 www 求偏导，逐条链展开：

∂L∂w=1n∑i∂(y^i−yi)2∂y^i⋅∂y^i∂w=1n∑i2(y^i−yi)⋅xi\frac{\partial L}{\partial w} = \frac{1}{n}\sum_i \frac{\partial (\hat y_i - y_i)^2}{\partial \hat y_i}\cdot\frac{\partial \hat y_i}{\partial w} = \frac{1}{n}\sum_i 2(\hat y_i - y_i)\cdot x_i ∂w∂L​=n1​i∑​∂y^​i​∂(y^​i​−yi​)2​⋅∂w∂y^​i​​=n1​i∑​2(y^​i​−yi​)⋅xi​

∂L∂b=1n∑i2(y^i−yi)⋅1\frac{\partial L}{\partial b} = \frac{1}{n}\sum_i 2(\hat y_i - y_i)\cdot 1 ∂b∂L​=n1​i∑​2(y^​i​−yi​)⋅1

写成矩阵形式（5 章会从计算图角度再看一遍）：

∂L∂w=2n x⊤(y^−y),∂L∂b=2n 1⊤(y^−y)\frac{\partial L}{\partial w} = \frac{2}{n}\, x^\top(\hat y - y), \qquad \frac{\partial L}{\partial b} = \frac{2}{n}\,\mathbf{1}^\top(\hat y - y) ∂w∂L​=n2​x⊤(y^​−y),∂b∂L​=n2​1⊤(y^​−y)

直觉：损失是一座山，梯度指向上坡最快的方向，下山就朝反方向走一小步：

w←w−η∂L∂w,b←b−η∂L∂bw \leftarrow w - \eta \frac{\partial L}{\partial w}, \qquad b \leftarrow b - \eta \frac{\partial L}{\partial b} w←w−η∂w∂L​,b←b−η∂b∂L​

注意最后一点：噪声方差是 σ2=0.52=0.25\sigma^2 = 0.5^2 = 0.25σ2=0.52=0.25，MSE 的理论下界就是 0.25（模型不可能"预测噪声"），所以 loss 停在 0.248 不是没训好，而是已经到头了。判断"loss 是不是已到噪声下界"是 10 章诊断过拟合的基本功。

2.4 常见陷阱

  1. 学习率太大直接发散。把 lr 改成 1.0 跑一下：loss 15.3 → 29.1 → 73.2 → 209.6 → 627.5，www 在 7.6、-4.4、15.3、-18.1 之间来回摆动且振幅越来越大——一步迈过了谷底落到对面更高的坡上，最终溢出成 inf/nan。经验做法：线性模型从 0.1 起试，loss 发散就除以 10。
  2. 梯度公式里忘了除 n：损失定义变了（sum 而非 mean），梯度必须同步变。两者不一致是"loss 正常、参数乱跳"的常见病因。
  3. shape 对不上：w 必须是 (1,1) 列向量，若写成 (1,)，x @ w 得到 (100,) 而不是 (100,1)，后面广播静默出错。NumPy/PyTorch 的经典教训：shape 错误宁可显式 reshape，不要依赖广播碰巧不错。

3. 解析解：正规方程

3.1 为什么需要它

梯度下降是迭代逼近；而最小二乘有闭式解——令梯度为零直接解方程。用它验证迭代法的结果，能立刻知道你的训练代码写没写对。

把模型写成矩阵形式 y^=Xθ\hat y = X\thetay^​=Xθ，其中

X=[x11⋮⋮xn1]∈Rn×2,θ=[wb]X = \begin{bmatrix} x_1 & 1 \\ \vdots & \vdots \\ x_n & 1 \end{bmatrix} \in \mathbb{R}^{n\times 2}, \quad \theta = \begin{bmatrix} w \\ b \end{bmatrix} X=⎣⎢⎢⎡​x1​⋮xn​​1⋮1​⎦⎥⎥⎤​∈Rn×2,θ=[wb​]

令 ∂L/∂θ=2nX⊤(Xθ−y)=0\partial L/\partial \theta = \frac{2}{n}X^\top(X\theta - y) = 0∂L/∂θ=n2​X⊤(Xθ−y)=0，解得正规方程（normal equation）：

θ=(X⊤X)−1X⊤y\theta = (X^\top X)^{-1} X^\top y θ=(X⊤X)−1X⊤y

3.2 两者的关系

梯度下降 正规方程
复杂度 每步 O(n)O(n)O(n)，可迭代到任意精度 矩阵求逆 O(d3)O(d^3)O(d3)，ddd 是特征数
适用 ddd 大、数据大、任何模型 仅线性最小二乘
深度学习中 唯一现实选择 从不可行：GPT 的 ddd 是上万维

深度网络没有解析解，所以"迭代 + 反向传播"是唯一路径——这正是下一节切到 PyTorch 的动机。

4. PyTorch 版：框架替你干了什么

对比一下，PyTorch 只替你干了两件事：

  1. loss.backward()：自动求梯度。手推公式（2.2 节）那几行代码全免——模型换成深度网络后，手推不再现实。
  2. .grad.zero_()：清零梯度。注意框架并不自动清——这是 PyTorch 的设计哲学（显式优于隐式），3 章的 optimizer.zero_grad() 封装的正是这一步。

前向、损失、更新、循环结构——一行都没少写。这就是本篇最重要的结论：训练循环的骨架 = 前向 → 损失 → backward → 清零 → 更新，从线性回归到 GPT 都是这个骨架。

6. 常见陷阱汇总

  1. 忘了 zero_grad（PyTorch 版）：每步梯度都是历史值累加，loss 表面在降但方向错乱，训练曲线剧烈震荡。这是 PyTorch 新手第一名 bug。
  2. 学习率与损失定义不匹配：损失用 sum 而学习率按 mean 的量级调，等效学习率放大 nnn 倍，直接发散。
  3. 用 .data 更新参数：w.data -= ... 绕过 autograd 检查（01 章），现代写法是 with torch.no_grad(): 或直接用 optimizer。
  4. 收敛了但没到最优：线性回归如果 loss 停在远高于噪声方差的位置，先怀疑学习率太小/迭代太少，再怀疑梯度公式错（用 2.2 的数值差分对照）。
  5. 忘记把数据转 float：torch.tensor(x) 当 x 是 int 数组时得到 int64 张量，@ 运算报 dtype 错误。

本篇小结

  • 线性回归 = 前向 y^=wx+b\hat y = wx+by^​=wx+b + MSE + 梯度 2nx⊤(y^−y)\frac{2}{n}x^\top(\hat y-y)n2​x⊤(y^​−y) + 梯度下降，四件套手写不超过 30 行。
  • 梯度公式要用数值差分验证；loss 的理论下界是噪声方差 σ2\sigma^2σ2，MSE 停在 0.25 附近不是 bug。
  • 正规方程 θ=(X⊤X)−1X⊤y\theta=(X^\top X)^{-1}X^\top yθ=(X⊤X)−1X⊤y 提供闭式解用于验证，但深度网络只能用迭代法。
  • PyTorch 只替你做两件事：自动求导和（通过 optimizer）更新；训练循环骨架从此定型，全书复用。
  • zero_grad 是 PyTorch 显式哲学的一部分：框架不替你猜"你要不要累加梯度"。

练习

  1. 把 2.3 节的 lr 分别设为 0.01、0.1、0.5、1.0 跑 200 epoch，记录每个学习率的最终 loss，解释非单调现象。
  2. 把损失改成 L=12n∑(y^i−yi)2L=\frac{1}{2n}\sum(\hat y_i-y_i)^2L=2n1​∑(y^​i​−yi​)2，推导新梯度公式并修改代码，观察对训练速度的影响。
  3. 用解析解验证你写的多维版本：把数据扩成 3 个特征（y=2x1−x2+0.5x3+1+ϵy = 2x_1 - x_2 + 0.5x_3 + 1 + \epsilony=2x1​−x2​+0.5x3​+1+ϵ），分别用正规方程和梯度下降求解并对照。
  4. 给训练循环加上"早停"：若连续 10 个 epoch loss 下降小于 1e-6 就停止。记录实际用了多少 epoch。（10 章会系统讲早停。）
  5. 思考题：为什么 w -= lr * w.grad 必须包在 torch.no_grad() 里？试着去掉包装运行，观察会发生什么错误。
