PyTorch 与深度学习从零开始

面向 Python 基础扎实、但没有系统学过深度学习的学习者：从"张量是什么"一路讲到"亲手训练一个迷你 GPT"，补上算法工程师的地基。
全系列为中文原创，代码全部 CPU 可跑（需要 GPU 的地方单独标注）。本仓库的《VLM & VLA》《语音方向》《模型性能优化》都默认你已掌握本系列内容——它就是那块缺失的前置拼图。

学习路径

篇 主题 你将学会
01-张量与自动微分 tensor / 广播 / autograd 创建与操作张量、广播规则、计算图原理、backward 的正确用法、no_grad 与 detach 的区别
02-从零实现线性回归-不用框架 NumPy 手写训练 前向、损失、梯度、梯度下降全部手写，与解析解对照；看穿"训练循环"的本质骨架
03-nn.Module与训练循环 Module / optimizer nn.Module 的注册机制、SGD 与 Adam 的直觉差异、标准训练循环模板，跑通第一个 MNIST
04-数据加载与预处理 Dataset / DataLoader 手写自定义 Dataset、collate_fn、多进程加载的坑、transforms、可复现的数据管道
05-反向传播的数学原理 链式法则 / 计算图 手工对计算图求导（配数字）、动态图 vs 静态图、gradcheck 梯度检查、梯度消失与爆炸
06-卷积神经网络 CNN / BatchNorm 卷积的直觉与数学、手写 2D 卷积、输出尺寸公式、LeNet→ResNet 演进、残差连接为什么有效
07-序列建模-RNN到注意力 RNN / LSTM / 注意力 序列建模、RNN 的梯度困境、LSTM 门控直觉、seq2seq 与 teacher forcing、QKV 注意力机制
08-Transformer从零实现 miniGPT 逐块手写多头注意力、位置编码、FFN、causal mask，组装成可训练的 miniGPT（nanoGPT 路线）
09-训练稳定性与优化器 初始化 / 调度 / AMP Xavier/Kaiming 初始化、BN/LN/RMSNorm 对比、warmup 与 cosine 调度、AdamW、梯度裁剪、混合精度
10-过拟合与正则化 泛化工程 读懂 train/val 曲线、weight decay/dropout/早停/label smoothing、BN 与 dropout 的交互陷阱
11-迁移学习与微调 预训练-微调 冻结层、差分学习率、微调时 BatchNorm 的统计量陷阱、LoRA 低秩分解的最小实现
12-模型保存-部署与推理 保存 / ONNX / 推理 state_dict 的正确姿势、断点续训、ONNX 导出与数值一致性验证、torch.compile、推理优化常识
13-实战项目-手写数字分类到迷你GPT 综合实战 规范的项目结构、训练/验证脚本、TensorBoard 记录、消融实验表、复现检查清单，代码全量给出

阶段划分

  1. 地基（01–02）：张量与自动微分、不用框架手写线性回归。学完你就知道"训练"到底在循环什么。
  2. 框架与数据（03–04）：nn.Module、optimizer、DataLoader。从"会算"到"会用 PyTorch 写工程代码"。
  3. 原理与模型（05–08）：反向传播数学 → CNN → RNN/注意力 → Transformer。这是全系列的理论主干，08 篇把前面所有知识组装成一个能生成文本的 miniGPT。
  4. 训练工程（09–11）：训练稳定性、正则化、迁移学习。让模型"训得动"之后，让它"训得好、训得省"。
  5. 落地（12–13）：保存、部署、推理优化，最后用一个综合项目把全部知识串成可复现的工程实践。

与本仓库其他方向的衔接

  • VLM & VLA Stage 1（VLM 基础与架构深度拆解）：拆 ViT 与 LLM 的架构时，默认你已经懂卷积（06）、多头注意力与残差结构（07/08）——本系列 06–08 正是它的前置。
  • VLM & VLA Stage 8（训练系统）：多阶段训练、LoRA 微调、显存优化，全部建立在 03（训练循环）、09（优化器与混合精度）、11（LoRA）之上。
  • 语音方向 Stage 2（Whisper）：Whisper 是 encoder-decoder Transformer，理解它需要 07 的 seq2seq 与 08 的 Transformer 实现。
  • 模型性能优化 Stage 1（量化）：量化为什么有效、fp16/bf16/fp32 的位宽差异，先看 09 的混合精度与 12 的推理部署，量化才有落点。

约定

  • 代码环境：Python 3.10+，PyTorch 2.x（写作时验证于 2.14，API 以 PyTorch 官方文档 为准）；另有 NumPy、torchvision，个别章节用到 onnxruntime。
  • 所有示例默认 CPU 可跑；需要 GPU 的代码段会用注释 # [GPU] 标出，并给出 CPU 上的替代方案或降级参数。
  • 每个关键张量操作都写出真实的 shape 与数值，方便你在没有屏幕画板的情况下"看见"计算过程。
  • 引用规范：关键论断给出论文/官方文档出处；无法查证的内容一律标注"经验做法"，不冒充定论。
  • 随机数：示例输出基于固定种子，你本地运行若种子不同，数值会略有差异，但量级与趋势一致。
