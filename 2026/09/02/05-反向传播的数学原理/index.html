05 - 反向传播的数学原理

本篇目标

读完本篇，你应该能做到：

  1. 用链式法则手工对一个多层计算图求导，每一步都写出具体数字。
  2. 说清 PyTorch 动态图与静态图的区别，以及 backward() 里"向量乘雅可比"（VJP）的机制。
  3. 用 torch.autograd.gradcheck 给任何自定义函数做梯度检查。
  4. 从数学上解释梯度消失与爆炸的成因，并说出工程上对应的缓解手段。

2 章我们手推过线性回归的梯度，但那是"整个公式一起推"。真实网络有百万参数、几十层复合函数——本篇给出系统方法：把计算拆成图上的节点，逐边应用链式法则。这也是理解 6 章 ResNet、7 章 RNN 梯度问题的共同语言。

1. 链式法则：一切的前提

1.1 一元复合函数

若 y=f(u)y = f(u)y=f(u)，u=g(x)u = g(x)u=g(x)，则

dydx=dydu⋅dudx\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} dxdy​=dudy​⋅dxdu​

直觉：xxx 动一点，先按 ggg 的敏感度改变 uuu，uuu 再按 fff 的敏感度改变 yyy——敏感度相乘。

1.2 多元情况：偏导照样成立

多输出/多输入时，每个中间变量对上游每个变量的偏导都按上式相乘再相加（全路径求和）。形式化版本用"雅可比矩阵"（第 3 节），但深度学习的绝大多数直觉一元链式法则就够用。

2.3 为什么"反向"而不是"对每个参数单独前向求导"

设网络有 NNN 个参数。朴素数值差分要 2N2N2N 次前向（02 章的 numerical_grad）；反向传播把总代价降到与一次前向同阶（约 2 倍前向的计算量）。这就是反向传播 1986 年论文的核心贡献（Rumelhart, Hinton & Williams, Learning representations by back-propagating errors, Nature 1986）。工程含义：训练一步 ≈ 3 次前向的算力，参数量再大也承担得起。

3. 动态图 vs 静态图，以及 VJP 机制

3.1 两种建图方式

  • 动态图（PyTorch / JAX 默认）：前向代码跑一遍，图边执行边建，每个 step 一张新图。调试像普通 Python（print/断点都行），控制流（if/while 依赖数据的循环，如 RNN 变长）天然支持。
  • 静态图（TF1.x / 老版 Theano）：先声明整张图再执行。优点是可以先全局优化（算子融合、内存规划）、方便序列化到推理引擎；缺点是"图"和"代码"是两套语言，调试痛苦。

现代框架的走向是动态图为主 + 编译加速：PyTorch 2.x 的 torch.compile 在动态图语义不变的前提下，把捕获的图编译成优化内核（12 章概览）。出处：PyTorch 2.0 官方发布说明。

3.2 backward 的真实机制：VJP（向量-雅可比积）

PyTorch 反向传播的不是"每个参数的梯度"这种大批量标量运算，而是从 loss 出发的一股梯度流。每遇到一个多输出节点，就用链式法则的矩阵形式：

xˉ=(∂y∂x)⊤yˉ\bar{x} = \left(\frac{\partial y}{\partial x}\right)^\top \bar{y} xˉ=(∂x∂y​)⊤yˉ​

yˉ\bar yyˉ​ 是上游流下来的梯度（行向量），∂y/∂x\partial y/\partial x∂y/∂x 是雅可比矩阵。PyTorch 从不显式构造雅可比，只实现每个算子的 VJP（一次矩阵乘的代价）。这解释了 01 章的现象：

  • backward() 只能从标量调——因为"梯度流"的源头 yˉ\bar yyˉ​ 必须是 1 维的（全 1）。
  • y.backward(torch.ones_like(y)) 等价于"对 y 各分量梯度求和"——因为你手动指定了源头向量。
  • 中间节点梯度"用完即弃"——梯度流到达叶子（参数）后，其余分支没人需要，就被释放。

3.3 非标量 backward 的语义陷阱

注意：out.sum().backward() 得到的是 ∑k∂outk/∂vi\sum_k \partial \text{out}_k/\partial v_i∑k​∂outk​/∂vi​——若 out 的多个分量都依赖同一 viv_ivi​（比如矩阵乘中一个参数影响整行输出），梯度是所有路径之和。这正是"多路梯度自动累加"的数学本质。

4. 梯度检查：torch.autograd.gradcheck

4.1 为什么需要它

自己写了自定义算子/自定义 autograd.Function，怎么确认 backward 实现正确？用数值差分当裁判：中心差分的误差是 O(ϵ2)O(\epsilon^2)O(ϵ2)，在 double 精度下足以检测实现错误。

4.2 用法

三条纪律（官方文档明示）：

  1. 输入用 dtype=torch.double；
  2. eps 默认 1e-6，atol/rtol 适当放宽（atol=1e-5 常用）；
  3. 检查点要小（几个到几百个元素）——差分对每个元素都要两次前向，只用于测试，绝不进训练循环。

出处：PyTorch 官方文档 torch.autograd.gradcheck。训练中怀疑"梯度断了"时的快速替代（不求精确值）：打印每层参数梯度的范数 p.grad.norm()，找范数异常小/大的层——这就是下一节问题的诊断入口。

5. 梯度消失与梯度爆炸

5.1 数学成因

深度网络的梯度是沿途局部导数的连乘：

∂L∂w1=∂L∂hn⋅∂hn∂hn−1⋯∂h2∂h1⋅∂h1∂w1\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial h_n}\cdot\frac{\partial h_n}{\partial h_{n-1}}\cdots\frac{\partial h_2}{\partial h_1}\cdot\frac{\partial h_1}{\partial w_1} ∂w1​∂L​=∂hn​∂L​⋅∂hn−1​∂hn​​⋯∂h1​∂h2​​⋅∂w1​∂h1​​

n 层连乘的行为由每层因子决定：

  • 每个因子都略小于 1 → 连乘指数衰减 → 消失（越靠近输入的层梯度越小、学不动）；
  • 每个因子都略大于 1 → 连乘指数增长 → 爆炸（数值溢出、参数飞掉）。

5.2 消失：sigmoid 的数字账

σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)(1-\sigma(z))σ′(z)=σ(z)(1−σ(z))，最大值在 z=0z=0z=0 处取到，上限 0.25。若每层经过一个饱和的 sigmoid，10 层后梯度至多剩：

0.2510≈9.5×10−70.25^{10} \approx 9.5 \times 10^{-7} 0.2510≈9.5×10−7

何况实际 σ′(z)\sigma'(z)σ′(z) 通常远小于 0.25（远离 0 就趋近 0）。用具体数字跑一遍：

这就是 2010 年之前深网络训不动的核心原因之一。三个经典缓解手段（后文分别展开）：

  1. 换激活函数：ReLU 导数在正区间恒为 1（无衰减因子），6 章 CNN 默认；
  2. 更好的初始化：Xavier/Kaiming 让每层因子接近 1（9 章）；
  3. 加"高速公路"：残差连接让梯度多一条乘 1 的直通路径（6 章 ResNet）。

6. 常见陷阱

  1. 对非标量调 backward 忘传 gradient 参数：报错 grad can be implicitly created only for scalar outputs（3.3 节）。
  2. gradcheck 用 float32：假阳性报警——不是你的梯度错，是差分精度不够（4.2 节）。
  3. 以为"中间层梯度可见"：默认只有叶子有 .grad，调试用 retain_grad() 或 hook（01 章）。
  4. 连乘方向搞反：消失/爆炸影响的是靠近输入的层（梯度从 loss 流向输入，一路相乘）；"最后一层梯度很大、第一层梯度接近 0"才是消失的典型指纹。
  5. 把梯度裁剪当成万能药：裁剪掩盖的是症状；如果每步都在裁剪（clip 系数频繁生效），说明 lr/初始化有问题，应查根因（经验做法：监控"被裁剪的步数占比"）。

本篇小结

  • 链式法则逐边相乘：加法传 1，乘法传另一个操作数，tanh/sigmoid 的局部导数用输出表示。
  • 反向传播把"对 N 个参数求导"从 O(N)O(N)O(N) 次前向降到约 2 次前向的代价，这是深度学习可行的算力基础。
  • PyTorch 是动态图：边执行边建图，backward 从标量 loss 反向流动，实现上每步只做 VJP、从不构造雅可比。
  • gradcheck 用 double 精度 + 数值差分验证自定义梯度；训练中用梯度范数快速定位问题层。
  • 梯度消失 = 局部导数小于 1 连乘（sigmoid 上限 0.25 的数字账）；爆炸 = 大于 1 连乘；分别对应"换激活/初始化/残差"与"梯度裁剪"。
