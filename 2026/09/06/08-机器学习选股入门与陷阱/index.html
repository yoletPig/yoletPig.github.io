08 - 机器学习选股入门与陷阱

本篇目标

  1. 说清机器学习（ML）在投资中能做什么、不能做什么；
  2. 实现一个最小、诚实的 ML 选股流程；
  3. 重点讲清金融场景特有的四个 ML 陷阱——它们比通用 ML 陷阱更致命。

本篇立场先行：ML 不是"更高级的选股魔法"。金融数据的信噪比极低（有效市场把可预测性压到刚够覆盖成本的水平）、样本相对特征数"小"、数据分布漂移（regime 切换）——这三点共同决定了 ML 在选股上主要赢在：非线性组合已有因子、风控与标签工程，而不是"从原始数据里发现新大陆"。

1. 为什么金融是 ML 的地狱级场景

对照经典 ML 的成功条件与金融的现实：

ML 成功的条件 金融的现实
信噪比高（图像里猫就是猫） 年化收益率的"可预测成分"占比极小，噪声主导
样本量大且独立同分布 日频单市场 20 年 ≈ 5000 个时间点，且时间上强相关（有效样本远小于表面样本）
分布平稳 regime 切换：牛市/熊市/风格切换，规律本身会变
错误代价对称 预测错一次的代价不对称（07 篇的路径依赖：深回撤会出局）

推论：你在表格数据上验证过的 ML 直觉，到金融里大半失效。特别是"特征越多越好、模型越复杂越强"——在信噪比低的世界里，复杂度的第一效果是加速拟合噪声。

2. 最小 ML 选股流程（sklearn，防作弊版）

任务设定：用 t 月末可知的特征，预测 t+1 月的横截面相对收益（06 篇的范式：排序而非涨跌预测）。

三个刻意的防作弊设计：

  1. TimeSeriesSplit 而非 KFold：普通 K 折会拿未来训练、预测过去——时间机器（05 篇前视偏差的 ML 变种，也是 ML 选股最常见的错误）；
  2. 模型故意保守（浅树、厚叶子）：不是性能最优配置，是抗过拟合配置；
  3. 评价用样本外 IC，不用 R²——R² 在金融截面数据上普遍 <2%，这个数字正常，不代表模型没用（排序有价值≠方差解释高）。

3. 金融 ML 的四大特有陷阱

陷阱一：标签设计比模型重要

"下月收益率"做标签的问题：极端值主导训练（一只翻倍股的梯度抵过一百只平盘股）。常见改良：

  • 横截面秩变换：y 换成当月收益的截面百分位（Rank），天然抗极端值，且把任务对齐成"排序"；
  • 风险调整标签：用收益/波动，减少"高波动股涨得多"的伪信号；
  • 多期标签：单月标签噪声极大，用未来 3 个月平均可降噪（代价：信号滞后性增加，回测要相应错位）。

陷阱二：特征里的前视偏差（ML 版）

除了 05 篇的常规项，ML 特有的两个：

  • 财务特征的公告日对齐：用"报告期末"而非"公告日"对齐季度财务数据——你提前 1~4 个月用到了未来信息，回测收益虚高且你根本不会察觉（模型看起来只是"很有洞察力"）；
  • 特征选择信息泄漏：用全样本数据做特征筛选（如"全样本 IC 最高的 10 个因子"），再切训练/测试——筛选这一步已经看过测试集。一切依赖 y 的预处理（筛选、标准化、PCA）都必须在训练集内部完成。

陷阱三：有效样本的幻觉

表面上有 10 年 × 5000 股 = 50000 个月度截面样本，实际：

  • 同期股票收益强相关（系统性风险主导）——一个截面提供的信息远小于 5000 个独立样本；
  • 月度截面独立的只有"月数"（≈120 个）——时间独立样本才是真样本量；
  • regime 依赖：训练集如果没见过一次熊市，模型对熊市的"知识"为零，而且你无法从损失函数上看出这一点。

陷阱四：回测-实盘的 ML 特有落差

  • 再训练时点：回测里"每月用至今数据重训"的模型，实盘要保证同样的重训纪律与特征管线一致——管线漂移是实盘衰减的常见原因；
  • 特征失效的不可见性：线性因子的衰减能看到 IC 下滑；深度模型把因子组合藏进了黑盒，衰减了也不知道是哪个输入坏了。实务对策：保留线性因子模型作为"对照基准"与"解释工具"，ML 模型只在增量上被信任。

4. ML 在投资中真正的甜点区

比"预测收益"更靠谱的 ML 用武之地（业界共识性方向，各配文献锚点）：

  1. 非线性因子组合：给定 06 篇的因子集，用浅模型学习因子间的交互（比等权/线性组合多榨一点），López de Prado 的特征重要性方法（MDI/MDA）可用于解释；
  2. 另类数据信号：文本情绪（财报/新闻 NLP）是 ML 的优势区——文本分类正是 NLP 强项（注意：同样要防公告日前视与数据窥探）；
  3. 执行与风控：交易成本估计、异常检测（数据质量监控）、波动率预测（波动比收益可预测性高一个量级，GARCH 类与 ML 混合是成熟方向）。

5. 诚实结论

ML 选股的正确姿势：把 90% 的精力花在数据质量、标签设计与验证纪律上，模型本身用最简单的。 模型的聪明程度排在第四位——排在"没有前视偏差"“样本外纪律”"成本真实"之后。这与你从 Kaggle 学来的直觉正好相反，而这正是金融 ML 的特殊之处。
