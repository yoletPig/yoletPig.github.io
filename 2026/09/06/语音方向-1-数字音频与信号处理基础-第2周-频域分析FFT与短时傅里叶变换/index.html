第 2 周教程：频域分析——FFT 与短时傅里叶变换（STFT）

本周要回答的四个问题

  1. 傅里叶变换在做什么？幅度谱和相位谱各代表什么物理量？
  2. 为什么对整段语音做一次 FFT 没有意义，必须做"短时"傅里叶变换？
  3. n_fft、win_length、hop_length 三个参数如何互相制约？
  4. STFT 能不能反过来还原成波形？相位丢了怎么办（Griffin-Lim）？

对应学习计划：第 2 周。交付物：纯 NumPy 手写 stft() / istft()，重建音频并计算 SNR；绘制语谱图。

1. 第一性原理：为什么需要频域

1.1 根本矛盾

波形 x[n]x[n]x[n] 是时间的函数，但语音的很多本质信息活在频率里：元音由共振峰（formant）频率决定，音高由基频 f0f_0f0​ 决定，噪声表现为宽带平坦谱。时域波形上这些信息全部纠缠在一起，肉眼不可读；频域表示则把它们摊开。

傅里叶分析的核心断言：任何（满足条件的）信号都可以分解为不同频率正弦波的叠加。对离散有限长信号，这个分解就是离散傅里叶变换（DFT）。

1.2 DFT 的定义与逐符号解读

这个公式在干什么：把 NNN 个样本"摊开"成 NNN 个标准频率成分，然后逐个测量——"这段信号里含有多少你这种频率的成分？"测出来的 NNN 个含量就是 X[0],…,X[N−1]X[0], \dots, X[N-1]X[0],…,X[N−1]。

对长度 NNN 的序列 x[n]x[n]x[n]，DFT 为：

X[k]=∑n=0N−1x[n] e−j2πkn/N,k=0,1,…,N−1X[k] = \sum_{n=0}^{N-1} x[n]\, e^{-j 2\pi k n / N}, \quad k = 0, 1, \dots, N-1 X[k]=n=0∑N−1​x[n]e−j2πkn/N,k=0,1,…,N−1

逐项理解：

  • e−j2πkn/N=cos⁡(2πkn/N)−jsin⁡(2πkn/N)e^{-j 2\pi k n / N} = \cos(2\pi k n/N) - j\sin(2\pi k n/N)e−j2πkn/N=cos(2πkn/N)−jsin(2πkn/N) 是数字频率为 k/Nk/Nk/N（每样本多少个周期）的复正弦基。
  • X[k]X[k]X[k] 是 x[n]x[n]x[n] 与该基的内积——度量"xxx 里含多少频率 kkk 的成分"。这是投影，与注意力的 query-key 点积在数学上是同一个动作。
  • X[k]X[k]X[k] 是复数：∣X[k]∣|X[k]|∣X[k]∣ 是幅度谱（该频率的能量强度），∠X[k]\angle X[k]∠X[k] 是相位谱（该频率成分的时间偏移）。

频率轴标定：X[k]X[k]X[k] 的下标 kkk 只是"第几号 bin"，要换算成物理频率（Hz）才能与真实世界对照。每个 bin 的间隔是"采样率 ÷ 点数"（把 [0,fs)[0, f_s)[0,fs​) 均分给 NNN 个 bin），所以第 kkk 个 bin 对应：

fk=k⋅fsNf_k = k \cdot \frac{f_s}{N} fk​=k⋅Nfs​​

读法：kkk 是"第几号"，fs/Nf_s/Nfs​/N 是"每号多少 Hz"。频谱分辨率 Δf=fs/N\Delta f = f_s / NΔf=fs​/N。这给出一个极重要的结论：想要 10 Hz 的频率分辨率，16 kHz 采样下需要 N=16000/10=1600N = 16000/10 = 1600N=16000/10=1600 个样本 = 100 ms 的分析窗。频率分辨率与时间分辨率天然对立——这是测不准原理在信号处理里的化身。

实信号性质：语音 x[n]x[n]x[n] 是实数，则 X[k]=X∗[N−k]X[k] = X^*[N-k]X[k]=X∗[N−k]（共轭对称），信息冗余一半。因此实际只用 k=0,…,N/2k = 0, \dots, N/2k=0,…,N/2 这 N/2+1N/2 + 1N/2+1 个 bin（np.fft.rfft 返回的正是这个）。

1.3 FFT：同一个数学，更快的算法

DFT 直接算要 O(N2)O(N^2)O(N2) 次复数乘法。Cooley–Tukey FFT 利用旋转因子 WN=e−j2π/NW_N = e^{-j2\pi/N}WN​=e−j2π/N 的周期性与对称性做分治，把复杂度降到

O(Nlog⁡2N)O(N \log_2 N) O(Nlog2​N)

这个式子在说什么：NNN 翻倍时，直接法的工作量×4（N2N^2N2），FFT 只×约 2 出头（Nlog⁡NN\log NNlogN）——信号越长，省得越多。

N=1024N = 1024N=1024 时：直接算 ≈106\approx 10^6≈106 次乘法，FFT 只要 ≈104\approx 10^4≈104 次。FFT 不是另一种变换，就是 DFT 的快速算法，结果逐位相同（浮点误差量级 10−1210^{-12}10−12）。

实践约定：n_fft 通常取 2 的幂（512/1024），让 FFT 跑在最速路径。

1.4 幅度谱、对数谱与相位谱的角色分工

  • 幅度谱 ∣X[k]∣|X[k]|∣X[k]∣：语谱图的亮度来源，承载"说了什么"的主要信息（ASR 模型普遍只吃幅度/功率谱）。
  • 相位谱 ∠X[k]\angle X[k]∠X[k]：承载波形的精细时间结构。经典实验（Oppenheim & Lim, 1981）表明：只用相位、把幅度置为常数去重建信号，图像/语音依然可辨认——相位丢了，即使幅度谱完全正确，重建语音也会出现明显的"金属感"失真（第 5 节会亲手验证）。这就是为什么 iSTFT 重建里相位是难点。
  • 对数压缩：人耳对声强的感知接近对数，且语音动态范围大（约 60 dB）。语谱图常用 log⁡(∣X∣+ϵ)\log(|X| + \epsilon)log(∣X∣+ϵ) 或分贝刻度 20log⁡10(∣X∣+ϵ)20\log_{10}(|X|+\epsilon)20log10​(∣X∣+ϵ)，ϵ∼10−5\epsilon \sim 10^{-5}ϵ∼10−5 防 log⁡0\log 0log0。

2. 短时傅里叶变换：给频谱加上时间轴

2.1 为什么整段 FFT 不行

对 10 秒语音做一次 FFT，得到的是"10 秒平均频谱"——发音随时间变化的信息全部丢失。解决：第 1 周的分帧思想——每一帧近似平稳，对每帧单独做 FFT。这就是短时傅里叶变换：

这个公式在干什么：把"切帧 + 加窗 + 一次 DFT"三步打包写成一个式子——从波形里每隔 HHH 个样本取一段（第 mmm 帧取 x[mH],…,x[mH+L−1]x[mH], \dots, x[mH+L-1]x[mH],…,x[mH+L−1]），乘上窗 w[n]w[n]w[n] 削平边缘，再做一次普通 DFT。对每个帧重复，就得到一张二维表格：行是时间（帧）、列是频率（bin），这就是语谱图的原始数据。

X[m,k]=∑n=0L−1x[n+mH] w[n] e−j2πkn/NfftX[m, k] = \sum_{n=0}^{L-1} x[n + mH]\, w[n]\, e^{-j 2\pi k n / N_{\text{fft}}} X[m,k]=n=0∑L−1​x[n+mH]w[n]e−j2πkn/Nfft​

逐符号读：x[n+mH]x[n+mH]x[n+mH] 是"第 mmm 帧的第 nnn 个样本"（mHmHmH 是帧起点），w[n]w[n]w[n] 是长 LLL = win_length 的窗（第 1 周已学），后半段 e−j2πkn/Nffte^{-j2\pi kn/N_{\text{fft}}}e−j2πkn/Nfft​ 就是 1.2 节 DFT 公式里的那个基。

  • NfftN_{\text{fft}}Nfft​ = n_fft：FFT 点数。若 Nfft>LN_{\text{fft}} > LNfft​>L，补零（zero-padding）——补零不提高真实频率分辨率，只是对频谱做插值让曲线更平滑。
  • 输出 X∈CM×(Nfft/2+1)X \in \mathbb{C}^{M \times (N_{\text{fft}}/2 + 1)}X∈CM×(Nfft​/2+1)，MMM 为帧数。

形状公式（默认中心填充时）：

M=1+⌊NsamplesH⌋,频率维=Nfft2+1M = 1 + \left\lfloor \frac{N_{\text{samples}}}{H} \right\rfloor, \quad \text{频率维} = \frac{N_{\text{fft}}}{2} + 1 M=1+⌊HNsamples​​⌋,频率维=2Nfft​​+1

读法：帧数 = “每 HHH 个样本切一刀，加上起手的第一帧”；频率维 = “NfftN_{\text{fft}}Nfft​ 个 bin 利用实信号共轭对称砍掉一半，+1+1+1 是奈奎斯特 bin”（见 1.2 节与思考题 Q2）。

2.2 语音的三大标准参数及其物理意义

参数 典型值（16 kHz） 物理含义
win_length 25 ms = 400 样本 时间分辨率：一帧内近似平稳
hop_length 10 ms = 160 样本 帧率 100 Hz；与窗长比值 = 重叠率（此处 60%）
n_fft 512 频率分辨率 Δf=16000/512=31.25\Delta f = 16000/512 = 31.25Δf=16000/512=31.25 Hz

Whisper 的变体（预告）：25 ms 窗、10 ms 移，但 n_fft=400（等于窗长），频率维 201201201——第 3 周会看到它如何进 80 维 Mel。

重叠率不是摆设：hop 太大（重叠少），帧间的窗函数衔接处会出现幅度凹陷，重建时产生"颤音"伪影；60-75% 重叠是经验安全区（COLA 条件，见 5.2）。

2.3 语谱图（Spectrogram）

取 ∣X[m,k]∣|X[m,k]|∣X[m,k]∣ 并做对数压缩，横轴时间、纵轴频率、亮度为能量，即语谱图。语音语谱图的典型景观：

  • 水平暗带 = 共振峰（formant，元音身份）；
  • 竖直条纹 = 爆破音（/p/ /t/ /k/ 的宽带脉冲）；
  • 周期性竖纹的间隔 = 基频（音高）；
  • 高频噪声团 = 摩擦音（/s/ /sh/）。

读语谱图是语音工程师的基本功，本周交付里必须亲手画并指认这些结构。

3. 手写 STFT：逐行实现与验证

三个易错点都藏在约定里，值得逐条记住：

  1. 窗函数：np.hanning(L) 是对称窗，librosa/scipy 的默认 hann 是周期窗（末尾差一个样本），数值上不同；
  2. 填充量：中心填充补的是 n_fft//2（不是 win_len//2），决定每一帧的时间戳；
  3. 帧长：切帧按 n_fft 切（窗居中补零到 n_fft），而不是按 win_len 切——两者不一致时帧的位置会整体错位。

Shape 解读（务必能手推）：

  • 帧数 101：中心填充下帧数公式为 M=1+⌊N/H⌋=1+⌊16000/160⌋=101M = 1 + \lfloor N/H \rfloor = 1 + \lfloor 16000/160 \rfloor = 101M=1+⌊N/H⌋=1+⌊16000/160⌋=101。直觉：1 秒 × 每 10 ms 一帧 = 100 个间隔，加上首帧共 101 帧。

于是 STFT 输出的物理读法是：(T,257)(T, 257)(T,257)，其中 TTT 按每秒 100 帧增长。10 秒语音 → (1001,257)(1001, 257)(1001,257)。这个"每秒 100 帧"的经验值后面算一切特征长度都要用。

5. 逆变换：iSTFT 与相位重建

5.1 OLA（Overlap-Add）重建

iSTFT 是 STFT 的逆过程：每帧做逆 FFT 得时域帧 → 乘合成窗 → 按 hop 叠放回原位置。

这个公式在干什么：一帧的逆 FFT 只还原出波形的一小段，把它放回原时间位置；相邻帧互相重叠，重叠区同一个样本被多帧各贡献了一次（每次还乘了窗、幅度被压低），所以把所有帧的贡献加起来之后，再除以"这个位置总共被窗加权了多少"（分母），把幅度补回原样——不隆起也不凹陷。

x^[n]=∑mw[n−mH]⋅IFFT(X[m,⋅])[n−mH]∑mw2[n−mH]\hat{x}[n] = \frac{\sum_m w[n - mH] \cdot \text{IFFT}(X[m, \cdot])[n - mH]} {\sum_m w^2[n - mH]} x^[n]=∑m​w2[n−mH]∑m​w[n−mH]⋅IFFT(X[m,⋅])[n−mH]​

分子是所有帧的重叠相加（OLA, Overlap-Add），分母是窗平方和归一化，补偿"每帧都乘了窗"造成的能量衰减。

5.2 COLA 条件

OLA 能完美重建的充分条件是窗函数满足 COLA（Constant Overlap-Add，恒定重叠相加）：任意时刻所有覆盖它的窗值之和为常数。Hann 窗在 50% 重叠时满足；hop = win_len/4（75% 重叠）也满足。窗平方和随时间变化的程度可以用 librosa.filters.window_sumsquare 直接算出来看（就是我们 5.3 代码里的 wsum）。违反 COLA 的症状：重建音频出现周期性音量起伏——这是手写 iSTFT 最常见的 bug。注意：即使 COLA 不严格满足，5.3 的分母归一化也能把起伏补平，代价是帧边缘的归一化分母接近 0、容易放大数值误差。

6. 工程权衡与失效模式

6.1 权衡

  • 窗长↑：频率分辨率↑、时间分辨率↓。基频检测要长窗（≥50 ms），爆破音定位要短窗（≤10 ms）——没有通解，25 ms 是语音折中。
  • hop↓（重叠↑）：时域衔接更平滑、重建更稳，但帧数与计算量线性增长。10 ms 是帧率与质量的平衡点。
  • n_fft > win_length：补零插值让峰值定位更准，不增加真实分辨率，别误读。

6.2 失效模式

  1. 频谱泄漏：矩形窗截断 → 单频正弦在谱上"洇开"成宽瓣。症状：纯音信号频谱不干净；定位：检查窗函数；修复：换 Hann 窗。
  2. iSTFT 重建出现周期性颤音：违反 COLA 或漏了分母归一化。定位：重建一段正弦波看包络；修复：核对窗平方和归一化。
  3. 补零误当高分辨率：把 n_fft=2048 当成"分辨率提高了 4 倍"。真实分辨率只由窗长（有效观测时长）决定。
  4. 中心填充导致的时间戳偏移：下游若按帧索引算时间，要记得 tm=m⋅H/fst_m = m \cdot H / f_stm​=m⋅H/fs​（中心填充下该式恰好成立，非中心填充需加偏移）。

7. 延伸思考题（含解析）

Q1：16 kHz、n_fft=512，第 20 个频率 bin 对应多少 Hz？能分辨 100 Hz 与 120 Hz 的两个正弦吗？
A：Δf=16000/512=31.25\Delta f = 16000/512 = 31.25Δf=16000/512=31.25 Hz，bin 20 = 625 Hz。100 与 120 Hz 间隔 20 Hz < 31.25 Hz，不能分辨；需要 N≥16000/20=800N \ge 16000/20 = 800N≥16000/20=800，取 n_fft=1024（窗长须同步加长才有真实收益）。

Q2：为什么实信号只需存 N/2+1N/2 + 1N/2+1 个 bin？+1+1+1 是哪个频率？
A：共轭对称使后半是冗余。+1+1+1 是奈奎斯特频率 fs/2f_s/2fs​/2 处的 bin（它自己是自己的对称点，必须保留）。

Q3：Whisper 用 n_fft=400（非 2 的幂），为什么不影响甚至更优？
A：现代 FFT 库（如 numpy 用的 pocketfft）对非 2 幂用混合基数算法处理，400=24×52400 = 2^4 \times 5^2400=24×52 因子光滑，速度几乎不亏；400 = 窗长避免补零，且频率维 201 与其 80 维 Mel 滤波器组匹配。工程上 2 幂只是"通常更快"，不是铁律。

Q4：Griffin-Lim 的目标函数是什么？为什么用随机相位初始化？
A：最小化 ∥ ∣STFT(x^)∣−M ∥\|\,|{\rm STFT}(\hat x)| - M\,\|∥∣STFT(x^)∣−M∥（幅度谱匹配），交替投影：时域满足支撑约束 ↔ 频域强制给定幅度。非凸问题，随机初始化相当于多次重启取优；实践中会跑多次选最优或用谱图先验初始化。

Q5：iSTFT 公式分母 ∑mw2\sum_m w^2∑m​w2 的物理作用？若写成 ∑mw\sum_m w∑m​w 会怎样？
A：每帧重建时乘了合成窗 www（分析窗 × 合成窗 = w2w^2w2），分母补偿这个衰减。写成 ∑mw\sum_m w∑m​w 会让重叠区幅度系统性偏大，输出周期性隆起。
