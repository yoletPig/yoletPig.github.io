10 - 凸优化概览

本篇目标

读完本篇，你应该能做到：

  1. 用定义判断一个集合/函数是不是凸的，知道几个常用的判定技巧。
  2. 解释"凸问题为什么好"：局部极小 = 全局极小，以及对偶洞的直觉。
  3. 会写拉格朗日函数，用"约束换进目标"的思路把约束问题转成无约束问题，并陈述 KKT 条件。
  4. 把 SVM 的优化形式读懂，并用 CVXPY 解一个最小示例；查表判断"手头的问题是不是凸的"。

本篇的目标不是教你解凸问题（那是求解器的工作），而是让你认出它们——工程上最值钱的一步是"发现眼前问题原来凸，于是一定有全局最优解"。

1. 凸集与凸函数

1.1 凸集

集合 CCC 是凸的，若对任意 x,y∈Cx, y \in Cx,y∈C 与 θ∈[0,1]\theta \in [0,1]θ∈[0,1]：

θx+(1−θ)y∈C\theta x + (1-\theta) y \in C θx+(1−θ)y∈C

读法：集合里任取两点，连线整段还在集合里。圆盘凸、环不行；半平面凸；两个不相交圆盘的并集不凸（Boyd《Convex Optimization》§2.1）。

1.2 凸函数

函数 fff 是凸的，若定义域是凸集且对任意 x,yx, yx,y 与 θ∈[0,1]\theta \in [0,1]θ∈[0,1]：

f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y)f(\theta x + (1-\theta) y) \le \theta f(x) + (1-\theta) f(y) f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y)

读法：函数图像在任意弦的下方（碗状）。严格凸要求不等号对 x≠yx\ne yx=y 严格成立。

1.3 判定技巧

  • 一阶条件：可微凸函数满足 f(y)≥f(x)+∇f(x)⊤(y−x)f(y) \ge f(x) + \nabla f(x)^\top(y-x)f(y)≥f(x)+∇f(x)⊤(y−x)——每点的切平面全部在函数下方；
  • 二阶条件：二阶可微时 fff 凸   ⟺  \iff⟺ Hessian 处处半正定（09 篇的 Hessian 直接复用）；f=x2f = x^2f=x2 的 Hessian 是 2I2I2I，凸；f=x2−y2f = x^2 - y^2f=x2−y2 不定，不凸；
  • 保凸运算（工程速查）：凸 + 凸 = 凸；仿射变换后仍凸；非负加权和仍凸；max⁡(f,g)\max(f, g)max(f,g) 仍凸；凸函数与非负数复合 h(f(x))h(f(x))h(f(x)) 仍凸（hhh 凸且不降，如 exp⁡\expexp）。组合这些规则能证明 90% 的实用凸性（Boyd §3.2）；
  • 例子：线性函数（既凸又凹）、∥x∥\|x\|∥x∥ 全部范数、exp⁡(x)\exp(x)exp(x)、−log⁡x-\log x−logx、二次型 x⊤Axx^\top A xx⊤Ax（A⪰0A\succeq 0A⪰0）。

2. 为什么凸问题"好"

2.1 局部极小即全局极小

反证：若 x∗x^*x∗ 是局部极小但存在更低的 yyy，则弦 (y,x∗)(y, x^*)(y,x∗) 上的点（凸组合）由凸性保证函数值 ≤θf(x∗)+(1−θ)f(y)<f(x∗)\le \theta f(x^*) + (1-\theta) f(y) < f(x^*)≤θf(x∗)+(1−θ)f(y)<f(x∗)，且这些点可以任意靠近 x∗x^*x∗——与局部极小矛盾。所以凸函数上：找到的任何局部极小就是全局极小，SGD 不会"卡在坏地方"，只存在"还没走到"。

2.2 对偶间隙：另一个礼物

凸问题的对偶问题（3 节）与原问题之间有弱对偶性恒成立（对偶最优值 ≤\le≤ 原问题最优值），且在温和条件下（Slater 条件：存在严格可行点）强对偶成立——上下界重合。非凸问题的对偶可能有"洞"（对偶间隙大），这时对偶界就没用了。这解释了为什么 12 篇里 KL 散度（凸）能当"可优化的代理"而不会骗人。

2.3 求解器生态

凸问题有多项式时间算法（内点法，Boyd §11），成熟求解器（CVXPY/MOSEK/ECOS/OSQP）输入问题描述即出全局最优解+最优性证书。工程含义：一旦建模成凸问题，"如何优化"这个问题本身就消失了。

3. 拉格朗日对偶：约束的"工程用法"

3.1 拉格朗日函数：把约束写进目标

标准形式 min⁡f0(x) s.t. fi(x)≤0, hj(x)=0\min f_0(x)\ \text{s.t.}\ f_i(x) \le 0,\ h_j(x) = 0minf0​(x) s.t. fi​(x)≤0, hj​(x)=0。引入拉格朗日乘子 λi≥0,νj\lambda_i \ge 0, \nu_jλi​≥0,νj​：

L(x,λ,ν)=f0(x)+∑iλifi(x)+∑jνjhj(x)L(x, \lambda, \nu) = f_0(x) + \sum_i \lambda_i f_i(x) + \sum_j \nu_j h_j(x) L(x,λ,ν)=f0​(x)+i∑​λi​fi​(x)+j∑​νj​hj​(x)

工程读法：把违反约束的"价格"加进目标。λ\lambdaλ 是违约单价——目标函数多赚 1 块、违约代价 λ\lambdaλ 块。直觉上 LLL 是"利润 − 罚款"，优化者会选择"要么守规矩要么交罚款"。这把约束优化变成了对 xxx 的无约束优化，这正是深度学习里各种约束处理技巧（惩罚法、增广拉格朗日、ADMM）的原型（经验做法：简单场景直接用大常数惩罚 μfi(x)+\mu f_i(x)_+μfi​(x)+​，精细场景用增广拉格朗日避免病态）。

3.2 对偶函数与对偶问题

对 xxx 最小化 LLL 得到对偶函数 g(λ,ν)=inf⁡xL(x,λ,ν)g(\lambda, \nu) = \inf_x L(x,\lambda,\nu)g(λ,ν)=infx​L(x,λ,ν)。可以证明（Boyd §5.2）：

g(λ,ν)≤p⋆对一切可行乘子成立（弱对偶）g(\lambda, \nu) \le p^\star \quad \text{对一切可行乘子成立（弱对偶）} g(λ,ν)≤p⋆对一切可行乘子成立（弱对偶）

即 ggg 是最优值的下界工厂。把下界最大化（max⁡λ≥0g\max_{\lambda\ge0} gmaxλ≥0​g）就是对偶问题——一个总是凸的问题。强对偶时上下界相遇，λ⋆\lambda^\starλ⋆ 还给出影子价格：约束松 1 单位，目标值变好 ∣λ⋆∣|\lambda^\star|∣λ⋆∣ 单位——资源定价、灵敏度分析全靠它。

3.3 手算一个最小例子

min⁡ x12+x22s.t.x1+x2=2\min\ x_1^2 + x_2^2 \quad \text{s.t.}\quad x_1 + x_2 = 2 min x12​+x22​s.t.x1​+x2​=2

几何：原点为心的等高线圆，与直线 x1+x2=2x_1+x_2=2x1​+x2​=2 的最近切点。拉格朗日函数 L=x12+x22+ν(x1+x2−2)L = x_1^2+x_2^2 + \nu(x_1+x_2-2)L=x12​+x22​+ν(x1​+x2​−2)。驻点条件：

2x1+ν=0,2x2+ν=0⇒x1=x2, 代入约束 x1=x2=1, ν=−22x_1 + \nu = 0,\quad 2x_2 + \nu = 0 \Rightarrow x_1 = x_2,\ \text{代入约束}\ x_1 = x_2 = 1,\ \nu = -2 2x1​+ν=0,2x2​+ν=0⇒x1​=x2​, 代入约束 x1​=x2​=1, ν=−2

最优值 p⋆=2p^\star = 2p⋆=2，ν⋆=−2\nu^\star = -2ν⋆=−2 的影子价格含义：把约束右端放宽为 2.01（圆心到直线距离变化），最优值变为 2.0122=2.0201\frac{2.01^2}{2} = 2.020122.012​=2.0201——每放宽 1 单位代价下降 2 单位，正是 ∣ν⋆∣=2|\nu^\star| = 2∣ν⋆∣=2。（可作为练习自行验证。）

3.4 把对偶函数算出来看看

延续 3.3 的例子，亲手算一次"下界工厂"。对固定的 ν\nuν，先对 xxx 取下确界：

g(ν)=inf⁡x [x12+x22+ν(x1+x2−2)]g(\nu) = \inf_{x}\ \left[x_1^2 + x_2^2 + \nu(x_1+x_2-2)\right] g(ν)=xinf​ [x12​+x22​+ν(x1​+x2​−2)]

对 x1,x2x_1, x_2x1​,x2​ 分别驻点：x1=x2=−ν/2x_1 = x_2 = -\nu/2x1​=x2​=−ν/2，代回：

g(ν)=2⋅ν24+ν(−ν−2)=−ν22−2νg(\nu) = 2\cdot\frac{\nu^2}{4} + \nu(-\nu - 2) = -\frac{\nu^2}{2} - 2\nu g(ν)=2⋅4ν2​+ν(−ν−2)=−2ν2​−2ν

这是一条开口向下的抛物线——对偶问题 max⁡νg(ν)\max_\nu g(\nu)maxν​g(ν)：驻点 −ν−2=0⇒ν=−2-\nu - 2 = 0 \Rightarrow \nu = -2−ν−2=0⇒ν=−2，g(−2)=−2+4=2g(-2) = -2 + 4 = 2g(−2)=−2+4=2。与原问题最优值 p⋆=2p^\star = 2p⋆=2 相等——强对偶达成（此问题满足 Slater 型条件）。整个过程演示了对偶的标准工作流：

  1. 原问题 → 拉格朗日函数（把约束标价）；
  2. 对 xxx 最小化 → 对偶函数（得到最优值的下界曲线）；
  3. 最大化对偶函数 → 对偶最优解与最优乘子。

经验做法：不等式约束时对偶问题天生是凸的（对偶函数是若干仿射函数的逐点下确界），所以"对偶化"是把任意问题至少变成"有一个可算下界"的手段——非凸问题（如整数规划、神经网络验证）的拉格朗日松弛正是这样用于求界与分支定界。

4. KKT 条件

凸问题且强对偶成立时，x⋆x^\starx⋆ 为最优解的充要条件是存在乘子满足Karush–Kuhn–Tucker 条件（Boyd §5.5.3）：

  1. 平稳性：∇f0(x⋆)+∑iλi⋆∇fi(x⋆)+∑jνj⋆∇hj(x⋆)=0\nabla f_0(x^\star) + \sum_i \lambda_i^\star \nabla f_i(x^\star) + \sum_j \nu_j^\star \nabla h_j(x^\star) = 0∇f0​(x⋆)+∑i​λi⋆​∇fi​(x⋆)+∑j​νj⋆​∇hj​(x⋆)=0（拉格朗日函数对 xxx 的梯度为零）；
  2. 原始可行：fi(x⋆)≤0, hj(x⋆)=0f_i(x^\star) \le 0,\ h_j(x^\star) = 0fi​(x⋆)≤0, hj​(x⋆)=0；
  3. 对偶可行：λi⋆≥0\lambda_i^\star \ge 0λi⋆​≥0；
  4. 互补松弛：λi⋆fi(x⋆)=0\lambda_i^\star f_i(x^\star) = 0λi⋆​fi​(x⋆)=0——“要么约束不起作用（λ=0\lambda=0λ=0），要么贴着约束（fi=0f_i=0fi​=0）”。

工程读法：KKT 是"无约束时 ∇f=0\nabla f = 0∇f=0"在约束世界的完整替身；互补松弛解释了 LASSO 为什么大量系数恰好为 0（L1 的解贴在菱形尖角上，03 篇几何在此复活）。SVM 的支撑集（只有少数支撑向量非零）同样是互补松弛的直接产物。

5. 案例：SVM 的优化形式

硬间隔 SVM 的原问题（不必会解，要会读）：

min⁡w,b 12∥w∥2s.t.yi(w⊤xi+b)≥1, ∀i\min_{w, b}\ \frac12\|w\|^2 \quad \text{s.t.}\quad y_i(w^\top x_i + b) \ge 1,\ \forall i w,bmin​ 21​∥w∥2s.t.yi​(w⊤xi​+b)≥1, ∀i

逐项拆解：

  • 目标 12∥w∥2\frac12\|w\|^221​∥w∥2：最大化间隔 =2∥w∥= \frac{2}{\|w\|}=∥w∥2​ 的等价二次形式，系数 1/2 纯为求导去 2；凸（09 篇：Hessian =I≻0= I \succ 0=I≻0）；
  • 约束 yi(w⊤xi+b)≥1y_i(w^\top x_i + b) \ge 1yi​(w⊤xi​+b)≥1：每个样本被正确分类且留出至少 1 的边距（yi∈{±1}y_i \in \{\pm1\}yi​∈{±1}）；
  • 对偶化后由互补松弛可知：只有间隔边界上的点（支撑向量）λi>0\lambda_i > 0λi​>0，其余样本统统 λi=0\lambda_i = 0λi​=0——这就是"支撑向量机"名字的数学来源；
  • 把核技巧 xi⊤xj→K(xi,xj)x_i^\top x_j \to K(x_i, x_j)xi⊤​xj​→K(xi​,xj​) 加进对偶形式，就成了核 SVM——对偶形式让核方法成为可能，这是"为什么要学对偶"的最有力例证。

本篇小结

  • 凸集 = 连线不出界；凸函数 = 弦在曲线上方；判定靠 Hessian 半正定或保凸运算表。
  • 凸问题的两大红利：局部极小即全局极小；强对偶（Slater 条件下）给出可计算的下界与影子价格。
  • 拉格朗日函数 = 目标 + 违约罚款，是"约束→无约束"的通用转换器；对偶函数是下界工厂；手算例子给出 p⋆=2p^\star=2p⋆=2、ν⋆=−2\nu^\star=-2ν⋆=−2。
  • KKT 四条 = 约束世界的"∇f=0\nabla f=0∇f=0"，互补松弛解释稀疏解（LASSO 尖角、SVM 支撑向量）。
  • SVM 原问题逐项可读；CVXPY 让"识别凸性"变成自动检查；查表结论：LP/QP/最小二乘/逻辑回归凸，神经网络/整数规划不凸。

  5. （编程+思考） 用 rng.standard_normal((50, 10)) 造数据，对比三个 CVXPY 问题：最小二乘、ℓ1≤c\ell_1\le cℓ1​≤c 约束版、ℓ2\ell_2ℓ2​ 范数 ≤c\le c≤c 约束版（取 ccc 使解存在），打印三组系数；数一数哪组出现精确的 0——把结果与 KKT 互补松弛、03 篇 L1 尖角几何串成一句话。
