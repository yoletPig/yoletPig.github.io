09 - 堆与优先队列

本篇目标

  1. 手写二叉堆（上浮/下沉），理解"数组存储的完全二叉树"为什么是堆的完美底座；
  2. 对比 TopK 的三种解法（排序/快选/堆）并建立选型判断；
  3. 掌握堆的两类系统级应用：多路归并与调度（优先队列）；
  4. 会用 heapq（含小顶堆取大、懒删除等惯用法）。

1. 优先队列：比"先进先出"更聪明的顺序

队列按到达顺序出队，但真实系统常按重要性出队：OS 调度取最高优先级进程、图算法（11 篇 Dijkstra）取当前最短距离节点、推理引擎取最紧急请求（衔接模型性能优化 Stage 7 的调度组件）。优先队列（priority queue）：支持 push（插入）与 pop（取出最值）的抽象数据类型，两者都 O(log n)、peek 最值 O(1)。

堆（heap）是优先队列最常用的实现。备选方案对比：

实现 push pop 备注
无序数组 O(1) O(n) pop 要扫全表
有序数组 O(n)（找位插入） O(1) push 昂贵
二叉堆 O(log n) O(log n) 标准答案
平衡树 O(log n) O(log n) 功能多但常数大（08 篇）

2. 二叉堆：数组里的完全二叉树

二叉堆 = 完全二叉树 + 堆序性质（父 ≤ 两个孩子，小顶堆；CLRS 第 6 章）。用数组存完全二叉树毫无浪费，且下标关系是纯算术：

两个核心操作，方向相反：

  • 上浮（sift-up）：新元素放在末尾，比父小就交换上移——服务于 push；
  • 下沉（sift-down）：末尾元素换到根，与较小孩子交换下移——服务于 pop。

陷阱：下沉时必须与较小的孩子交换——跟大孩子换会把更小的孩子压在父节点下面，堆序立刻破坏。这是手写堆第一高频 bug。

建堆 O(n)：对 n//2-1 .. 0 逐个下沉，一次建好整个堆。为什么不是 O(n log n)？下沉代价与节点高度成正比，高 h 的节点有约 n/2^(h+1) 个，求和 Σ n/2^(h+1)·O(h) = O(n)（CLRS 6.3 的精确分析：几何级数第四次出场）。heapq.heapify 就是它：

3. TopK 三种解法对比

问题（LC 215/347）：n 个元素里取最大/最小的 k 个（或出现频率前 k 高）。

选型结论（经验做法，与竞赛/工业界共识一致）：

场景 选谁
k ≈ n 排序
一次性、k 小、数据在内存 快速选择
n 很大/数据流/只见过一遍 堆 O(n log k)
面试口述"数据流 TopK" 必答堆 + 提"海量数据用近似算法（如 Count-Min Sketch），经验做法"

4. 多路归并：k 个有序序列合成一个

问题：k 条各长 n 的有序链合成一条。两两归并要 O(kn·log k) 次合并轮次（总代价同阶但常数大）；堆一次搞定 O(kn log k)，且每步只维护 k 个"当前候选"：

为什么对：k 条链的当前头部中必含全局最小（每条链内部有序），弹出后只补充它的后继。这个"维护每路当前候选"的模式还直接服务于：LC 378 有序矩阵第 k 小、LC 632 最小区间（k 个列表的滑动覆盖）。链表版（LC 23 原题）思路全同，只是"下标+1"换成"node.next"。

5. 堆与调度：从 OS 到推理引擎

优先队列是调度系统的核心部件。用一道高频题（LC 621 任务调度器）与一个简化调度器演示：

提示：heapq 只有最小堆。三个惯用法：① 存负数实现最大堆（LC 621）；② (key, seq, item) 复合键破平局且避免比较不可比对象（如 dict）；③ heapreplace 代替"pop 后 push"（一次 sift 而非两次）。懒删除：堆里不支持的"删任意元素"就打标（如记录失效版本号），弹出时跳过——11 篇 Dijkstra 的松弛更新用的正是它。

本篇小结

  1. 优先队列是"按重要性出队"，二叉堆是其标准实现：数组存完全二叉树 + 上浮/下沉，push/pop O(log n)；
  2. 下沉要跟较小孩子换；heapify 建堆 O(n)（几何级数分析）；
  3. TopK 选型：k≈n 排序、一次性快选、数据流用堆 O(n log k)；高频词 = 计数 + 堆；
  4. 多路归并：堆维护 k 路当前候选，O(N log k)；LC 23/378/632 同一模式；
  5. 调度系统 = 优先队列 + 复合键（优先级, 序号）；heapq 三惯用法：负数最大堆、复合键、heapreplace；懒删除是堆的通用补丁。

练习

  1. （LC 215 - 数组中的第K个最大元素）三种解法全部实现并对拍（随机数据对比结果一致性），口述各自复杂度。
  2. （LC 23 - 合并K个升序链表）链表版多路归并，体会"元组里放链表节点引用"需要 seq 破平局。
  3. （LC 295 - 数据流的中位数）经典双堆：大顶堆存小半、小顶堆存大半，两堆大小差 ≤1；这是堆在"动态统计量"上的招牌应用。
  4. （LC 347 - 前 K 个高频元素）用 heapq.nsmallest/nlargest 一行版与手写堆版各写一遍。
  5. （LC 621 - 任务调度器）实现正确的冷却队列轮转逻辑；再写数学公式版 O(n)：(maxCount-1)*(n+1) + 并列最多值的种类数（经验做法：公式版更快但堆版更好讲）。
