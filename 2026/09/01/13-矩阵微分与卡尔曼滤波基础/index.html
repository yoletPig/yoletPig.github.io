13 - 矩阵微分与卡尔曼滤波基础

本篇目标

读完本篇，你应该能做到：

  1. 查表使用最常用的向量/矩阵求导结论，不做"转置猜谜"。
  2. 说清 Jacobian 与 Hessian 分别是什么、什么时候出场。
  3. 从零推导最小二乘的正规方程 A⊤Ax=A⊤bA^\top A\mathbf{x} = A^\top\mathbf{b}A⊤Ax=A⊤b，并用数字算一遍。
  4. 完整推导卡尔曼滤波的预测-更新两步，用 1D 位置估计逐行算 4 个时间步，说清 QQQ 和 RRR 为什么不可省。

本篇直接对接《自动驾驶》Stage 4（卡尔曼滤波）与《PyTorch 与深度学习》02/05 篇（梯度与反向传播）。

2. Jacobian 与 Hessian

2.1 Jacobian：向量函数的一阶导

f:Rn→Rm\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^mf:Rn→Rm 的 Jacobian 是 m×nm\times nm×n 偏导矩阵：

Jij=∂fi∂xj,J=[∇f1⊤⋮∇fm⊤]J_{ij} = \frac{\partial f_i}{\partial x_j}, \qquad J = \begin{bmatrix} \nabla f_1^\top \\ \vdots \\ \nabla f_m^\top \end{bmatrix} Jij​=∂xj​∂fi​​,J=⎣⎢⎢⎡​∇f1⊤​⋮∇fm⊤​​⎦⎥⎥⎤​

几何：JvJ\mathbf{v}Jv 给出"沿 v\mathbf{v}v 方向走一小步，输出怎么变"——它是局部线性化 f(x+Δ)≈f(x)+JΔf(\mathbf{x}+\Delta) \approx f(\mathbf{x}) + J\Deltaf(x+Δ)≈f(x)+JΔ。神经网络反向传播本质是 Jacobian 的转置在计算图上的连乘（m=1m=1m=1 时 J⊤=∇fJ^\top = \nabla fJ⊤=∇f 退化为梯度）。机器人学里的速度映射（关节速度 → 末端速度）也是 Jacobian。

2.2 Hessian：标量函数的二阶导

09 篇已讲：Hij=∂2f/∂xi∂xjH_{ij} = \partial^2 f/\partial x_i\partial x_jHij​=∂2f/∂xi​∂xj​，对称、用于判断凹凸与极值类型。这里补充一条 10 篇用到的联系：对二次型 f=12x⊤Axf = \frac12\mathbf{x}^\top A\mathbf{x}f=21​x⊤Ax，有 ∇f=Ax\nabla f = A\mathbf{x}∇f=Ax、H=AH = AH=A——二次函数的 Hessian 就是它的矩阵，这是"曲率矩阵"具象化的最好例子。

3. 最小二乘的矩阵推导

3.1 正规方程完整推导

给定超定方程 Ax≈bA\mathbf{x} \approx \mathbf{b}Ax≈b（A∈Rm×n,m>nA \in \mathbb{R}^{m\times n}, m > nA∈Rm×n,m>n），求最小化残差平方和的 x\mathbf{x}x：

min⁡x f(x)=∥Ax−b∥22=(Ax−b)⊤(Ax−b)\min_{\mathbf{x}}\ f(\mathbf{x}) = \|A\mathbf{x}-\mathbf{b}\|_2^2 = (A\mathbf{x}-\mathbf{b})^\top(A\mathbf{x}-\mathbf{b}) xmin​ f(x)=∥Ax−b∥22​=(Ax−b)⊤(Ax−b)

展开（用 (AB)⊤=B⊤A⊤(AB)^\top = B^\top A^\top(AB)⊤=B⊤A⊤）：

f=x⊤A⊤Ax−2b⊤Ax+b⊤bf = \mathbf{x}^\top A^\top A\mathbf{x} - 2\mathbf{b}^\top A\mathbf{x} + \mathbf{b}^\top\mathbf{b} f=x⊤A⊤Ax−2b⊤Ax+b⊤b

用规则 3（A⊤AA^\top AA⊤A 对称）与规则 1 求梯度：

∇f=2A⊤Ax−2A⊤b\nabla f = 2A^\top A\mathbf{x} - 2A^\top\mathbf{b} ∇f=2A⊤Ax−2A⊤b

置零（09 篇的驻点条件；A⊤AA^\top AA⊤A 半正定，10 篇凸性保证这就是全局最小）：

 A⊤A x=A⊤b （正规方程）\boxed{\ A^\top A\,\mathbf{x} = A^\top\mathbf{b}\ }\qquad \text{（正规方程）}  A⊤Ax=A⊤b ​（正规方程）

几何读法（02 篇 2.2 节的回收）：Ax^A\hat{\mathbf{x}}Ax^ 是 b\mathbf{b}b 在 AAA 的列空间上的正交投影——残差 Ax^−bA\hat{\mathbf{x}}-\mathbf{b}Ax^−b 垂直于列空间，"垂直"翻译成代数就是 A⊤(Ax^−b)=0A^\top(A\hat{\mathbf{x}}-\mathbf{b}) = \mathbf{0}A⊤(Ax^−b)=0。两条路殊途同归。

4. 协方差传播

4.1 线性变换下的不确定性

随机向量 x\mathbf{x}x 的协方差矩阵为 Σ\SigmaΣ（04 篇：对角线方差、非对角联动）。经过线性变换 y=Ax+c\mathbf{y} = A\mathbf{x} + \mathbf{c}y=Ax+c 后：

E[y]=Aμ+c,Cov(y)=A Σ A⊤\mathbb{E}[\mathbf{y}] = A\boldsymbol{\mu} + \mathbf{c}, \qquad \mathrm{Cov}(\mathbf{y}) = A\,\Sigma\,A^\top E[y]=Aμ+c,Cov(y)=AΣA⊤

推导一行：Cov(y)=E[(A(x−μ))(A(x−μ))⊤]=A E[(x−μ)(x−μ)⊤]A⊤\mathrm{Cov}(y) = \mathbb{E}[(A(\mathbf{x}-\boldsymbol{\mu}))(A(\mathbf{x}-\boldsymbol{\mu}))^\top] = A\,\mathbb{E}[(\mathbf{x}-\boldsymbol{\mu})(\mathbf{x}-\boldsymbol{\mu})^\top]A^\topCov(y)=E[(A(x−μ))(A(x−μ))⊤]=AE[(x−μ)(x−μ)⊤]A⊤。

标量特例：y=2xy = 2xy=2x 则 σy2=4σx2\sigma_y^2 = 4\sigma_x^2σy2​=4σx2​（方差乘 a2a^2a2，06 篇规则的矩阵版）；y=x1+x2y = x_1+x_2y=x1​+x2​（A=[1,1]A = [1, 1]A=[1,1]）则 σy2=σ12+σ22+2Cov\sigma_y^2 = \sigma_1^2 + \sigma_2^2 + 2\mathrm{Cov}σy2​=σ12​+σ22​+2Cov——协方差阵非对角元的正负直接决定叠加后是"滚雪球"还是"对冲"。

这条公式是卡尔曼滤波的引擎：每一步状态转移和观测映射都是线性变换，不确定性沿它传播。

5. 卡尔曼滤波：预测-更新完整推导

5.1 问题的形状

系统是线性的，噪声是高斯的：

xt=Fxt−1+w,w∼N(0,Q)zt=Hxt+v,v∼N(0,R)\mathbf{x}_t = F\mathbf{x}_{t-1} + \mathbf{w},\quad \mathbf{w}\sim N(0, Q) \qquad \mathbf{z}_t = H\mathbf{x}_t + \mathbf{v},\quad \mathbf{v}\sim N(0, R) xt​=Fxt−1​+w,w∼N(0,Q)zt​=Hxt​+v,v∼N(0,R)

x\mathbf{x}x 是要估的状态（如位置+速度），z\mathbf{z}z 是传感器读数。维护对状态的信念：均值 x^\hat{\mathbf{x}}x^ + 协方差 PPP（我们对自己"多不确定"的量化——贝叶斯 posterior 的均值和方差，05 篇的框架在连续世界的落地）。高斯信念 + 线性系统 + 高斯噪声 ⇒ 后验仍是高斯，且只需递推两个矩——这就是卡尔曼 1960 年那篇论文的全部魔法（Kalman, 1960, ASME J. Basic Engineering）。

5.2 预测步（先验）

按运动模型推进信念，不确定性因过程噪声膨胀（4.1 节公式逐项代入）：

x^−=Fx^,P−=FPF⊤+Q\hat{\mathbf{x}}^- = F\hat{\mathbf{x}}, \qquad P^- = F P F^\top + Q x^−=Fx^,P−=FPF⊤+Q

5.3 更新步（贝叶斯）

来了观测 z\mathbf{z}z。三件套（推导见任何估计理论教材，如 Bar-Shalom《Estimation with Applications to Tracking and Navigation》ch. 5；或 R. Labbe 的 Kalman and Bayesian Filters in Python 免费在线书）：

K=P−H⊤(HP−H⊤+R)−1（卡尔曼增益）K = P^- H^\top (H P^- H^\top + R)^{-1} \quad\text{（卡尔曼增益）} K=P−H⊤(HP−H⊤+R)−1（卡尔曼增益）

x^=x^−+K(z−Hx^−)（新估计 = 旧预测 + 增益 × 新息）\hat{\mathbf{x}} = \hat{\mathbf{x}}^- + K(\mathbf{z} - H\hat{\mathbf{x}}^-) \quad\text{（新估计 = 旧预测 + 增益 × 新息）} x^=x^−+K(z−Hx^−)（新估计 = 旧预测 + 增益 × 新息）

P=(I−KH)P−（不确定性收缩）P = (I - K H)P^- \quad\text{（不确定性收缩）} P=(I−KH)P−（不确定性收缩）

读懂数学结构（每个符号都有物理身份）：

  • 新息 y=z−Hx^−\mathbf{y} = \mathbf{z} - H\hat{\mathbf{x}}^-y=z−Hx^−：预测与观测的差，" surprise "；
  • 增益 KKK 的本质是两个不确定度的加权：把 KKK 改写为 K=P−P−+RK = \frac{P^-}{P^- + R}K=P−+RP−​（1D 标量情形）——预测方差 P−P^-P− 大（运动模型没把握）→ K→1K\to1K→1，信观测；观测噪声 RRR 大（传感器不可靠）→ K→0K\to0K→0，信模型。这就是"融合"二字的数学实现；
  • P=(I−KH)P−P = (I-KH)P^-P=(I−KH)P− 保证更新后总不确定度 ≤ 两者任一（信息只增不减，熵减）。

6. 为什么需要 Q 和 R

两个参数不是"调优旋钮"那么简单——它们编码了你对两个世界的信任先验：

  • RRR = 传感器噪声协方差：来自数据手册/标定（IMU 规格表、雷达测距精度）。设得太小 → 滤波器信噪声如信真理，输出抖动；设得太大 → 对真实变化反应迟钝。
  • QQQ = 过程噪声协方差：承认"运动模型不完美"（风、地面颠簸、未建模的机动）。QQQ 设太小 → 滤波器逐渐对模型过度自信，K→0K\to0K→0，滤波发散（观测再也拉不回来——卡尔曼滤波的经典故障模式）；设太大 → 等于宣布模型无用，退化为纯平滑。

经验做法：RRR 用标定值起步；QQQ 扫描调试（跟踪滞后 vs 噪声抑制的权衡）；两者比值决定稳态增益 (P−)2=QR(P^-)^2 = QR(P−)2=QR——改变 Q/RQ/RQ/R 比就是改变滤波器性格。NIS/卡方一致性检验（残差是否匹配预测方差）是判断 Q,RQ,RQ,R 是否诚实的标准工具（Bar-Shalom 书中叫滤波一致性检验）。

7. filterpy 最小示例

实际工程不手写矩阵版卡尔曼——filterpy 是 Python 生态的标准选择（作者 R. Labbe，即上面那本免费书的作者）。

与 5.4 节的关系：标量版是它的对角特例；filterpy 只是替你做了矩阵乘法和数值稳定化（Joseph form 协方差更新等）。先手算理解，再上库——出现发散时你才知道去查 Q/RQ/RQ/R 而不是重装库。

  • Jacobian 是向量函数的局部线性化（反向传播 = Jacobian 转置连乘）；Hessian 是曲率矩阵，二次型的 Hessian 就是矩阵本身。
  • 正规方程 A⊤Ax=A⊤bA^\top A\mathbf{x} = A^\top\mathbf{b}A⊤Ax=A⊤b 从展开+梯度置零推得，等价于"把 b\mathbf{b}b 正交投影到列空间"；数字算例 y^=0.99+1.04t\hat y = 0.99 + 1.04ty^​=0.99+1.04t，SSE =0.042= 0.042=0.042。
