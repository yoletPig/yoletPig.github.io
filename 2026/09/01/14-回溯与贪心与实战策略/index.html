14 - 回溯与贪心与实战策略

本篇目标

  1. 掌握回溯的统一模板：路径 - 选择列表 - 结束条件，排列/组合/子集一模板全覆盖；
  2. 会做回溯的两大剪枝：合法性剪枝与有序性剪枝，理解为什么"先排序"这么常见；
  3. 掌握贪心正确性的交换论证——敢用贪心是因为能证明，不是因为"感觉对"；
  4. 收束全系列：刷题路线、白板沟通规范、复杂度表述模板与综合自测清单。

1. 回溯：有系统地枚举所有可能

回溯（backtracking）= 决策树上的 DFS（10 篇图 DFS 的决策树特化）。三个概念（出自《算法（第 4 版）》回溯章节的表述框架）：

  • 路径：已经做过的选择；
  • 选择列表：当前还能做的选择；
  • 结束条件：路径到达叶子（满足要求/越界）时收集或终止。

模板一个，变体无穷：

陷阱一：result.append(path) 不拷贝——最后所有"答案"都是同一个（已清空的）path。必须 path[:] 或 list(path)。

陷阱二：path.pop() 的撤销必须与 append 严格对称，漏一个就串树。

2. 三件套：子集、组合、排列

三题的差异全部落在"选择列表怎么定义"上：子集/组合用 start 索引（无序），排列用 used 数组（有序）。去重（LC 90/47 输入含重复）：先排序，同层跳过与前一个相同且未使用的元素（if i > start and nums[i] == nums[i-1]: continue）——"先排序"是回溯去重与剪枝的共同前提。

3. 回溯实战：N 皇后与剪枝的艺术

剪枝的两类（经验做法归纳）：合法性剪枝（当前选择直接违反约束，如皇后冲突）与有序性剪枝（利用排序后的单调性提前止损，如 combine 的剩余数量检查、LC 40 组合总和 II 中"同层相同元素跳过"）。写回溯时对着决策树问：哪些分支明知无解还进去？每个"明知"都对应一个可写的剪枝条件。

4. 贪心：用交换论证证明"局部最优 = 全局最优"

贪心：每步取当前最优，永不回头。它比 DP 快得多，但成立需要证明。最常用的证明工具是交换论证（exchange argument）：假设存在最优解与贪心选择不同，证明"交换后不变差"，逐步把最优解变换成贪心解——贪心至少一样优。

例 1：区间调度（LC 435 无重叠区间/452 射气球）——按结束时间排序，能选就选：

为什么按结束时间而不是开始时间/长度：按开始排，一个很早开始但巨长的区间霸占全场；按长度排，反例 [1,10],[9,11],[10,20]（最短者 9-11 同时挡住两个）。交换论证能证"结束最早"对，其余证不出来——证明本身就是选型的依据。

贪心 vs DP 的判断口诀（经验做法）：能用交换论证证明"当前最优不损害未来" → 贪心；决策之间有相互牵制、必须比较多种"当前选择"的后果 → DP。面试拿不准时先讲贪心思路与证明，证明不出再退 DP——展示的是"知道何时贪心不成立"。

5. 面试实战：刷题路线

结合本系列 14 章，给一条可执行的路线（经验做法，综合常见面试准备共识）：

  1. 第 1–2 周（地基）：01–03 章读完，LC 热身 100 题（哈希/双指针/数组）每天 3–5 题，练"读题 → 复杂度判断 → 选结构"的条件反射；
  2. 第 3–4 周（线性结构与二分）：04–06 章 + LC 20/84/239/3/76/33/34。这批题套路浓度最高，每题写完写一行"不变式注释"；
  3. 第 5–6 周（递归与树）：07–09 章 + LC 226/104/98/236/215/347/295。树题先说"先序/中序/后序哪一种信息流向"再动笔；
  4. 第 7–8 周（图论）：10–11 章 + LC 200/207/210/785/743/1584。重点练建模：把题面翻译成"节点是什么、边是什么、权是什么"；
  5. 第 9–10 周（DP 与回溯）：12–14 章 + LC 70/198/300/62/72/416/78/46/55/435。DP 题先写记忆化再写递推，回溯题先画决策树；
  6. 持续：每章"练习"部分当作业；错题隔三天重做（间隔重复，经验做法）；临面试两周只做"限时模拟 + 口述"。

目标岗位侧重（本仓库读者画像）：推理优化/系统岗加重 01（复杂度）、09（堆/调度）、11（最短路/A*）；自动驾驶岗加重 10–11（图、匈牙利前置的二分图）与 12（状态估计的递推思想）；量化岗加重 03（哈希）、09（TopK）、13（组合约束=背包）。

6. 白板沟通规范：把思考过程变成得分点

面试考的是协作沟通，不只是答案（经验做法，与大厂面试官公开分享的口径一致）：

  1. 复述与澄清（1–2 分钟）：用自己的话复述题目，主动问清：输入规模？有无重复/负数/为空？要求最优解还是任意解？——这些直接决定复杂度档位；
  2. 先给暴力解：说清 O(n²) 暴力并指出瓶颈（“瓶颈在对每个 i 重复找 target-x”），这一步展示完整性；
  3. 提出优化并说依据：'瓶颈是查找 → 哈希表 O(1) 查找 → 总 O(n)"——每个优化都挂在 01 章的复杂度语言上；
  4. 说不变式再写代码：双指针说"两端淘汰的安全性"，二分说区间定义，回溯说决策树结构。边写边讲；
  5. 主动跑测试：写完立刻用空输入、单元素、极值、典型例走一遍——面试官等着看你有没有这个习惯；
  6. 复杂度表述模板：“时间 O(n log n)，来自排序；空间 O(n)，来自哈希表。”——时间与空间分开说、都给出处，这是 01 章要求的面试落地版。忌说"大概是 n 平方吧"这种无出处表述。

7. 综合自测清单

能独立回答以下问题，说明本系列过关（每题都在对应章节）：

  1. 01：n=10^5、时限 1s，你的复杂度预算是多少？摊还分析为什么能证明 append 是 O(1)？
  2. 02：为什么工业代码"默认数组、慎用链表"？哨兵节点消灭了什么特判？
  3. 03：Python dict 用开放寻址还是拉链？负载因子超 2/3 会发生什么？
  4. 04：单调栈的 O(n) 是怎么均摊出来的？单调队列队头队尾各管什么？
  5. 05：滑动窗口的左指针每一步为什么"安全"？最小覆盖子串的 missing 计数怎么工作？
  6. 06：lower_bound 的区间约定与不变式？二分答案的 check 函数需要什么性质？
  7. 07：递归三要素？快排最坏输入是什么、随机化为什么有效？主定理三种情形各配一个例子？
  8. 08：验证 BST 为什么不能只比较孩子？AVL 旋转保持什么不变？
  9. 09：手写堆下沉为什么与"较小孩子"交换？TopK 三解法各在什么场景最优？
  10. 10：BFS 入队即标记防什么？Kahn 算法怎么"顺便"检环？二分图判定定理是什么？
  11. 11：Dijkstra 为什么怕负权？A* 的 h 可采纳是什么意思、h=0 退化成什么？
  12. 12：DP 两要素？LIS 的状态为什么必须"以 i 结尾"？
  13. 13：0-1 背包一维化为什么倒序？组合数与排列数的外层枚举对象怎么定？
  14. 14：交换论证的证明套路？回溯的 path 为什么要拷贝？

本篇小结

  1. 回溯 = 决策树 DFS：路径/选择列表/结束条件三件套，三经典题差异全在"选择列表"定义；
  2. 剪枝分两类：合法性（约束违反）与有序性（排序后单调止损）；先排序是去重与剪枝的共同前提；
  3. 贪心的正确性用交换论证证明：区间调度按结束时间、跳跃游戏维护 furthest——证明本身就是选型依据；
  4. 面试流程六步：复述澄清 → 暴力 → 优化依据 → 不变式 → 测试 → 双复杂度给出处；
  5. 刷题路线按本系列章节节奏推进，间隔重复 + 限时口述是内化的关键。

练习

  1. （LC 90 - 子集 II）含重复元素的子集：排序 + 同层去重，写出"为什么去重条件是 i > start"的解释。
  2. （LC 51/52 - N 皇后）实现完整解并输出棋盘（不止计数）；对比无剪枝版本（只查 row/col）的运行时间差异。
  3. （LC 45 - 跳跃游戏 II）最少跳跃次数：贪心 + 交换论证（当前层 furthest 撑到头时步数 +1）；再写 DP 版对比。
  4. （LC 56 - 合并区间）排序 + 线性扫描：按左端点排序后，为什么合并是安全的？用交换论证写两句证明。
  5. （LC 301 - 删除无效的括号）回溯综合题：计数剪枝（左括号余量）+ 去重集合，体会"合法性剪枝"与"状态去重"的组合。
