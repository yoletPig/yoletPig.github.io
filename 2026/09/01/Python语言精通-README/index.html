Python 语言精通：从语法使用者到语言专家

面向已经"会用 Python 写脚本"的学习者：你知道 def、class、for 怎么写，但说不清 is 和 == 的区别、闭包捕获的是变量还是值、yield 暂停时解释器在干什么、GIL 到底挡住了谁、asyncio 的协程和线程是不是一回事。本系列补的就是这一层：不是语法书，而是 Python 的对象模型、并发模型与工程化写法——语法是查表就能会的事实，而这层理解决定了你读得懂 vLLM 源码、写得出生产级 Agent 服务。
事实基准：按 Python 3.10+ 编写（3.13 free-threading 现状在 07 篇如实介绍），关键论断标注 Python 官方文档 / PEP 编号 / 《Fluent Python》，所有代码标准库优先，可运行、可复现。

学习路径

篇 主题 你将学会
01-对象模型与命名 一切皆对象、可变/不可变、引用语义 用 id/is 解释赋值、别名与小整数缓存陷阱；CPython 的引用计数 + 分代 GC
02-函数深入 一等公民、闭包、可变默认参数 默认参数在 def 时求值（经典面试题）、闭包与 nonlocal、*args/**kwargs
03-装饰器 手写装饰器与执行时机 无参/带参装饰器、functools.wraps、多层顺序、Agent 工具注册模式
04-迭代器与生成器 迭代协议、yield 执行流 __iter__/__next__、逐步图解 yield、yield from、惰性求值省内存实测
05-上下文管理器 with 原理与资源管理 __enter__/__exit__、contextmanager、异常抑制、ExitStack、事务/锁的正确用法
06-类型注解与现代语法 typing、dataclass、match TypeVar/Protocol 静态鸭子类型、mypy 上手、3.10+ match、f-string 进阶
07-GIL与并发模型 GIL 与并发选型 CPU/IO 密集实测对比、GIL 为什么挡不住 IO 并发、3.13 free-threading 现状
08-多线程与多进程 threading 与 multiprocessing 锁与竞态（银行账户反例）、queue.Queue、Pool、pickle 限制、concurrent.futures
09-asyncio基础 事件循环与 async/await 协作式调度心智模型、何时让出控制权、gather/wait_for、取消与超时规范
10-asyncio进阶与实战 并发爬虫与线程/进程混用 Lock/Semaphore/Queue、限流+重试+超时完整实战、to_thread、同步 vs 异步实测
11-元类与描述符 属性查找与 ORM 原理 MRO、描述符协议（@property 的本质）、校验描述符、元类自动注册（pydantic/SQLAlchemy 原理）
12-import系统与模块工程 import 机制与项目布局 sys.modules/查找器、循环导入解法、相对导入、importlib 插件系统
13-性能剖析与优化 不要猜要测 cProfile/timeit 规范、常见优化手段实测收益、__slots__、何时优化
14-常见陷阱与代码规范 十大陷阱与评审清单 每条陷阱反例+正解、PEP 8 关键条目、ruff/black 工具链、代码评审模板

阶段划分

  1. 对象模型（01–03）：一切皆对象 → 函数是一等对象 → 装饰器。这一层打通后，框架源码里的"魔法"大半现形。
  2. 协议与抽象（04–06）：迭代器/生成器、上下文管理器、类型注解——Python 的核心设计哲学是"协议"，这三篇就是协议的三大主力。
  3. 并发（07–10）：GIL 是什么、什么时候用线程/进程/协程，asyncio 从心智模型到实战。这是 Agent 开发与推理服务的命脉。
  4. 语言机制与工程化（11–14）：元类/描述符（读 ORM/pydantic 源码的门票）、import 系统、性能剖析、陷阱与规范——从"能写"到"写得专业"。

与本仓库其他系列的衔接

  • uv 系列：分工明确——uv 系列是工具链层（环境、依赖、锁文件、打包），本系列是语言层（对象模型、并发、写法）。12 篇的项目布局规范直接对接 uv 02 篇的 uv init 项目骨架；
  • Agent 开发系列：其中 asyncio 并发是命脉——09/10 两篇把"为什么 Agent 的工具调用要并发""CancelledException 怎么处理"从语言机制讲透；14 篇的评审清单可用于 Agent 代码 review；
  • 模型性能优化系列：Stage 5 读 vLLM 源码的前提是理解 元类/描述符（vLLM 的模型注册、配置类大量使用，11 篇）与 asyncio（vLLM 的引擎调度器是 asyncio 写的，09/10 篇）——本系列就是那两把钥匙；
  • 算法与数据结构系列：13 篇的 timeit 剖析规范，是验证"算法复杂度"之外常数级差异的标准工具。

约定

  • Python 3.10+（match 语句、X | Y 联合类型语法等按 3.10 基准；3.12/3.13 新特性出现时会显式标注）；
  • 所有代码标准库优先，用到第三方库（如 13 篇的 line_profiler）会显式说明；
  • 交互式示例统一用 >>> 表示 REPL 输入，紧跟真实输出（repr 形式）；脚本示例给出预期输出注释；
  • 关键论断给出出处：Python 官方文档（docs.python.org）、PEP 编号、《Fluent Python》（第 2 版，Luciano Ramalho）；
  • 标注 “经验做法” 的段落是工程实践经验，不是语言规范，按团队约定取舍。
