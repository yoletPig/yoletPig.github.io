07 - 递归与分治

本篇目标

  1. 把递归从"函数调自己"升级为"数学归纳法的执行"，掌握递归三要素的检查清单；
  2. 理解调用栈与递归深度的关系，知道 Python 的深度限制与尾递归的真相；
  3. 吃透分治双璧：归并排序与快速排序（含 _partition 手写与随机化）；
  4. 掌握快速选择（TopK 的期望 O(n) 解法）与主定理（Master Theorem）的使用。

1. 递归三要素：先把"信任"建立起来

写递归最忌讳"脑内展开调用树追第三层"——人脑栈会溢出。正确姿势是信任归纳：只看一层。三要素检查清单（经验做法，与 MIT 6.006 教学口径一致）：

  1. 基准情形（base case）：最小的输入直接返回，不递归。缺它=无限递归（Python 里体现为 RecursionError）；
  2. 递归步骤：调用自己解决规模严格更小的同类问题。不缩小=死递归；
  3. 合并（combine）：相信子问题答案正确，用它们拼出本层答案。这一步是逻辑全部所在。

正确性论证就是数学归纳法：基准情形成立（n=1）；假设 n−1 时正确，推出 n 时正确（要素 3 做的事）。所以只要三要素都成立，递归必然正确——不用展开树，一层内完成证明。

2. 调用栈：递归的空间代价与 Python 的限制

每次函数调用在**调用栈（call stack）**上压一个栈帧（局部变量、返回地址）。递归深度 d 的算法栈空间 O(d)——这就是"递归版反转链表 O(n) 空间"的来源（02 篇练习埋的伏笔）。

Python 的调用栈深度默认上限约 1000（sys.getrecursionlimit()，CPython 文档），超了抛 RecursionError。工程对策按优先级：

  1. 改成迭代（显式栈/循环）——首选；
  2. sys.setrecursionlimit() 调大——只适合自知的浅层场景，盲目调大有段错误风险（C 栈溢出，经验做法）；
  3. 分治算法尽量平衡（深度 log n），天然安全。

尾递归（递归调用是函数最后一个动作）理论上可被编译器优化成循环、栈空间 O(1)。但CPython 不做尾递归优化（Guido 的明确决定，历史上多次讨论不采纳），所以 Python 里写尾递归没有性能意义——必须写成迭代：

3. 分治：归并排序

分治（divide and conquer）三步：分（divide）→ 治（conquer）→ 合（combine）。归并排序是结构最纯正的例子：

复杂度推导（递归式）：T(n) = 2T(n/2) + O(n)。每层合并总代价 O(n)，共 log n 层 → O(n log n)。这就是主定理的第一个实战案例（第 6 节）。归并排序的两个工程价值：稳定（相等元素保持原序，多关键字排序的基石）与最坏 O(n log n) 有保证（对比快排）；代价是 O(n) 辅助空间。链表版归并用快慢指针找中点可做到 O(1) 额外空间（02 篇第 5 节），LC 148 排序链表正是它。

4. 快速排序与 _partition

快排的分治方向与归并相反：先在原地做"划分"（partition）再递归，合并是免费的（原地）。

_partition 的不变式（面试必画图讲）：扫描指针 j 把数组切成三段——[lo, i] ≤ pivot、(i, j) > pivot、[j, hi] 未看；a[j] <= pivot 就扩张左段。最后 pivot 与左段右端交换归位。

陷阱一（工程）：已排序数组是 Lomuto+固定基准的最坏输入（每层只切出一个元素，O(n²)）——真实数据大量"接近有序"，所以工业实现（如 C++ std::sort 的 introsort 混合策略、Python Timsort）都有对抗手段。Python 内置 sorted() 是 Timsort：归并思想的混合变体，稳定、对部分有序数据接近 O(n)（出处：CPython listsort.txt，Tim Peters）。

陷阱二（细节）：快排不稳定（划分交换会打乱相等元素相对序）；对稳定性有要求就换归并。

5. 快速选择：TopK 的期望 O(n)

问题：n 个数里找第 k 大（LC 215）。排序 O(n log n)、堆 O(n log k)（09 篇）；更快的是快速选择（quickselect）：partition 之后答案在哪半边已知，只递归一边：

递归式 T(n) = T(n/2) + O(n) 展开是 n(1 + 1/2 + 1/4 + …) < 2n——几何级数再次出场（01 篇、03 篇扩容，这是第三次，值得形成条件反射：砍半递归 + 线性单层 = 线性总量）。

6. 主定理：分治复杂度的速查表

分治递归式 T(n) = a·T(n/b) + f(n)（a 个子问题、每个规模 n/b、分解合并代价 f）。主定理（Master Theorem，出处：CLRS 4.6；也可表述为 Akra-Bazzi 特例）：比较 f(n) 与 n^(log_b a)——即"叶子代价"与"根上代价"谁占主导：

f(n) 与 n^(log_b a) 的关系 结论 实例
f 更小（多项式意义上） T(n) = Θ(n^(log_b a)) T(n)=2T(n/2)+O(1)：二叉树遍历 Θ(n)
同阶（差个 log^k） T(n) = Θ(n^(log_b a) · log n) T(n)=2T(n/2)+O(n)：归并 Θ(n log n)
f 更大且可正则 T(n) = Θ(f(n)) T(n)=2T(n/2)+O(n log n)：Θ(n log²n)

用法（经验做法）：算出 n^(log_b a)，与 f 比大小——谁大听谁的，同阶乘个 log。三个算法对号入座：归并 a=2,b=2,f=n → n^(log₂2)=n 同阶 → n log n；二分查找 a=1,b=2,f=O(1) → n⁰=1 同阶 → log n；快速选择 a=1,b=2,f=O(n) → f 大 → O(n)。

提示：主定理是"速查"不是"推理工具"。面试讲复杂度时，先口头展开"每层代价 × 层数"（几何级数或算术级数），再报主定理验证——比直接背结论可信。

本篇小结

  1. 递归 = 数学归纳法的执行：三要素（基准、缩小、合并）齐全即正确，一层内思考不展开树；
  2. 递归空间 = 调用栈深度 O(d)；CPython 无尾递归优化，尾递归手动转循环；
  3. 归并：稳定、恒定 O(n log n)、O(n) 空间；快排：原地、平均 O(n log n)、最坏 O(n²) 靠随机化对抗；Timsort 是两者的工程混合体；
  4. _partition 不变式是快排与快速选择共同的核心；只递归一边，快速选择把 TopK 做到期望 O(n)；
  5. 主定理口诀：n^(log_b a) 与 f 谁大听谁的，同阶乘 log。

练习

  1. （LC 148 - 排序链表）要求 O(n log n)：链表归并排序，快慢指针找中点 + 断开 + 递归 + 合并（02 篇两个工具的组合）。
  2. （LC 50 - Pow(x, n)）快速幂：n 为偶数拆半、奇数乘 x，O(log n) 递归与迭代各写一版，体会"分治拆半"。
  3. （LC 215 - 数组中的第K个最大元素）快选解法之外，再用小顶堆解一遍（09 篇），两种复杂度 O(n) 期望 vs O(n log k) 的适用场景各是什么？
  4. （LC 241 - 为运算表达式设计优先级）分治：每个运算符都是一次"分"，左右递归算出所有可能值再合并。
  5. （LC 105 - 从前序与中序遍历序列构造二叉树）分治：根分左右两半递归建树，写清基准情形与合并逻辑。
