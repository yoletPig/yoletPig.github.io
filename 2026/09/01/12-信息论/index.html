12 - 信息论

本篇目标

读完本篇，你应该能做到：

  1. 计算任意离散分布的熵，说出"熵 = 平均惊讶度 = 最优平均码长下界"这两层含义。
  2. 写出交叉熵与 KL 散度的关系式 H(p,q)=H(p)+KL(p∥q)H(p,q) = H(p) + \mathrm{KL}(p\|q)H(p,q)=H(p)+KL(p∥q)，并用数字演示 KL 的非对称性。
  3. 说清正向 KL 与反向 KL 的行为差异（mode-covering vs mode-seeking），以及训练中为什么常用反向 KL。
  4. 用互信息回答"相关系数漏掉了什么"，并把困惑度、GPT 损失函数放进同一张图。

本篇是《VLM & VLA》Stage 1/6（交叉熵、KL 对齐）与语音方向（CE loss）的理论源头。

1. 自信息与熵

1.1 自信息：惊讶度的度量

一个概率为 ppp 的事件发生，你有多惊讶？信息论给的定义：

I(x)=log⁡21p(x)=−log⁡2p(x)单位: bitI(x) = \log_2 \frac{1}{p(x)} = -\log_2 p(x) \quad \text{单位: bit} I(x)=log2​p(x)1​=−log2​p(x)单位: bit

三条性质决定了它只能长这样（Cover & Thomas《Elements of Information Theory》第 2 章）：概率越小越惊讶（单调递减）；必然事件（p=1p=1p=1）零惊讶；独立事件同时发生，惊讶度相加（log⁡\loglog 把乘法变加法）。数字手感：p=0.5p = 0.5p=0.5 → 1 bit；p=0.1p = 0.1p=0.1 → 3.32 bits；p=0.01p = 0.01p=0.01 → 6.64 bits。

1.2 熵：平均惊讶度

熵是自信息在分布上的期望：

H(p)=−∑xp(x)log⁡2p(x)H(p) = -\sum_x p(x)\log_2 p(x) H(p)=−x∑​p(x)log2​p(x)

  • 抛均匀硬币：H=−2×12log⁡212=1H = -2\times\frac12\log_2\frac12 = 1H=−2×21​log2​21​=1 bit——一次抛硬币最多携带 1 bit；
  • 偏硬币 p=(0.9,0.1)p = (0.9, 0.1)p=(0.9,0.1)：H=−0.9log⁡20.9−0.1log⁡20.1=0.9(0.152)+0.1(3.322)=0.137+0.332=0.469H = -0.9\log_2 0.9 - 0.1\log_2 0.1 = 0.9(0.152) + 0.1(3.322) = 0.137 + 0.332 = 0.469H=−0.9log2​0.9−0.1log2​0.1=0.9(0.152)+0.1(3.322)=0.137+0.332=0.469 bit——越偏越确定，熵越低；
  • 均匀分布是同支撑集上熵最大的分布（最大可到 log⁡2n\log_2 nlog2​n）。

工程解读：熵衡量"这个随机源平均每次输出带来多少不确定度"。语言建模、策略优化、特征选择里的一切"信息量"讨论都以它为地基。

2. 编码视角：熵是最优平均码长的下界

2.1 从"压缩"理解熵

把随机源的输出编码成 0/1 串传输。香农无噪声编码定理（Cover & Thomas 第 5 章）：

任何无损编码方案的平均码长 Lˉ≥H(p)\bar{L} \ge H(p)Lˉ≥H(p)，且存在编码（如算术编码）使 Lˉ\bar{L}Lˉ 任意接近 H(p)H(p)H(p)。

熵 = 压缩的理论极限。直觉：给高概率符号配短码、低概率符号配长码（Huffman 思想），平均码长才能压到下界。

2.2 数字演示

偏硬币 p=(0.9,0.1)p = (0.9, 0.1)p=(0.9,0.1)：单符号最优编码也得各 1 bit，平均码长 1 bit——离 H=0.469H = 0.469H=0.469 很远。但把两个输出打包成一个块（4 种块：正正/正反/反正/反反，概率 0.81/0.09/0.09/0.010.81/0.09/0.09/0.010.81/0.09/0.09/0.01）做 Huffman，平均码长约 0.9 bit/符号；块长 4、8 时逐步逼近 0.469。

为什么训练视角关心这个：损失函数 = 平均负对数似然 = 模型对数据分配的平均自信息。损失逼近数据在模型下的熵，就是"模型把数据压缩到极致"的另一种说法——语言模型的 next-token 预测本质是在学压缩（这一观点的展开见 Hutter 奖与 recent “LLM=compressor” 文献）。

3. 交叉熵与 KL 散度

3.1 定义与恒等式

用分布 qqq 给"真实来自 ppp 的数据"编码的平均码长叫交叉熵：

H(p,q)=−∑xp(x)log⁡2q(x)H(p, q) = -\sum_x p(x)\log_2 q(x) H(p,q)=−x∑​p(x)log2​q(x)

它与 KL 散度（相对熵）只差一个常数：

KL(p∥q)=∑xp(x)log⁡2p(x)q(x)=H(p,q)−H(p)  ≥  0\mathrm{KL}(p \| q) = \sum_x p(x)\log_2\frac{p(x)}{q(x)} = H(p, q) - H(p) \;\ge\; 0 KL(p∥q)=x∑​p(x)log2​q(x)p(x)​=H(p,q)−H(p)≥0

KL = 用错误分布 q 编码 p 数据时，多付的平均码长（惩罚/税）。等号当且仅当 p=qp = qp=q。这两个量的差 H(p)H(p)H(p) 与模型无关，所以最小化交叉熵   ⟺  \iff⟺ 最小化 KL——分类训练里两个词混用而不出错的数学原因（07 篇从 MLE 角度推过同一个结论）。

3.2 非对称性：数值演示

KL 不是距离——它没有对称性，也没有三角不等式。取 P=(0.5,0.5)P = (0.5, 0.5)P=(0.5,0.5)（公平硬币），Q=(0.9,0.1)Q = (0.9, 0.1)Q=(0.9,0.1)（偏硬币）：

KL(P∥Q)=0.5log⁡20.50.9+0.5log⁡20.50.1=0.5(−0.848)+0.5(2.322)=0.737 bit\mathrm{KL}(P\|Q) = 0.5\log_2\frac{0.5}{0.9} + 0.5\log_2\frac{0.5}{0.1} = 0.5(-0.848) + 0.5(2.322) = 0.737\ \text{bit} KL(P∥Q)=0.5log2​0.90.5​+0.5log2​0.10.5​=0.5(−0.848)+0.5(2.322)=0.737 bit

KL(Q∥P)=0.9log⁡20.90.5+0.1log⁡20.10.5=0.9(0.848)+0.1(−2.322)=0.531 bit\mathrm{KL}(Q\|P) = 0.9\log_2\frac{0.9}{0.5} + 0.1\log_2\frac{0.1}{0.5} = 0.9(0.848) + 0.1(-2.322) = 0.531\ \text{bit} KL(Q∥P)=0.9log2​0.50.9​+0.1log2​0.50.1​=0.9(0.848)+0.1(−2.322)=0.531 bit

同一对分布，两个方向差 0.206 bit。方向不同，"错在哪里被罚得最重"完全不同——这正是下一节的主题。

3.3 正向 KL 与反向 KL：行为差异

设 ppp 是复杂目标分布（比如双峰），qqq 是简单的近似族（比如单高斯）。最小化两个方向会得到性格相反的 qqq：

  • 正向 KL(p∥q)\mathrm{KL}(p\|q)KL(p∥q)（期望在 ppp 下取，即"数据采样"方向）：qqq 被迫覆盖 ppp 的所有高概率区，否则 ppp 处 q→0q\to0q→0 会被罚到无穷（log⁡(p/q)\log(p/q)log(p/q) 爆炸）——mass-covering，摊开贴。用一批来自 ppp 的样本就能算（每次 −log⁡q(xi)-\log q(x_i)−logq(xi​) 的均值），这就是 MLE/监督学习的可计算性来源：交叉熵损失 = 正向 KL 里的模型项；
  • 反向 KL(q∥p)\mathrm{KL}(q\|p)KL(q∥p)（期望在 qqq 下取）：qqq 只敢待在 ppp 的某个峰附近，一旦踏上 p=0p=0p=0 的区域罚到无穷——mode-seeking，锁峰。

为什么变分推断/蒸馏训练常用反向 KL（严格说"反向"是相对数据拟合方向而言）：因为 KL(q∥p)\mathrm{KL}(q\|p)KL(q∥p) 的期望在 qqq 下取——而 qqq 是我们自己输出的分布，可以采样、可以解析求导；ppp 往往只有未归一化的形式（采样不可行），反向 KL 恰好只需要"在 q 的样本处评估 p"，把不可算变成了可算（变分推断 ELBO、VAE、RLHF 中的策略约束均如此，MacKay《Information Theory, Inference and Learning Algorithms》ch. 33 的双峰图是标准演示）。代价是模式坍缩——反向 KL 只解释一个峰，这正是 VAE 后验"保守"、蒸馏学生模型"偏科"的数学根源。

4. 互信息：相关系数的"非线性补丁"

4.1 定义

I(X;Y)=KL(p(x,y) ∥ p(x)p(y))=H(X)−H(X∣Y)I(X;Y) = \mathrm{KL}\big(p(x,y)\,\|\,p(x)p(y)\big) = H(X) - H(X\mid Y) I(X;Y)=KL(p(x,y)∥p(x)p(y))=H(X)−H(X∣Y)

读法：知道 YYY 之后，XXX 的不确定度减少了多少。性质：非负；独立时为 0；对称（I(X;Y)=I(Y;X)I(X;Y) = I(Y;X)I(X;Y)=I(Y;X)）；能捕捉任意统计依赖。

4.2 与相关系数的区别

相关系数 ρ\rhoρ 只度量线性关系。构造反例：Y=X2Y = X^2Y=X2，X∼N(0,1)X \sim N(0,1)X∼N(0,1)——Cov(X,Y)=0\mathrm{Cov}(X,Y) = 0Cov(X,Y)=0（对称性抵消），ρ=0\rho = 0ρ=0，但 YYY 由 XXX 完全决定，I(X;Y)>0I(X;Y) > 0I(X;Y)>0 且相当大。

经验做法：特征筛选时 ρ\rhoρ 只能抓线性冗余，I(X;Y)I(X;Y)I(X;Y) 抓任意依赖但估计需要更多样本且对分箱敏感；两者是互补而非替代。ρ=0\rho=0ρ=0 绝不等于独立，I=0I=0I=0 才等于独立——这句话在量化（因子正交化）与因果筛查里都救命。

5. 困惑度：语言模型的体温计

5.1 定义

困惑度（perplexity）= 交叉熵的指数化：

PPL=2H(p,q)=e NLL‾nats\mathrm{PPL} = 2^{H(p, q)} = e^{\ \overline{\mathrm{NLL}}_{\text{nats}}} PPL=2H(p,q)=e NLLnats​

读法：“模型平均在每个位置像在多少个词里纠结”。均匀猜 1000 词的词表：PPL=1000\mathrm{PPL} = 1000PPL=1000；若模型把平均 NLL（以 e 为底）压到 3.2 nats，PPL=e3.2≈24.5\mathrm{PPL} = e^{3.2} \approx 24.5PPL=e3.2≈24.5——相当于每个位置在约 25 个词里犹豫。

5.2 使用须知（经验做法）

  • 困惑度只在同一词表、同一分词器、同一数据切分下可比——BPE 词表不同则 PPL 不可横向对比；
  • PPL 低不等于下游任务好（它度量"拟合文本分布"，不度量指令遵循/推理）；
  • 训练日志里 loss ≈ 2.7（nats）与 PPL ≈ 14.9 是同一个数的两种写法（e2.7≈14.88e^{2.7} \approx 14.88e2.7≈14.88）。

6. GPT 损失函数 = 交叉熵的完整解释

把全链条一次打通。GPT 是自回归语言模型：给定前文 x<tx_{<t}x<t​，输出词表上的分布 qθ(⋅∣x<t)q_\theta(\cdot \mid x_{<t})qθ​(⋅∣x<t​)（softmax）。训练目标是最小化：

L(θ)=−1T∑t=1Tlog⁡qθ(xt⋆∣x<t)L(\theta) = -\frac{1}{T}\sum_{t=1}^{T}\log q_\theta(x_t^\star \mid x_{<t}) L(θ)=−T1​t=1∑T​logqθ​(xt⋆​∣x<t​)

逐层拆解这一行：

  1. 每个 −log⁡qθ(xt⋆∣x<t)-\log q_\theta(x_t^\star\mid x_{<t})−logqθ​(xt⋆​∣x<t​) 是 one-hot 标签下的交叉熵（07 篇 3.1 节的公式逐字复现）；
  2. 对整段数据求和取平均后，它等于 H^(pdata,qθ)\hat H(p_{\text{data}}, q_\theta)H^(pdata​,qθ​)——数据经验分布与模型分布的交叉熵；
  3. 由 3.1 节恒等式，=H(pdata)+KL(pdata∥qθ)= H(p_{\text{data}}) + \mathrm{KL}(p_{\text{data}}\|q_\theta)=H(pdata​)+KL(pdata​∥qθ​)，前者是数据本身的常数——所以最小化训练损失 = 最小化"数据 → 模型"方向的正向 KL = 最大似然 = 把数据压缩到接近其真实熵（监督学习走正向、变分推断走反向，见 3.3 节的对照）；
  4. 训练完成后 exp⁡(L)\exp(L)exp(L) 就是困惑度，评估集上的它就是模型的"平均分支因子"。

一句话总结：GPT 的损失、分类的交叉熵、KL 散度、MLE、熵、压缩极限——是同一个数学对象在六个场景里的名字。

本篇小结

  • 自信息 −log⁡2p-\log_2 p−log2​p 是惊讶度；熵是平均惊讶度：均匀硬币 1 bit，偏硬币 0.469 bit。
  • 香农编码定理：熵是最优平均码长的下界——损失函数逼近数据熵 = 学会压缩。
  • 交叉熵 H(p,q)=H(p)+KL(p∥q)H(p,q) = H(p) + \mathrm{KL}(p\|q)H(p,q)=H(p)+KL(p∥q)；KL 非对称（0.737 vs 0.531 的演示）：正向 KL 摊开覆盖（MLE/监督学习可计算），反向 KL 锁峰（变分/蒸馏因"只需在 q 的样本处评估 p"而可行，代价是模式坍缩）。
  • 互信息抓任意依赖（Y=X2Y=X^2Y=X2 的 ρ=0\rho=0ρ=0 反例），ρ=0\rho=0ρ=0 不等于独立。
  • 困惑度 = 交叉熵指数化 = 平均纠结词数；GPT 损失 = 逐 token one-hot 交叉熵 = 正向 KL = MLE = 压缩极限的逼近。
