13 - 动态规划进阶

本篇目标

  1. 吃透背包双形态：0-1 背包与完全背包，以及一维化的正序/倒序之谜（本章最重要细节）；
  2. 掌握字符串 DP 双璧：编辑距离（LC 72）与它的状态转移读法；
  3. 会写区间 DP 与状态机 DP（股票问题族），理解"加维度"的通用手法；
  4. 建立 DP 调试的硬技能：打印 DP 表格，用眼睛验证转移方程。

1. 0-1 背包：每件物品"选或不选"

问题：n 件物品各有重量 w[i]、价值 v[i]，容量 C 的背包，每件至多选一次，求最大价值。这是"资源约束下的决策"的原型（面试、量化里的组合约束、推理引擎里的显存分配，都是它的变体）。

一维化与"倒序"之谜

dp[i][*] 只依赖 dp[i-1][*] → 压到一维。但内层必须倒序：正序会让 dp[c - w] 读到"本行已更新"的值——等于"这件物品被用了两次"，0-1 变成了完全背包。这是 12 篇"循环顺序 = 依赖拓扑序"的最著名案例：

问题（LC 72）：把 word1 变成 word2 的最少操作（插入/删除/替换）。状态：dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作。转移按"最后一个字符怎么处理"分类：

LCS 与编辑距离的统一视角（12 篇练习 3 的回收）：dp[i][j] 的"相等白送、不等取最优"结构同时覆盖 LCS、编辑距离、正则匹配等一族题——二维字符串 DP 的转移几乎总在"末位匹配与否"上分岔。

4. DP 调试硬技能：打印表格

DP 的 bug 几乎从不报错，只是"答案不对"。打印表格逐格核对是唯一可靠的调试法（经验做法，竞赛与面试共识）：

调试流程（三问）：① 边界行/列对吗？② 挑 2–3 个格子，手工按转移方程重算，和表对得上吗？③ 最终格子是否语义一致（dp[m][n] 确实是"整串变整串"）？三步走完，90% 的 DP bug 当场现形。

5. 区间 DP：石子合并/戳气球

模式：状态是区间 [i, j]，转移枚举"区间内的分割点 k"或"最后处理哪个元素"。典型：合并石子（LC 1000 变体）、戳气球（LC 312）、最长回文子序列（LC 516）。

区间 DP 的循环框架二选一：i 倒序 + j 正序（如上），或外层枚举区间长度 len = 2..n、内层枚举左端 i。哪个顺手用哪个，但要能说清"转移依赖的所有格子都已在之前算好"。

6. 状态机 DP：股票问题族

问题族（LC 121/122/309/714）：每天可买/卖/休息，各种交易限制。解法：给状态加一维——“当前处于什么交易状态”，状态之间的合法迁移画成状态机图，转移就是沿图走边。

提示：状态机 DP 的检查点——同一天的状态迁移不能"接力"（今天卖出又立刻买入）：更新顺序必须全部基于"昨天"的值（元组同时赋值），否则状态串味。LC 123/188（至多 k 次交易）再加一维"已完成交易数"即可，框架不变。

7. 路径 DP 补全：带障碍与滚动压缩

一维滚动读法的口诀：“旧 dp[j] 是从上面来，新 dp[j-1] 是从左边来”——把二维转移在一维数组上还原，理解了这个，背包一维化也不再神秘。

本篇小结

  1. 背包四格锚点：0-1 内层倒序、完全内层正序；组合数物品在外层、排列数容量在外层；
  2. 一维化的本质是把"上一行旧值 / 本行新值"混存于一个数组，循环方向控制读哪个——依赖拓扑序（12 篇）的具体化；
  3. 编辑距离：末位匹配与否分岔的三选一转移；打印表格逐格核对是 DP 调试的硬技能；
  4. 区间 DP：状态是 [i, j]，转移枚举分割点或端点，循环顺序保证短区间先算；
  5. 状态机 DP：交易限制转成状态与合法迁移；同日迁移禁止 → 所有更新基于昨天的值。

练习

  1. （LC 416 - 分割等和子集）0-1 背包判定版：能否凑出 sum/2；dp 值从"最大价值"换成"能否达成"（布尔表）。
  2. （LC 494 - 目标和）转化成背包：设负号集合和为 x，则 sum - 2x = target → 求 x 的方案数（0-1 背包计数）；重点体验"数学变形后再套背包"。
  3. （LC 72 + LC 583 - 两个字符串的删除操作）编辑距离原题之外，把 583 写成"只允许删除"的简化版，对照转移怎么退化。
  4. （LC 312 - 戳气球）区间 DP 进阶：反转思路为"最后戳破哪个气球"，开区间边界补 1；与 516 对比两种"枚举最后一步"的方向。
  5. （LC 188 - 买卖股票的最佳时机 IV）至多 k 次交易：状态机加一维，验证框架扩展性；k >= n//2 时退化为 LC 122（剪枝，经验做法）。
