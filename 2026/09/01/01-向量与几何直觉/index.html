01 - 向量与几何直觉

本篇目标

读完本篇，你应该能做到：

  1. 在"向量是一列数"和"向量是空间中的箭头"两种视角之间自由切换，并知道什么时候该用哪个。
  2. 说清楚线性组合、张成空间、线性相关这三个概念的几何图像。
  3. 不查资料写出 L1/L2/L∞ 范数的定义，并解释为什么 L1 范数产生稀疏解（配等高线图）。
  4. 手算两个向量的余弦相似度，并说清它为什么是 embedding 检索的基础。

本篇是整个系列的语言课。后面 13 章里出现的一切"矩阵变换"“协方差”“梯度方向”，底层都是本篇的向量运算。

1. 向量的两种身份：列表 vs 箭头

1.1 列表视角（代数）

计算机里的向量就是一列有序的数：

v=[3−12]\mathbf{v} = \begin{bmatrix} 3 \\ -1 \\ 2 \end{bmatrix} v=⎣⎢⎡​3−12​⎦⎥⎤​

Python 里它就是一个 np.array([3, -1, 2])。列表视角回答"怎么存、怎么算"：加法是逐位相加，数乘是逐位相乘。

1.2 箭头视角（几何）

同样这个 v\mathbf{v}v，在三维空间里是从原点指向点 (3,−1,2)(3, -1, 2)(3,−1,2) 的一支箭：有方向，有长度 32+(−1)2+22=14≈3.742\sqrt{3^2+(-1)^2+2^2}=\sqrt{14}\approx 3.74232+(−1)2+22​=14​≈3.742。箭头视角回答"它是什么意思"：一个样本的特征是一条箭头，两个 embedding 的关系要看两条箭头的夹角。

1.3 什么时候用哪个视角

  • 做存储、运算、批量处理时用列表视角（NumPy 的强项）；
  • 谈相似度、距离、投影、变换时切换到箭头视角（几何直觉）。

工程里最常见的错误是只用列表视角：把 embedding 当成"一列数"，于是面对"为什么余弦相似度用点积除以长度"这类问题时没有图像可依。

2. 线性组合与张成空间

2.1 线性组合

给定两个向量 u,v\mathbf{u}, \mathbf{v}u,v，任意形如

a u+b v,a,b∈Ra\,\mathbf{u} + b\,\mathbf{v}, \quad a, b \in \mathbb{R} au+bv,a,b∈R

的向量称为它们的线性组合（linear combination）。几何上：先缩放两支箭头，再首尾相接。

2.2 张成空间

所有可能的线性组合构成的集合，叫这两个向量的张成空间（span）。三种典型情形（2D 为例）：

  • u=[1,0]⊤, v=[0,1]⊤\mathbf{u}=[1,0]^\top,\ \mathbf{v}=[0,1]^\topu=[1,0]⊤, v=[0,1]⊤：张成整个平面——它们线性无关；
  • v=2u\mathbf{v}=2\mathbf{u}v=2u：所有组合都落在同一条直线上——线性相关，其中一个是多余的；
  • 更一般地，nnn 维空间中最多需要 nnn 个线性无关向量来张成全空间（Strang《Linear Algebra》第 3 章）。

2.3 为什么工程上关心"相关"

特征矩阵中两列高度相关（例如"身高(cm)“和"身高(米)”），意味着其中一列不带来新信息——线性代数上叫秩亏，统计上叫多重共线性。这也是 04 篇 PCA 能"压缩"数据的根本前提：数据其实是低维的，只是被嵌在高维坐标里。

3. 范数：给"长度"下三种定义

3.1 定义

范数（norm）是把向量映射为非负实数、满足"长度"公理的函数。机器学习中最常用的三个（Casella & Berger 与各优化教材通用记法）：

∥x∥1=∑i∣xi∣,∥x∥2=∑ixi2,∥x∥∞=max⁡i∣xi∣\|\mathbf{x}\|_1 = \sum_i |x_i|, \qquad \|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}, \qquad \|\mathbf{x}\|_\infty = \max_i |x_i| ∥x∥1​=i∑​∣xi​∣,∥x∥2​=i∑​xi2​​,∥x∥∞​=imax​∣xi​∣

以 x=[3,−4]⊤\mathbf{x} = [3, -4]^\topx=[3,−4]⊤ 为例：∥x∥1=7\|\mathbf{x}\|_1 = 7∥x∥1​=7，∥x∥2=5\|\mathbf{x}\|_2 = 5∥x∥2​=5，∥x∥∞=4\|\mathbf{x}\|_\infty = 4∥x∥∞​=4。永远有 ∥x∥∞≤∥x∥2≤∥x∥1\|\mathbf{x}\|_\infty \le \|\mathbf{x}\|_2 \le \|\mathbf{x}\|_1∥x∥∞​≤∥x∥2​≤∥x∥1​。

3.2 各自的工程含义

  • L2：欧氏距离，“直线距离”。对大分量敏感——梯度为 2xi2x_i2xi​，分量越大推得越猛。
  • L1：曼哈顿距离，“出租车距离”。对所有分量一视同仁（导数恒为 ±1\pm 1±1），因此倾向于把一些分量直接推到 0。
  • L∞：只惩罚最大的那个分量，"木桶效应"式度量。

3.3 为什么 L1 产生稀疏：等高线图像

考虑约束 ∥x∥p≤c\|\mathbf{x}\|_p \le c∥x∥p​≤c 下的可行域形状：

  • L2 的可行域是圆盘（光滑，处处圆滚滚）；
  • L1 的可行域是菱形（四个尖角都在坐标轴上）。

把损失函数的等高线（同心的椭圆）叠上去：椭圆从外向内收缩，最先碰到可行域的那个点就是最优解。与圆盘相碰的点一般在"普通位置"（两个坐标都不为 0）；与菱形相碰的点大概率撞在尖角上——而尖角正好落在坐标轴上，即某个分量恰好为 0。这就是 LASSO（L1 正则）产生稀疏解的几何原因（Boyd《Convex Optimization》§6.3.2 有同款图；统计学原始出处 Tibshirani 1996）。

经验做法：想要"自动特征选择 / 压缩权重数量"用 L1；只想要"温和地压小权重、防止过拟合"用 L2。深度学习里 weight decay 默认是 L2，因为稀疏性对神经网络通常不是目标。

4. 点积与相似度

4.1 定义与两个等价形式

u⋅v=∑iuivi=∥u∥ ∥v∥cos⁡θ\mathbf{u} \cdot \mathbf{v} = \sum_i u_i v_i = \|\mathbf{u}\|\,\|\mathbf{v}\|\cos\theta u⋅v=i∑​ui​vi​=∥u∥∥v∥cosθ

左边是代数（逐位相乘再求和），右边是几何（长度×长度×夹角余弦）。这个等式是整个 embedding 时代的数学基石。

4.2 从点积读出三件事

固定 u,v\mathbf{u}, \mathbf{v}u,v 的长度，点积只由夹角决定：

  • 同向（θ=0\theta=0θ=0）：cos⁡θ=1\cos\theta = 1cosθ=1，点积达到最大——“意思一致”；
  • 垂直（θ=90°\theta=90°θ=90°）：cos⁡θ=0\cos\theta = 0cosθ=0——“不相关”（正交 = 信息上互不干扰，这是 04 篇 PCA 主成分互相正交的直觉来源）；
  • 反向（θ=180°\theta=180°θ=180°）：cos⁡θ=−1\cos\theta = -1cosθ=−1——“意思相反”。

4.3 余弦相似度

把夹角单独提取出来：

cos⁡θ=u⋅v∥u∥ ∥v∥\cos\theta = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|\,\|\mathbf{v}\|} cosθ=∥u∥∥v∥u⋅v​

手算一例：u=[2,1]⊤\mathbf{u} = [2, 1]^\topu=[2,1]⊤（“猫”），v=[1,1]⊤\mathbf{v} = [1, 1]^\topv=[1,1]⊤（“狗”），w=[−1,2]⊤\mathbf{w} = [-1, 2]^\topw=[−1,2]⊤（“汽车”）：

cos⁡(u,v)=2+15⋅2=310≈0.949,cos⁡(u,w)=−2+25⋅5=0\cos(\mathbf{u}, \mathbf{v}) = \frac{2+1}{\sqrt{5}\cdot\sqrt{2}} = \frac{3}{\sqrt{10}} \approx 0.949, \qquad \cos(\mathbf{u}, \mathbf{w}) = \frac{-2+2}{\sqrt{5}\cdot\sqrt{5}} = 0 cos(u,v)=5​⋅2​2+1​=10​3​≈0.949,cos(u,w)=5​⋅5​−2+2​=0

猫和狗方向接近（0.949），猫和汽车正交（0）。

4.4 为什么 embedding 检索用它

文本/图像 embedding 的检索流程本质是：把查询和候选都映成高维向量，然后按余弦相似度排序。用余弦而不是点积的原因：点积会偏爱长向量（一个范数很大的向量跟谁点积都大），余弦先归一化长度、只看方向。工程实现上有个关键优化（经验做法）：预先把所有候选做 ℓ2\ell_2ℓ2​ 归一化（v / np.linalg.norm(v)），之后余弦相似度就退化为一次矩阵乘法 cos⁡≈Xnorm⋅qnorm\cos \approx X_{\text{norm}} \cdot \mathbf{q}_{\text{norm}}cos≈Xnorm​⋅qnorm​，GPU/BLAS 上一次 @ 就能对百万级候选排序。

（注意这个 2 维玩具例子里猫狗恰好等分；真实 embedding 是几百维，方向分辨率高得多。）

本系列反复用到的向量操作，一次列全：

经验做法：在 NumPy/PyTorch 之间搬运代码时，绝大多数 shape 报错源于 1D 向量与 (n,1) 列向量混用。本系列的约定：数学推导里向量是列向量，代码里用 1D 数组，需要矩阵乘法时显式用 [:, None] 变形。

本篇小结

  • 向量有两重身份：一列数（代数，可计算）与一支箭头（几何，可想象），工程上要来回切换。
  • 线性组合 = 缩放 + 相加；张成空间回答"这几个向量能覆盖多大的世界"；线性相关意味着存在冗余，这正是压缩与降维的立足点。
  • 三种范数三种性格：L2 偏心（罚大分量）、L1 公平（产生稀疏，几何原因是菱形尖角在坐标轴上）、L∞ 只看短板。
  • 点积 = 逐位乘和 = 长度×长度×夹角余弦。余弦相似度剥掉长度只看方向，是 embedding 检索的打分函数；工程上先 ℓ2\ell_2ℓ2​ 归一化再 @ 一次完成批量检索。

练习

  1. （推导） 证明对任意向量有 ∥x∥∞≤∥x∥2≤∥x∥1\|\mathbf{x}\|_\infty \le \|\mathbf{x}\|_2 \le \|\mathbf{x}\|_1∥x∥∞​≤∥x∥2​≤∥x∥1​。（提示：左边从 max⁡∣xi∣≤∑xi2\max |x_i| \le \sqrt{\sum x_i^2}max∣xi​∣≤∑xi2​​ 出发；右边两边平方比较。）
  2. （推导） 证明：若 u\mathbf{u}u 与 v\mathbf{v}v 正交，则 ∥u+v∥22=∥u∥22+∥v∥22\|\mathbf{u}+\mathbf{v}\|_2^2 = \|\mathbf{u}\|_2^2 + \|\mathbf{v}\|_2^2∥u+v∥22​=∥u∥22​+∥v∥22​（勾股定理的向量形式）。
  3. （手算） a=[1,2,2]⊤\mathbf{a} = [1, 2, 2]^\topa=[1,2,2]⊤，b=[−2,1,2]⊤\mathbf{b} = [-2, 1, 2]^\topb=[−2,1,2]⊤。计算两个 L2 范数、点积、夹角余弦，判断它们是否正交。（答案：3,3,4,4/9≈0.4443, 3, 4, 4/9 \approx 0.4443,3,4,4/9≈0.444，不正交。）
  4. （编程） 生成 500 个二维随机点，分别计算它们的 L1 与 L2 范数，画出两种范数的散点等值分布；再写出 ∥x∥1=c\|\mathbf{x}\|_1 = c∥x∥1​=c 的等值线方程并叠加验证 3.3 节的菱形结论。
  5. （编程） 用 4.4 节的批量检索写法：构造 8 个随机 128 维向量代表文档、1 个查询，完成 ℓ2\ell_2ℓ2​ 归一化 + 矩阵乘法检索，打印相似度排序；然后故意把查询长度放大 100 倍，验证排序不变（余弦对长度不敏感）。
