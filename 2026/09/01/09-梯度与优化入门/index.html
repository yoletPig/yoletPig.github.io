09 - 梯度与优化入门

本篇目标

读完本篇，你应该能做到：

  1. 说清导数、梯度、方向导数的关系，并明白"方向导数是点积"背后的几何。
  2. 用链式法则手工对一个两三层的小计算图求梯度——反向传播的雏形。
  3. 用 Hessian 判断极值类型，识别鞍点。
  4. 完整推导梯度下降并亲手调学习率：直观感受过大/过小/正好的三种命运，理解 SGD 的"噪声换速度"。

本篇是《PyTorch 与深度学习》系列 02/05/09 篇的数学原型：训练循环的每一行都是本篇的代码化。

1. 导数、梯度与方向导数

1.1 从一元到多元

一元函数的导数 f′(x)f'(x)f′(x) 是"该点的瞬时斜率"。多元函数每个方向都有一个斜率，梯度把它们打包：

∇f=[∂f∂x1,∂f∂x2,…]⊤\nabla f = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots \right]^\top ∇f=[∂x1​∂f​,∂x2​∂f​,…]⊤

例：f(x,y)=x2+2y2f(x,y) = x^2 + 2y^2f(x,y)=x2+2y2 在点 (2,2)(2, 2)(2,2) 处 ∇f=[2x,4y]⊤=[4,8]⊤\nabla f = [2x, 4y]^\top = [4, 8]^\top∇f=[2x,4y]⊤=[4,8]⊤。

1.2 方向导数：为什么是点积

沿单位向量 u\mathbf{u}u 前进一小步，函数值的变化率：

Duf=∇f⋅uD_{\mathbf{u}}f = \nabla f \cdot \mathbf{u} Du​f=∇f⋅u

推导（一元链式法则的直接应用）：g(t)=f(x0+tu)g(t) = f(\mathbf{x}_0 + t\mathbf{u})g(t)=f(x0​+tu)，则 Duf=g′(0)=∑i∂f∂xiuiD_\mathbf{u}f = g'(0) = \sum_i \frac{\partial f}{\partial x_i} u_iDu​f=g′(0)=∑i​∂xi​∂f​ui​——正是点积。由点积的几何形式（01 篇）：

Duf=∥∇f∥ ∥u∥cos⁡θ=∥∇f∥cos⁡θ(u 为单位向量)D_{\mathbf{u}}f = \|\nabla f\|\,\|\mathbf{u}\|\cos\theta = \|\nabla f\|\cos\theta \quad(\mathbf{u}\ \text{为单位向量}) Du​f=∥∇f∥∥u∥cosθ=∥∇f∥cosθ(u 为单位向量)

θ=0\theta = 0θ=0 时最大：梯度方向是上升最快的方向，−∇f-\nabla f−∇f 是下降最快的方向，速率 =∥∇f∥= \|\nabla f\|=∥∇f∥；垂直方向 (θ=90°\theta=90°θ=90°) 变化率为 0——等高线在每一点与梯度垂直，这就是"梯度垂直于等高线"的由来（Boyd《Convex Optimization》§9；图示见任何多元微积分教材）。

2. 链式法则与计算图

2.1 一元链式法则

dzdx=dzdy⋅dydx\frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}dxdz​=dydz​⋅dxdy​——复合函数的导数是各段导数的乘积。

2.2 多元链式法则：乘积升级为"加权求和"

一个中间变量被多条路径使用时，梯度要沿每条路径求和：

∂L∂x=∑路径∏路径上的边∂(下游)∂(上游)\frac{\partial L}{\partial x} = \sum_{\text{路径}} \prod_{\text{路径上的边}} \frac{\partial(\text{下游})}{\partial(\text{上游})} ∂x∂L​=路径∑​路径上的边∏​∂(上游)∂(下游)​

2.3 手算一个小计算图

模型 L=(wx+b−y)2L = (wx + b - y)^2L=(wx+b−y)2，数据 x=2,y=1x=2, y=1x=2,y=1，参数 w=0.5,b=0.1w=0.5, b=0.1w=0.5,b=0.1：

y^=wx+b=1.1e=y^−y=0.1L=e2=0.01\begin{aligned} \hat{y} &= wx + b = 1.1 \\ e &= \hat{y} - y = 0.1 \\ L &= e^2 = 0.01 \end{aligned} y^​eL​=wx+b=1.1=y^​−y=0.1=e2=0.01​

反向传播（从 LLL 往回走，注意 y^\hat yy^​ 同时出现在 eee 中）：

∂L∂e=2e=0.2,∂e∂y^=1,∂y^∂w=x=2,∂y^∂b=1\frac{\partial L}{\partial e} = 2e = 0.2,\quad \frac{\partial e}{\partial \hat{y}} = 1,\quad \frac{\partial \hat{y}}{\partial w} = x = 2,\quad \frac{\partial \hat{y}}{\partial b} = 1 ∂e∂L​=2e=0.2,∂y^​∂e​=1,∂w∂y^​​=x=2,∂b∂y^​​=1

∂L∂w=0.2×1×2=0.4,∂L∂b=0.2×1×1=0.2\frac{\partial L}{\partial w} = 0.2 \times 1 \times 2 = 0.4, \qquad \frac{\partial L}{\partial b} = 0.2 \times 1 \times 1 = 0.2 ∂w∂L​=0.2×1×2=0.4,∂b∂L​=0.2×1×1=0.2

经验做法：把每个中间量的数值写在旁边、反向时逐边乘过去（多路径相加）——这个"纸笔反向传播"习惯能让你在任何框架报 NaN 时快速定位是哪条边炸了。《PyTorch 与深度学习》05 篇的 gradcheck 做的是同一件事的自动化。

3. 多元极值与 Hessian

3.1 极值的必要条件

驻点：∇f=0\nabla f = \mathbf{0}∇f=0。但驻点可能是极小、极大或鞍点——需要二阶信息。

3.2 Hessian 与凹凸性

Hessian 是二阶偏导排成的（对称）矩阵：

Hij=∂2f∂xi∂xjH_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j} Hij​=∂xi​∂xj​∂2f​

它在驻点附近的角色相当于一元情形的二阶导数（Strang《Linear Algebra》§6.5；Boyd《Convex Optimization》§3.1.4）：

  • HHH 正定（所有特征值 >0>0>0）→ 该点是局部极小；
  • HHH 负定（全 <0<0<0）→ 局部极大；
  • HHH 不定（有正有负）→ 鞍点：某些方向是谷、另一些方向是脊；
  • HHH 半正定（全 ≥0\ge 0≥0）处处成立 → fff 是凸函数（任何局部极小即全局极小，10 篇的主角）。

例：f=x2−y2f = x^2 - y^2f=x2−y2 的 Hessian 是 diag(2,−2)\mathrm{diag}(2, -2)diag(2,−2)，不定 → 原点是鞍点：沿 xxx 方向上坡、沿 yyy 方向下坡。

图注：3D 图就是一片薯片/马鞍；等高线图里鞍点周围一圈双曲线，红点处梯度为 0 但既非最高也非最低。高维神经网络损失面里鞍点远比局部极小常见（维度越高越难"每个方向都向上"），这是深度学习优化困难但总能"逃出去"的原因之一（Dauphin et al., 2014）。

4. 梯度下降：完整推导与可视化

4.1 推导

目标 min⁡f(x)\min f(\mathbf{x})minf(x)。在当前点 xt\mathbf{x}_txt​ 做一阶泰勒展开：

f(xt+Δ)≈f(xt)+∇f(xt)⊤Δf(\mathbf{x}_t + \Delta) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^\top \Delta f(xt​+Δ)≈f(xt​)+∇f(xt​)⊤Δ

要让函数值下降，取 Δ=−α ∇f(xt)\Delta = -\alpha\,\nabla f(\mathbf{x}_t)Δ=−α∇f(xt​)（沿最速下降方向、步长 α>0\alpha > 0α>0）：

 xt+1=xt−α ∇f(xt) \boxed{\ \mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\,\nabla f(\mathbf{x}_t)\ }  xt+1​=xt​−α∇f(xt​) ​

每步的预计下降量为 α∥∇f∥2≥0\alpha\|\nabla f\|^2 \ge 0α∥∇f∥2≥0（保证 α\alphaα 足够小时有效）。

4.2 等高线上的步进轨迹

对 f(x,y)=x2+2y2f(x,y) = x^2 + 2y^2f(x,y)=x2+2y2，∇f=[2x,4y]⊤\nabla f = [2x, 4y]^\top∇f=[2x,4y]⊤。从 (2,2)(2,2)(2,2) 出发，α=0.1\alpha = 0.1α=0.1：

步 xt\mathbf{x}_txt​ ∇f\nabla f∇f fff
0 (2.000, 2.000) (4.0, 8.0) 12.000
1 (1.600, 1.200) (3.2, 4.8) 5.440
2 (1.280, 0.720) (2.56, 2.88) 2.675
3 (1.024, 0.432) (2.05, 1.73) 1.422

注意每步都垂直穿过等高线（1.2 节的结论），且轨迹会拐弯——因为椭圆等高线的"最陡方向"是逐点变化的。

4.3 学习率的三种命运（1D 数值演示）

最干净的演示用 f(x)=x2f(x) = x^2f(x)=x2，梯度 2x2x2x，从 x0=2x_0 = 2x0​=2 出发。迭代公式 xt+1=xt−α⋅2xt=(1−2α)xtx_{t+1} = x_t - \alpha\cdot 2x_t = (1-2\alpha)x_txt+1​=xt​−α⋅2xt​=(1−2α)xt​：

α=0.5: 2→0 （一步到达,巧合最优）;α=0.1: 2→1.6→1.28→1.024 (×0.8 平稳收敛)\alpha = 0.5:\ 2 \to 0\ \text{（一步到达,巧合最优）};\qquad \alpha = 0.1:\ 2 \to 1.6 \to 1.28 \to 1.024\ (\times 0.8\ \text{平稳收敛}) α=0.5: 2→0 （一步到达,巧合最优）;α=0.1: 2→1.6→1.28→1.024 (×0.8 平稳收敛)

α=1.1: 2→−2.4→2.88→−3.456 (×1.2 振荡放大,发散!)\alpha = 1.1:\ 2 \to -2.4 \to 2.88 \to -3.456\ (\times 1.2\ \text{振荡放大,发散!}) α=1.1: 2→−2.4→2.88→−3.456 (×1.2 振荡放大,发散!)

规律：∣1−2α∣<1|1-2\alpha| < 1∣1−2α∣<1（即 α<1\alpha < 1α<1）才收敛；学习率超过 2/L2/L2/L（LLL 为曲率上界）必然振荡发散。结论的推广（Boyd §9.3）：二次函数上梯度下降的收敛率由 α\alphaα 与 Hessian 最大特征值决定——这也是 13 篇卡尔曼滤波"增益别设太大"的同源直觉。

经验做法：深度学习里 Hessian 未知且昂贵，学习率靠"从 1e-3/1e-4 起步 + 观察损失曲线（锯齿大→调小；平台期→调大或换优化器）+ warmup/cosine 调度"来管理；Adam 等自适应方法本质是在给每个坐标"私定"有效步长。

5. 随机梯度下降的直觉

5.1 从"全量"到"抽样"

损失 1n∑iℓi(θ)\frac{1}{n}\sum_i \ell_i(\theta)n1​∑i​ℓi​(θ) 的精确梯度要遍历全数据——nnn 上百万时不可行。SGD 每步只抽一小批（mini-batch）算梯度：

xt+1=xt−α ∇ℓBt(xt),Bt⊂{1..n}\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\, \nabla \ell_{\mathcal{B}_t}(\mathbf{x}_t), \qquad \mathcal{B}_t \subset \{1..n\} xt+1​=xt​−α∇ℓBt​​(xt​),Bt​⊂{1..n}

5.2 为什么噪声是"可接受的价格"

  • 批梯度 ∇ℓB\nabla\ell_{\mathcal{B}}∇ℓB​ 是真梯度 ∇f\nabla f∇f 的无偏估计：E[∇ℓB]=∇f\mathbb{E}[\nabla\ell_{\mathcal{B}}] = \nabla fE[∇ℓB​]=∇f——方向平均来看是对的，只是每步带噪声；
  • 噪声的副产品：帮着逃出浅局部极小和鞍点（在谷底附近来回晃，反而可能被弹出）；
  • 成本从 O(n)O(n)O(n) 降到 O(∣B∣)O(|\mathcal{B}|)O(∣B∣)，而且 early on 的噪声大步子比"精确但慢"更快到达好区域。

经验做法：batch 大小的权衡——大批次梯度噪声小、GPU 利用率高，但泛化有时变差且更新次数变少；小批次噪声大、正则效果好但吞吐低。工程上常按"显存装得下的最大值"附近再二分搜索。

本篇小结

  • 梯度 = 各方向斜率的打包；方向导数 =∇f⋅u= \nabla f\cdot\mathbf{u}=∇f⋅u，负梯度是最速下降方向，梯度垂直等高线。
  • 多元链式法则 = 沿计算图逐边乘、多路径加；手算 ∂L/∂w=0.4\partial L/\partial w = 0.4∂L/∂w=0.4 的例子就是一次微型反向传播。
  • Hessian 特征值定极值类型：全正极小、全负极大、有正有负鞍点；高维损失面鞍点占多数。
  • 梯度下降 xt+1=xt−α∇f\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha\nabla fxt+1​=xt​−α∇f；二次函数上 α\alphaα 决定收敛/发散（阈值 2/L2/L2/L），等高线轨迹图展示了三种命运。
  • SGD 用有噪声但无偏的小批梯度换速度，噪声顺带帮助逃离坏驻点。
