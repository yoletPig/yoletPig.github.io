数学基础（面向算法工程师）

面向 Python/NumPy 基础扎实、正在走向算法工程师岗位的学习者：把工程中反复出现的数学工具——线性代数、概率统计、优化、信息论、傅里叶——讲成"可计算、有图像、有代码"的直觉，而不是培养数学家。
本系列为中文原创，公式用 LaTeX，每章配 NumPy 实操与真实数值算例。本仓库的《自动驾驶》《PyTorch与深度学习》《VLM & VLA》《量化投资》《语音方向》都默认你已掌握本系列内容——它是所有方向的公共前置。

学习路径

篇 主题 你将学会
01-向量与几何直觉 向量 / 范数 / 点积 向量的"列表"与"箭头"两种视角、线性组合与张成空间、L1/L2/L∞ 范数及 L1 为何产生稀疏、余弦相似度与 embedding 检索
02-矩阵与线性变换 矩阵 = 变换 旋转/缩放/剪切的几何图像、矩阵乘法的四种理解、逆与秩、高斯消元与 LU、np.linalg.solve 求解 Ax=b
03-特征值与SVD 特征分解 / SVD 特征向量是"变换的不变方向"、2x2 手算、谱定理演示、SVD 的"旋转·缩放·旋转"几何、图像秩-k 压缩实测、伪逆
04-PCA与降维 主成分分析 协方差矩阵的真实含义、PCA 四步流程、与 SVD 的关系、方差解释率怎么读、3D→2D 完整实例、该不该先标准化
05-概率基础 概率公理 / 贝叶斯 条件概率与独立性、全概率公式、贝叶斯定理完整推导与医疗检测假阳性真算、朴素贝叶斯文本分类最小实现
06-随机变量与分布 分布 / 期望方差 PMF/PDF/CDF 图像区别、期望方差协方差的工程含义、六大常用分布、代码演示中心极限定理、为什么"假设正态"危险
07-最大似然与贝叶斯推断 MLE / MAP 似然与概率的区别、伯努利/正态的 MLE 完整推导、交叉熵=负对数似然、Beta-Bernoulli 共轭先验完整算例、MAP vs MLE
08-统计推断与假设检验 置信区间 / p 值 标准误、置信区间的正确理解与常见误读、p 值到底什么意思、A/B 测试 t 检验完整算一遍、多重检验、相关≠因果与辛普森悖论
09-梯度与优化入门 梯度下降 导数→梯度→方向导数、链式法则、Hessian 与凹凸性、梯度下降推导与等高线轨迹、学习率过大/过小数值演示、鞍点与 SGD 直觉
10-凸优化概览 凸性 / 对偶 / KKT 凸集凸函数判定、为什么凸问题局部=全局、拉格朗日对偶的工程直觉、KKT 条件、SVM 优化形式、CVXPY 最小示例、凸问题速查表
11-概率图模型一览 贝叶斯网络 / HMM 条件独立性的可视化、贝叶斯网络手算 CPT、HMM 前向算法 Python 实现、从 HMM 到 RNN 到注意力的观念联系、LLM 时代图模型的价值
12-信息论 熵 / KL / 交叉熵 自信息与熵、熵=最优码长下界、KL 散度非对称性数值演示、正向/反向 KL 的区别、互信息、困惑度、GPT 损失=交叉熵
13-矩阵微分与卡尔曼滤波基础 矩阵求导 / 卡尔曼 向量矩阵求导规则表、Jacobian 与 Hessian、最小二乘正规方程完整推导、协方差传播、卡尔曼预测-更新完整推导与 1D 数值实例
14-傅里叶分析与综合应用 FFT / STFT / 实战 频域直觉、DFT 与 NumPy fft 频谱解读、采样定理与混叠演示、卷积定理、STFT 与梅尔频谱前置、FFT 滤波 vs 卡尔曼平滑去噪实战

阶段划分

  1. 线性代数（01–04）：向量、矩阵、特征值/SVD、PCA。全部围绕"变换"与"数据形状"两个视角展开，是所有后续内容的语言。
  2. 概率与统计（05–08）：概率公理→分布→MLE/贝叶斯→假设检验。从"会算概率"到"会做推断、会看实验"。
  3. 优化（09–10）：梯度与凸优化。训练神经网络、理解损失函数、读懂 CVXPY 代码所需的全部优化直觉。
  4. 结构化模型与信息（11–12）：概率图模型与信息论。理解序列建模的来龙去脉，以及交叉熵/KL/困惑度这些训练日志里天天出现的指标。
  5. 工程综合（13–14）：矩阵微分+卡尔曼滤波、傅里叶+综合项目。两个完整落地点，直接对接自动驾驶与语音方向。

与本仓库其他方向的衔接

  • 自动驾驶 Stage 4（卡尔曼滤波）：卡尔曼滤波的预测-更新公式全部建立在协方差矩阵（04）、矩阵微分（13）之上——先读 04 + 13，Stage 4 的公式不再是天书。
  • VLM & VLA Stage 1 / Stage 6：Stage 1 讲架构时默认你懂 softmax 与交叉熵，Stage 6 讲训练时大量出现 KL 散度（RLHF/蒸馏对齐）——分别见本系列 07（交叉熵=负对数似然）与 12（KL 散度的两个方向）。
  • PyTorch 与深度学习系列：02 篇"从零实现线性回归"、05 篇"反向传播的数学原理"、09 篇"优化器"，分别对应本系列 02（矩阵）、09（梯度与链式法则）、09–10（优化与凸性）。
  • 量化投资：均值-方差组合依赖协方差矩阵（04）、相关性分析（01/04）、收益率的正态假设及其肥尾陷阱（06 的"为什么假设正态危险"）、夏普比率的统计推断（08）。
  • 语音方向 Stage 1（DSP）：FFT、采样定理、卷积定理、STFT/梅尔频谱全部在本系列 14 篇系统讲过，Stage 1 直接进入工程实现。

约定

  • 代码环境：Python 3.10+，NumPy 1.24+（个别章节用到 matplotlib、可选 filterpy / cvxpy）。全部代码 CPU 可跑，无需 GPU。
  • 图像说明：正文给出 matplotlib 绘图代码，运行后在本地生成 PNG；因无头环境不便贴图，文中用"图注"文字描述图像要点，请务必亲手运行查看。
  • 数值示例全部真实可验：凡给出的数字（如 2×22\times22×2 特征值、A/B 测试 z 值、KL 散度值）都可以用对应代码复现；随机示例固定 np.random.seed。
  • 引用规范：关键论断给出经典教材出处（Strang《Linear Algebra》、Boyd《Convex Optimization》、Cover & Thomas《Elements of Information Theory》、Casella & Berger《Statistical Inference》等）；无法查证的经验性内容一律标注"经验做法"，不冒充定论。
  • 记号约定：向量默认列向量，粗体小写 x\mathbf{x}x；矩阵粗体大写 AAA；A⊤A^\topA⊤ 表示转置；∥x∥\|\mathbf{x}\|∥x∥ 不加下标时指 L2 范数；log 无特别说明时以 e 为底（信息论章节显式用 log⁡2\log_2log2​）。
