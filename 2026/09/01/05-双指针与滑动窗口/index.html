05 - 双指针与滑动窗口

本篇目标

  1. 掌握双指针的三大形态：对撞指针、快慢指针、原地读写指针，并知道各自适用的不变式；
  2. 把滑动窗口统一定义为"双指针维护的区间 + 可增量更新的统计量"，学会定长与变长两个模板；
  3. 独立写出最小覆盖子串（LC 76）这类"硬题"，理解窗口收缩的正确性论证。

1. 双指针的本质：用单调性消灭重复扫描

双重循环暴力是 O(n²)，因为它对每个左端点都重新扫一遍右端点。双指针的获胜条件：当左端点（或某个决策量）单调移动时，右端点的最优位置也单调移动——于是两个指针各走 O(n) 步，总 O(n)。这个"决策单调性"就是所有双指针题的共同前提（经验做法：面试先说不变式，再写代码）。

正确性论证（面试值得说）：假设答案在 (i, j)，若当前 lo 被跳过时 nums[lo]+nums[hi] < target，则 nums[lo] 与任何 nums[k] (k≤hi) 的和都 < target——它确实不可能出现在任何剩余答案里，丢弃是安全的。这就是"每一步都排除一个不可能"的 elimination 论证。

2. 对撞指针的三个经典应用

对撞指针的适用信号：问题关于"一对元素"且两端信息可判断优劣（有序两数之和、回文、容器容量、三数之和外层循环配对撞 LC 15）。

3. 快慢指针与原地读写

02 篇用快慢指针判环。这里补全数组上的"读写双指针"模式——原地删除/移动类问题的统一解法：写指针 w 指向"下一个可写位置"，读指针 r 扫描全数组，有效元素写入 w 后两者同进，无效时只 r 进。

提示："保持相对顺序"与"允许乱序"决定写法：允许乱序可用交换（LC 75 颜色分类的三指针分区），必须保序就用覆盖 + 回填（或交换但理解其保序性）。

4. 滑动窗口：定长模板

窗口本质：用两个同向指针 [l, r) 围出一个区间，右端扩张采集信息，左端按条件收缩丢弃信息，同时维护一个可 O(1) 增量更新的统计量（和、计数、哈希表）。先看定长版：

定长窗口要维护的信息若不可增量更新（如"窗口内最大值"），就升级成 04 篇的单调队列；若要"窗口内第 k 小"则是有序结构/双堆问题（09 篇）。先判断统计量能否增量更新，再选工具，这是窗口类题的第一决策。

5. 滑动窗口：变长模板

变长窗口（不定长）的标准形态：右指针无条件前进采集，左指针在"违反约束"时收缩。每一刻窗口都保持"合法"或"恰好非法"的状态，答案是过程中某个统计量的最值。

min_window 的收缩正确性（面试常被追问）：missing == 0 时窗口已覆盖 t；只要左端字符是"过剩"的（计数 < 0），移除后依然覆盖，所以一路收缩到左端是"恰好必需"的字符为止——此刻窗口是最小的覆盖窗口之一，记录答案后主动收缩一格破坏覆盖，让右端去找下一个。missing 单一整数代替"逐字符比对是否齐了"，是本题从 O(26·n) 到干净 O(n) 的关键小优化。

7. 常见误区

  1. 先写代码后找不变式：窗口题的 bug 几乎都来自"收缩条件没想清"。开口先说：窗口合法的定义是什么？违反时左端收缩到哪？
  2. 计数用错时机：“先查后插”（两数之和）与"先加后查"（前缀和配对）是两个方向，混用会漏掉/多算；
  3. 用 if 收缩应该用 while：违反约束可能需要连续收缩多格。看到 while 里改 left 的地方，问自己"收缩一次够吗"；
  4. 把双指针当成万能 O(n)：没有单调性就退回 O(n²)。判断方法（经验做法）：想象左指针右移一格，最优的右指针位置会倒退吗？会——双指针不适用。

本篇小结

  1. 双指针三大形态对应三种不变式：对撞（两端淘汰）、快慢（间距/速度差）、读写（有效元素搬运）；
  2. 滑动窗口 = 同向双指针 + 可增量更新的统计量；定长看"一头一尾"，变长看"进 1 收多"；
  3. 最小覆盖子串是窗口模板的天花板：need 表 + missing 总量计数 + “收缩到刚好不满足”；
  4. 每个指针的每一步都要有"安全丢弃"的理由——这就是双指针 O(n) 的合法性来源；
  5. 决策顺序：统计量能否增量更新 → 定长还是变长 → 需要最值吗（配单调队列/堆）。

练习

  1. （LC 15 - 三数之和）排序 + 固定一个数 + 对撞指针，O(n²)；重点写好三重去重。
  2. （LC 209 - 长度最小的子数组）正整数数组中和 ≥ target 的最短子数组，变长窗口模板直接套用。
  3. （LC 567 - 字符串的排列）判断 s2 是否包含 s1 的某个排列：定长窗口 + 计数比较（或增量维护差异计数做到 O(26) 内）。
  4. （LC 11 - 盛最多水的容器）不看上文独立写一遍，并口头完成"移动短边"的 elimination 论证。
  5. （LC 76 - 最小覆盖子串）遮住上文独立实现；测试用例至少包含 s 比 t 短、t 有重复字符两种边界。
