05 - 概率基础

本篇目标

读完本篇，你应该能做到：

  1. 用概率公理和文氏图正确处理"或"“且”“非”，会算条件概率并判断独立性。
  2. 熟练使用全概率公式与贝叶斯定理，亲手算出医疗检测的假阳性问题。
  3. 理解"先验→似然→后验"的贝叶斯更新结构，知道它是卡尔曼滤波（13 篇）和贝叶斯推断（07 篇）的骨架。
  4. 用 NumPy 实现一个最小朴素贝叶斯文本分类器。

概率是 06–08 篇的共同语言，也是量化投资和机器学习理论的地基。

1. 样本空间与概率公理

1.1 基本对象

  • 样本空间 Ω\OmegaΩ：随机实验所有可能结果的集合（掷两枚硬币：Ω={正正,正反,反正,反反}\Omega = \{正正, 正反, 反正, 反反\}Ω={正正,正反,反正,反反}）；
  • 事件：Ω\OmegaΩ 的子集，如"至少一枚正面" ={正正,正反,反正}= \{正正, 正反, 反正\}={正正,正反,反正}；
  • 概率 PPP：给事件赋一个 [0,1][0,1][0,1] 之间的数。

1.2 三条公理（Kolmogorov）

1. P(A)≥0;2. P(Ω)=1;3. A,B 互斥时 P(A∪B)=P(A)+P(B)1.\ P(A) \ge 0; \qquad 2.\ P(\Omega) = 1; \qquad 3.\ A,B\ \text{互斥时}\ P(A \cup B) = P(A) + P(B) 1. P(A)≥0;2. P(Ω)=1;3. A,B 互斥时 P(A∪B)=P(A)+P(B)

全部概率运算都从这三条推出（Casella & Berger《Statistical Inference》§1.2）。最常用的推论是补集与容斥：

P(Aˉ)=1−P(A),P(A∪B)=P(A)+P(B)−P(A∩B)P(\bar{A}) = 1 - P(A), \qquad P(A \cup B) = P(A) + P(B) - P(A \cap B) P(Aˉ)=1−P(A),P(A∪B)=P(A)+P(B)−P(A∩B)

容斥公式的用法：掷两枚骰子，"第一枚是 6 或第二枚是 6"的概率 = 16+16−136=1136\frac16 + \frac16 - \frac1{36} = \frac{11}{36}61​+61​−361​=3611​（直接数一下 11 个格子，正好吻合）。

2. 条件概率与独立性

2.1 条件概率

P(A∣B)=P(A∩B)P(B),P(B)>0P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0 P(A∣B)=P(B)P(A∩B)​,P(B)>0

读法：“在 BBB 已经发生的世界里，AAA 的概率”。本质是把样本空间缩小到 BBB 内部重新归一化。

数值示例：掷两枚骰子，已知点数之和为 8，问第一枚是偶数的概率？和为 8 的组合有 5 个（等可能）：(2,6),(3,5),(4,4),(5,3),(6,2)(2,6),(3,5),(4,4),(5,3),(6,2)(2,6),(3,5),(4,4),(5,3),(6,2)；其中第一枚为偶数的有 (2,6),(4,4),(6,2)(2,6),(4,4),(6,2)(2,6),(4,4),(6,2) 共 3 个：

P(第一枚偶∣和=8)=35P(\text{第一枚偶} \mid \text{和}=8) = \frac{3}{5} P(第一枚偶∣和=8)=53​

（无条件时第一枚为偶数的概率是 1/21/21/2——"和为 8"这个信息改变了你的判断，这就是条件概率存在的意义。）

2.2 独立性

AAA 与 BBB 独立定义为 P(A∩B)=P(A) P(B)P(A \cap B) = P(A)\,P(B)P(A∩B)=P(A)P(B)，等价于 P(A∣B)=P(A)P(A\mid B) = P(A)P(A∣B)=P(A)——“知道 BBB 发生不改变 AAA 的概率”。

小心三个易错点：

  1. 独立 ≠ 互斥：互斥意味着 P(A∩B)=0P(A\cap B)=0P(A∩B)=0，而独立要求 P(A∩B)=P(A)P(B)P(A\cap B) = P(A)P(B)P(A∩B)=P(A)P(B)；两个概率大于 0 的事件不可能既独立又互斥。
  2. 独立不能靠感觉：连续掷骰子每一枚独立；但"抽到的两张牌都是 A"中的两次抽取（不放回）不独立。
  3. 机器学习里的"朴素"：朴素贝叶斯假设"给定类别后各特征独立"——这是条件独立，与边缘独立是两回事（见 11 篇）。

3. 全概率公式与贝叶斯定理

3.1 全概率公式

把样本空间按 B1,…,BnB_1, \ldots, B_nB1​,…,Bn​ 切成互斥完备的几块：

P(A)=∑iP(A∣Bi) P(Bi)P(A) = \sum_i P(A \mid B_i)\,P(B_i) P(A)=i∑​P(A∣Bi​)P(Bi​)

例：某零件由甲乙两台机床生产，甲产 60%、次品率 2%；乙产 40%、次品率 5%。随机取一件是次品的概率：

P(次)=0.02×0.6+0.05×0.4=0.012+0.020=0.032P(\text{次}) = 0.02 \times 0.6 + 0.05 \times 0.4 = 0.012 + 0.020 = 0.032 P(次)=0.02×0.6+0.05×0.4=0.012+0.020=0.032

3.2 贝叶斯定理

由条件概率定义直接翻转：

P(Bi∣A)⏟后验=P(A∣Bi) P(Bi)⏟先验P(A)⏟证据,P(A)=∑jP(A∣Bj)P(Bj)\underbrace{P(B_i \mid A)}_{\text{后验}} = \frac{P(A \mid B_i)\,\underbrace{P(B_i)}_{\text{先验}}}{\underbrace{P(A)}_{\text{证据}}}, \qquad P(A) = \sum_j P(A\mid B_j)P(B_j) 后验P(Bi​∣A)​​=证据P(A)​​P(A∣Bi​)先验P(Bi​)​​​,P(A)=j∑​P(A∣Bj​)P(Bj​)

它回答的问题只有一个：拿到新证据后，如何更新信念。"先验 → 似然 × 先验 / 证据 → 后验"这个结构会原封不动地出现在 07 篇的贝叶斯推断和 13 篇的卡尔曼滤波（预测即先验、更新即贝叶斯）里。

3.3 经典案例：医疗检测的假阳性（完整算）

设定（数字均为假设但真实可算）：某病人群患病率 P(D)=0.01P(D) = 0.01P(D)=0.01；检测灵敏度 P(+∣D)=0.99P(+\mid D) = 0.99P(+∣D)=0.99（病人大概率测出阳性）；假阳性率 P(+∣Dˉ)=0.05P(+\mid \bar{D}) = 0.05P(+∣Dˉ)=0.05（健康人也有 5% 测出阳性）。问：测出阳性的人真的患病的概率？

第一步，全概率公式算 P(+)P(+)P(+)：

P(+)=P(+∣D)P(D)+P(+∣Dˉ)P(Dˉ)=0.99×0.01+0.05×0.99=0.0099+0.0495=0.0594P(+) = P(+\mid D)P(D) + P(+\mid \bar{D})P(\bar{D}) = 0.99 \times 0.01 + 0.05 \times 0.99 = 0.0099 + 0.0495 = 0.0594 P(+)=P(+∣D)P(D)+P(+∣Dˉ)P(Dˉ)=0.99×0.01+0.05×0.99=0.0099+0.0495=0.0594

第二步，贝叶斯定理：

P(D∣+)=0.99×0.010.0594=0.00990.0594=16≈0.167P(D \mid +) = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} = \frac{1}{6} \approx 0.167 P(D∣+)=0.05940.99×0.01​=0.05940.0099​=61​≈0.167

结论震撼但合理：阳性结果下只有约 16.7% 真的患病。直观解释（把数字想象成 10000 人）：100 个病人里 99 个测出阳性；9900 个健康人里仍有 495 个假阳性——阳性队伍共 594 人，真病人只占 99/594 = 1/6。低先验（罕见事件）会被假阳性稀释，这就是"基率谬误"（base rate fallacy）。

工程对应：风控/反作弊系统告警的"精度"天然被低基率压低；告警阈值（相当于检测灵敏度）的选取必须结合基率，否则误报会淹没团队。

4. 贝叶斯更新：链式使用

贝叶斯定理不是一次性公式，而是循环：今天的后验是明天的先验。设观察依次到来，每来一个证据就更新一次：

P(H∣e1,e2)=P(H∣e1) 用 e2 再更新一次P(H \mid e_1, e_2) = P(H \mid e_1)\ \text{用}\ e_2\ \text{再更新一次} P(H∣e1​,e2​)=P(H∣e1​) 用 e2​ 再更新一次

这种"滚动更新信念"的模式就是序贯推断：卡尔曼滤波每帧更新一次状态信念（13 篇）；垃圾邮件过滤器每封邮件更新词表权重；量化策略每根 K 线更新对参数的估计。数学骨架全在本节。

5. 朴素贝叶斯文本分类：最小实现

5.1 模型

垃圾邮件分类：类别 C∈{spam,ham}C \in \{\text{spam}, \text{ham}\}C∈{spam,ham}，邮件由词袋 w=(w1,…,wm)\mathbf{w} = (w_1, \ldots, w_m)w=(w1​,…,wm​) 表示。贝叶斯定理 + “词之间条件独立”（朴素假设）：

P(C∣w)∝P(C)∏iP(wi∣C)P(C \mid \mathbf{w}) \propto P(C) \prod_i P(w_i \mid C) P(C∣w)∝P(C)i∏​P(wi​∣C)

用对数防止几百个小概率连乘下溢（经验做法：工程实现一律在 log 空间做贝叶斯）：

log⁡P(C∣w)∝log⁡P(C)+∑ilog⁡P(wi∣C)\log P(C \mid \mathbf{w}) \propto \log P(C) + \sum_i \log P(w_i \mid C) logP(C∣w)∝logP(C)+i∑​logP(wi​∣C)

词概率用拉普拉斯平滑（避免没见过的词把整个乘积清零）：

P(w∣C)=词 w 在 C 类中的次数+1C 类总词数+∣V∣P(w \mid C) = \frac{\text{词}\ w\ \text{在}\ C\ \text{类中的次数} + 1}{C\ \text{类总词数} + |V|} P(w∣C)=C 类总词数+∣V∣词 w 在 C 类中的次数+1​

5.3 为什么"朴素"还这么能打

条件独立假设显然是假的（“中奖”"奖金"总是同时出现），但这导致的主要后果是后验概率的绝对值被高估，而分类边界（谁大谁小）往往还是对的。这是"模型错了但有用"的经典案例（ Domingos & Pazzani 1997 的分析）。

本篇小结

  • 三条公理推出一切概率运算；容斥公式处理"或"，条件概率处理"已知"。
  • 独立 = P(A∩B)=P(A)P(B)P(A\cap B) = P(A)P(B)P(A∩B)=P(A)P(B) = “知道一个不改变另一个”；互斥与独立不能兼得。
  • 全概率公式"分块算总量"，贝叶斯定理"翻转条件方向"：后验 = 似然×先验/证据。医疗检测算例：先验 1%、灵敏度 99%、假阳性 5% → 阳性中真患病仅 1/6。
  • 贝叶斯更新可以滚动使用，是序贯推断（卡尔曼滤波）的骨架。
  • 朴素贝叶斯 = 贝叶斯 + 条件独立假设 + log 空间 + 拉普拉斯平滑；模型假设错但分类边界常常对。
