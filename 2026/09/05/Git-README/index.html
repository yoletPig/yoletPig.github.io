Git 系列教程：从"会背命令"到"理解模型"

面向"用过 add/commit/push 但一遇冲突就慌、一提 rebase 就怕"的学习者。全系列的立场：Git 的难点不是命令多，而是大多数教程不教对象模型——不理解 blob/tree/commit 这套模型，命令只能死记；理解了模型，所有命令都能自己推出来。
事实基准：Git 由 Linus Torvalds 于 2005 年 4 月创建；本系列覆盖 Git 2.2x~2.4x 的稳定行为，个别版本差异会注明（以 git-scm.com 官方文档为准）。

学习路径

篇 主题 你将学会
01-核心概念与对象模型 快照、四类对象、三个区域 建立正确心智模型：commit 是快照不是 diff；一切命令都操作对象图
02-基础工作流 config、add/commit、diff、ignore 日常循环的正确姿势与提交粒度纪律
03-分支与合并 分支=指针、三类合并、冲突解决 从"怕分支"到"分支是最廉价的能力"
04-远程协作 remote、fetch/pull/push、跟踪分支 远程引用的真相；fetch 与 pull 的区别；推送被拒怎么办
05-rebase与历史改写 rebase、amend、cherry-pick 把"丑历史"整理成"可读历史"，以及那条黄金法则
06-撤销的艺术 restore、reset 三模式、revert、reflog 任何误操作都有救——前提是你懂 reflog
07-工作区利器 stash、worktree、submodule、sparse-checkout 多任务并行、大仓库与大仓库嵌套的正确处理
08-内部原理-对象引用与打包 plumbing、refs、packfile、gc 用底层命令验证 01 篇模型；搞懂 .git 里都有什么
09-团队协作流程与规范 工作流选型、提交规范、review feature branch / trunk-based 的取舍；Conventional Commits；签名提交
10-高级主题与实战 bisect、hooks、LFS、rerere、排错手册 二分定位坏提交、钩子自动化、大文件方案、全套急救命令卡

阶段划分

  1. 模型与日常（01–02）：先装"操作系统"（对象模型），再练"日常输入"（工作流）。
  2. 协作核心（03–04）：分支与远程是团队开发的主战场。
  3. 历史工程（05–06）：改写与撤销——Git 区别于旧 VCS 的超能力，也是事故高发区。
  4. 进阶与内化（07–10）：从"会用"到"讲得清原理、救得了现场"。

学习方法建议

  1. 01 篇务必动手跑一遍底层命令（git cat-file 等），模型只有亲手摸过才算拥有；
  2. 每篇末尾的"自测"不是装饰：能不看书写出答案，才算过；
  3. 06 篇（撤销）与 10 篇（急救卡）建议打印/收藏——事故现场没有时间翻教程；
  4. 与本仓库的衔接：uv 系列的依赖锁文件（uv.lock）应当提交进 Git——哪个文件该不该提交，在 02 篇有完整决策表。
