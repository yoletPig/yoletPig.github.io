第 3 周教程：数据配方（Data Mixture）与多任务消融实验

本周要回答的三个问题

  1. 多模态 SFT 数据有哪几类能力域？每类对训练信号的要求有何本质不同？
  2. 为什么"把所有数据拼在一起混训"会导致某些能力被另一些能力挤掉？配比怎么定？
  3. 消融实验怎么做才能得出可信结论，而不是"跑了个寂寞"？

对应学习计划：第 3 周。交付物：3 类任务 × 约 1000 条混合数据集，两种配比（8:1:1 vs 4:3:3）各微调一个 Checkpoint，对比 OCR 与空间定位表现，产出消融分析笔记。

1. 第一性原理：多任务混训的内 compete 与遗忘

1.1 根本矛盾

一个 7B LLM 的权重空间虽然巨大，但不同任务对同一批权重的要求可能是冲突的。OCR 任务要求模型对字符形状的视觉特征极度敏感（输出精确文本），而通用对话要求输出流畅自然的描述（语言先验主导）。当两类数据直接混合训练时，共享的 LLM 权重被两个方向的梯度交替拉扯：

θt+1=θt−η∑kλk∇θLk\theta_{t+1} = \theta_t - \eta \sum_{k} \lambda_k \nabla_\theta \mathcal{L}_k θt+1​=θt​−ηk∑​λk​∇θ​Lk​

其中 Lk\mathcal{L}_kLk​ 是任务 kkk 的损失，λk\lambda_kλk​ 由数据配比隐式决定。若 λOCR≫λ对话\lambda_{\text{OCR}} \gg \lambda_{\text{对话}}λOCR​≫λ对话​，梯度方向被 OCR 主导，通用能力对应的参数区域被持续推离——灾难性遗忘（Catastrophic Forgetting）。

三个层面的机制：

  1. 梯度方向冲突：不同任务在最优点附近的梯度夹角可能为钝角（互相抵消），混训无法同时满足，只能收敛到折中点——每个任务都不到最优。
  2. 容量挤占：LLM 的任务相关子空间有限，高频任务占据后，低频任务的表征被压缩。表现就是"只会做 OCR，失去常规对话能力"（学习计划自测清单的考点）。
  3. 梯度尺度不均衡：不同任务的回答长度、loss 量级天然不同（OCR 标注的文本 token 多、caption 语言规范），梯度范数大的任务隐式获得更大权重，配比失衡被进一步放大。

1.2 多模态 SFT 数据的能力域分类

学习计划列出的四类数据，本质差异在于监督信号的空间结构：

能力域 代表任务 回答结构 监督信号特点 数据量敏感度
通用视觉理解 Caption / VQA 自然语言 语言流畅性 + 语义正确性 低（底座已会说话）
细粒度文本理解 OCR / Document / Chart 逐字符精确文本 每个字符都是硬约束，错一字即错 极高（长尾字符/版式必须大量覆盖）
空间定位 Grounding / 检测 归一化坐标序列 数值精确性，格式刚性 高（坐标约定需一致训练）
多步推理 Visual CoT 推理链 + 结论 中间步骤的因果正确性 中（底座推理能力可迁移）

OCR 是最"贵"的一类：一个文档图可能包含数百个字符，每个字符的预测都要从视觉特征精确解码，而且字符分布长尾（生僻字、特殊符号、下标）。1000 条 OCR 数据远不足以覆盖，这正是配比实验中 OCR 能力最容易波动的结构性原因。

坐标格式的一致性问题：空间定位的坐标序列约定必须全局唯一——[ymin, xmin, ymax, xmax] 还是 [xmin, ymin, xmax, ymax]？归一化到 0~1000 还是绝对像素？整数还是小数？同一次训练里混用两种约定是自我毁灭——模型学到的是"坐标有两个可能的格式"，输出时随机掷骰子。Qwen2-VL 约定为归一化到 0~1000 的整数 [xmin, ymin, xmax, ymax]（注意：Qwen2.5-VL 起改成了相对 resize 后图片的绝对像素坐标，官方文档写明这一变化）；x1, y1, x2, y2 顺序配合其 M-RoPE 是 t,h,wt, h, wt,h,w。无论用哪家模型，混训前必须先查所用模型的官方文档并统一。

1.3 配比的量化直觉

配比没有理论最优解，但有可操作的经验框架。设三类任务数据量为 n1,n2,n3n_1, n_2, n_3n1​,n2​,n3​，直接混合时有效采样概率 pk=nk/∑np_k = n_k / \sum npk​=nk​/∑n。两种修正策略：

策略一：温度采样（Temperature Sampling，借鉴多语言 LLM 预训练）

pk=nkα∑jnjα,α∈(0,1]p_k = \frac{n_k^{\alpha}}{\sum_j n_j^{\alpha}}, \quad \alpha \in (0, 1] pk​=∑j​njα​nkα​​,α∈(0,1]

  • α=1\alpha = 1α=1：自然配比（数据多者主导）；
  • α→0\alpha \to 0α→0：均匀采样（各任务等概率）；
  • 经验起点：α=0.3∼0.5\alpha = 0.3 \sim 0.5α=0.3∼0.5，在"尊重数据量"与"保护小数据任务"间折中。

策略二：手工配比 + 上限截断（本周 MVP 采用，简单可控）：如通用：OCR：坐标 = 5:3:2，且任何单任务采样占比设上限（如 40%）防单一任务淹没。

一个重要的反直觉：配比不是"想要什么能力就多喂什么数据"。通用数据（尤其是高质量对话）扮演的角色是防遗忘的锚——学习计划的 5:3:2 示例中通用占最大头，不是因为它最重要，而是因为它是"地基"，其他专域能力都是在地基上叠的。压缩通用数据的占比来给 OCR 让路，短期 OCR 涨分、长期全面退化。

2. 消融实验方法论：控制变量的纪律

2.1 消融实验的四个前提

一个可信的数据配比消融，必须先满足：

  1. 单一变量：两个 Checkpoint 之间只有数据配比不同。底座模型、超参（lr、epoch、batch、cutoff_len）、随机种子、数据总量全部锁死。
  2. 参数边界可验证：训练日志中打印的 trainable params 数量一致（第 2 周 3.3 节的纪律）。
  3. 评估集独立且覆盖各能力域：为每个能力域准备独立的 held-out 测试集（各 50~100 条），绝不混入训练数据。
  4. 多次运行或固定种子：千条数据级别的 SFT 方差不小，单次运行结论脆弱。至少固定种子跑通流程；关键结论建议换种子复跑一次。

2.2 评估协议设计

针对本周 MVP 的三任务混合，设计如下评估：

评估域 测试集构造 指标
通用描述 50 张未训练图片 + “描述图片” 人工/主观评分（1~5），或 CIDEr 类自动指标
OCR 50 张含清晰文字的截图/文档 字符准确率：编辑距离 1−Levenshtein(pred,gt)len(gt)1 - \frac{\text{Levenshtein}(pred, gt)}{\text{len}(gt)}1−len(gt)Levenshtein(pred,gt)​
空间定位 50 张含明确单一目标的图片 IoU（交并比）：预测框与标注框的重叠率，IoU > 0.5 记为命中

OCR 用编辑距离而非"整句对错"（部分正确也能被度量），定位用 IoU 而非"坐标完全一致"（连续数值需要软指标）。指标要与任务的容错结构匹配——用 exact match 评 OCR 会把 99% 正确判成 0 分，噪声大到看不出配比差异。

2.3 消融笔记的写作框架

交付的消融分析笔记至少包含：

  1. 实验设置表：底座、数据量、配比、超参、种子、硬件、训练时长——读者（包括三个月后的你自己）必须能复现；
  2. 结果矩阵：每个 Checkpoint × 每个评估域的分数；
  3. 交叉观察：配比偏向 OCR 后，通用与定位各降了多少（遗忘的方向与幅度）；
  4. 异常记录：训练中的 loss 曲线异常、OOM、数据加载报错及其处置；
  5. 结论与下一步：明确"在本设置下"的结论边界（如"1000 条规模下 4:3:3 的 OCR 收益不足以补偿通用退化"），不做超出数据规模的泛化。

4. 工程权衡与失效模式

4.1 配比决策速查

症状 配方调整方向 依据
通用对话明显退化（遗忘） 通用占比提高；或引入 10~30% 通用 replay 数据 锚定语言能力
OCR 总是差 先查 OCR 数据绝对量（<5k 条很难学好），再谈配比 长尾字符覆盖需要量
定位输出坐标格式混乱 统一坐标约定 + 格式校验 + 适度提占比 刚性格式需一致性
各任务都平庸 检查是否任务过多（>8 类）；考虑课程式（先通用后专精） 多任务折中点效应
单任务占 60%+ 设采样上限或 α<1 防单任务淹没

4.2 三个代表性失效模式

失效 1：任务标签泄漏到 prompt，评测虚高

  • 症状：OCR 准确率 95%+，实际部署后完全不可用。
  • 根因：训练样本的 prompt 写成"识别图中所有印刷体英文大写字母"，而评测/真实提问是"识别图中所有文字"——模型学到的是对特定 prompt 模板的应答，不是 OCR 能力。这是数据构造最常见的自我欺骗。
  • 定位：评测 prompt 与训练 prompt 做措辞多样性检查；换 5 种同义问法测试，分数应稳定。
  • 修复：每类任务的问法模板化多样性（训练数据内 5~10 种问法），评测用未见过的措辞。

失效 2：配比消融用了不同随机种子/不同 epoch，结论归因错误

  • 症状：两个 Checkpoint 差异巨大，但复跑后反转。
  • 根因：小数据 SFT 对随机性敏感（初始化、数据 shuffle 顺序都会造成 >5% 的指标波动），把噪声当成了配比效应。
  • 定位：同配方换种子复跑，若波动与"配方差异"同量级，则原结论不可信。
  • 修复：锁种子做首轮对比；关键结论换 2~3 个种子报告均值与方差。

失效 3：坐标归一化基准不一致导致 IoU 永远接近 0

  • 症状：grounding 训练正常、loss 也降了，但评估 IoU≈0。
  • 根因：训练数据坐标归一化到 0~1000（Qwen2-VL 风格），评测脚本按 0~1 小数解析（或相反）；或训练用 [x1,y1,x2,y2] 而标注是 [y1,x1,y2,x2]。
  • 定位：抽一条预测和标注人工对齐，画到图上看错位模式（整体缩放偏移 → 归一化基准错；坐标轴互换 → 顺序错）。
  • 修复：建立唯一的坐标 schema 并在数据管线上加静态校验（3.1 的正则断言就是实现）。

5. 延伸思考题

  1. 遗忘的量化：设计一个"遗忘系数"来量化 Checkpoint B 相对 A 的通用能力退化，并论证为什么简单的"分数差"不够用（提示：考虑底座模型本身的分数作参照，遗忘 =（B - 底座）/（底座 - A 的方向差），并讨论小样本噪声对系数稳定性的影响。）
  2. 课程学习 vs 混合采样：先训通用再训专精（curriculum）与按比例混合（mixture），在"防遗忘"上各有何优劣？（提示：curriculum 尾段只有专精数据，遗忘风险后置；mixture 全程有回放但专精收敛慢。工业界常见折中：两段式配比——前期通用主导、后期专精提权但保留 20% 通用。）
  3. 温度 α 的敏感性实验：用 3.1 的采样器扫 α∈{0.2,0.5,1.0}\alpha \in \{0.2, 0.5, 1.0\}α∈{0.2,0.5,1.0}，画出三任务占比随 α 的曲线；思考当三类数据量变成 5000:300:200（极度不均衡）时，α=1 与 α=0.3 的差距会被放大还是缩小，为什么。（提示：nαn^\alphanα 在数量差距大时对 α 更敏感，50000.3/2000.3 ≈ 2，而 50001/2001 = 25——极度不均衡下均匀化采样几乎是唯一现实选项。）
