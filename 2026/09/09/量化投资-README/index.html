量化投资系列教程：用数据做投资决策

面向有基础 Python 能力、想系统学习量化投资与股票选股的初学者。全系列从"量化是什么、和赌博/玄学的区别"讲起，到数据获取、指标、回测、多因子选股、组合与风控，最后用机器学习视角收尾。

⚠️ 重要声明：本系列全部内容仅用于学习与研究，不构成任何投资建议。回测结果不代表未来表现，教程中的示例数据均为虚构演示。真实投资有本金损失风险；文中涉及的工具与数据源接口可能随时间变化，以各自官方文档为准。

学习路径

篇 主题 你将学会
01-量化投资认知与风险 量化 vs 主观、常见迷思 建立正确预期：量化的本质、局限、以及为什么大多数散户策略跑不赢指数
02-数据获取与Python工具链 数据是量化的地基 用 pandas 处理行情数据；了解 akshare 等开源数据源及其边界
03-收益率与风险度量 量化的"语言" 对数收益率、波动率、最大回撤、夏普比率——公式与实现
04-技术指标与信号 MA/RSI/动量 指标的计算、信号的含义，以及"指标≠圣杯"的证据
05-回测：方法与陷阱 全系列最重要一篇 前视偏差、幸存者偏差、过拟合——为什么大多数回测是自欺
06-多因子选股入门 量化的主流范式 因子是什么、IC/分层回测怎么评价一个因子
07-组合构建与风险控制 马科维茨到仓位管理 分散化的数学、相关性、仓位与止损的量化视角
08-机器学习选股入门与陷阱 ML 在投资中的真实位置 特征/标签设计、金融数据为什么"脏"、过拟合重灾区
09-实战项目-动量选股回测系统 综合实战 端到端：数据→因子→选股→回测→评估→防作弊自查
10-进阶-交易成本与执行建模 执行工程 滑点三成分、平方根律冲击模型、VWAP/TWAP、策略容量推导
11-进阶-因子工程进阶 因子工程 MAD 去极值、中性化/正交化、双重排序、增量验证三关卡、衰减监控
12-进阶-组合优化进阶 优化器工程 约束矩阵、协方差收缩、Black-Litterman 思想、因子风险模型、扰动检验
13-进阶-从回测到实盘工程化 生产工程 研究/生产代码边界、信号流水线四件套、交易接入合规、失效处置预案

阶段划分

  1. 认知与地基（01–03）：先建立预期，再打数据与度量基础。跳过 01 直接学策略，是最常见的失败路径。
  2. 信号与验证（04–05）：产生信号 + 验证信号。05 篇的陷阱清单是全系列的灵魂。
  3. 选股与组合（06–07）：从"选一只股"到"管一组股票"。
  4. 进阶与实战（08–09）：机器学习的真实角色与端到端项目。
  5. 进阶篇（10–13）：走向实盘的纵深——执行成本、因子工程、组合优化、生产工程。建议在读完 01–07 后按需进入。

本系列的立场（提前说清，避免误导）

  1. 量化 ≠ 稳赚。量化是用统计方法管理概率与风险，亏损月/亏损年是常态；
  2. 回测赚钱 ≠ 实盘赚钱（05 篇列举的每个偏差都在扩大这个差距）；
  3. 本系列不推荐任何具体标的、不预测行情，所有示例只用历史数据做方法论演示；
  4. 对"低风险高收益"的宣称保持本能怀疑——这同样适用于本系列自己给出的任何示例结果。

环境要求

Python 3.10+，pandas、numpy、matplotlib 为核心依赖；数据获取示例以 akshare（开源财经数据接口库）为主，因其免费且无需注册；涉及接口的部分均注明"以官方文档为准"。无需任何付费数据服务。
